Reviewer Agent — 代码评审代理

类名: ReviewAgent(BaseAgent)  |  文件: src/cogniforge/agents/review_agent.py (120 行)  |  角色标识: reviewer

1. 概述

Reviewer Agent 是 CogniForge 的质量门禁第一关，采用 Agentic 委派模式——将代码评审任务（阅读设计文档、审查代码变更、生成评审报告）委派给 Claude Code CLI Agent。它生成符合 cr-report-schema.json 的结构化 CR 报告。

设计理念：Reviewer 不自行审查代码，而是构建一个包含设计意图引用的评审 Prompt，让 Claude Code 在完整工具访问权限下阅读 LLD 和代码，发现设计偏差和实现问题。

2. 角色定义

属性值

3. 执行流程

run(input_data):
  1. 提取 module + files (可选文件列表)
  2. 确定 doc_id → cr-{module}-{seq}
  3. 确定输出路径 → .cogniforge/wiki/reports/{doc_id}.json
  4. 构建 Prompt:
     - 带 JSON 输出路径和结构模板
     - 先阅读 .cogniforge/wiki/lld/{module}/ 了解设计意图
     - 阅读相关代码文件
     - 使用 PASS/FAIL 标注每项检查
     - 使用中文、只写 JSON 不写 HTML
  5. agent.generate_agentic(prompt, role="reviewer")
  6. 校验输出的 JSON (cr-report-schema.json)
  7. 渲染 HTML → git commit

4. Prompt 结构

对以下模块进行代码评审，以 JSON 格式输出并写入:

输出路径: {json_path}
JSON 结构: {
  "meta": {
    "doc_id": "cr-{module}-{seq}",
    "type": "report",
    "title": "CR 报告 - {module}",
    "author": "review_agent",
    "created": "{now}"
  },
  "content": "... (使用 PASS/FAIL 标注每项检查，包含改进建议)"
}

输入数据:
module: {module}
files: {files 列表}

要求:
1. 先阅读 .cogniforge/wiki/lld/{module}/ 了解设计意图
2. 阅读相关代码文件
3. 在 content 字段中使用 PASS/FAIL 标注每项检查
4. 使用中文、只写 JSON 不写 HTML、完成后回复确认

5. CR 报告结构

字段类型说明
meta.doc_idstr报告唯一标识 (cr-{module}-{seq})
meta.type"report"文档类型
meta.titlestr"CR 报告 - {module}"
meta.author"review_agent"作者标识
contentstr评审内容——PASS/FAIL 检查项列表及改进建议

6. CR 报告版本管理

Reviewer 支持多轮评审——通过 seq 计数器递增（cr-{module}-001, cr-{module}-002...），每次评审生成新报告而不覆盖历史。

7. 与 Claude Code 的通信

Reviewer Agent 通过 agent.generate_agentic(prompt, role="reviewer") 委派任务，Claude Code 获得：

  • 文件读取能力： 阅读 LLD 设计文档和源代码
  • Shell 执行能力： 运行 git diff 查看变更
  • 写入能力： 将 CR 报告写入指定 JSON 路径
模式 B — 委派代理：Reviewer 不直接操作文件系统，而是将"阅读设计文档 → 审查代码 → 生成报告"这条完整链委派给 Claude Code。系统层面的操作（Schema 验证、HTML 渲染、Git 提交）由 Reviewer Agent 本身执行。

8. Schema 验证链

Claude Code 输出 → JSON 文件写入
  ↓
Reviewer Agent 读取并解析
  ↓
cr-report-schema.json 验证 (jsonschema.Draft7Validator)
  ↓ 失败 → 返回 status="failed"
  ↓ 通过
render_file() → HTML 渲染 → git commit

9. 错误处理

场景处理方式
LLM agent 为 None抛出 AgentError（需要 Claude Code agent）
JSON 解析失败返回 status="failed" + 错误原文
Schema 验证失败返回 status="failed" + 前 3 项错误
Claude Code 未产生文件返回提示文件未生成
HTML 渲染失败继续（仅 JSON，无 HTML 产物）
