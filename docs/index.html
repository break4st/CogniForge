设计文档索引

设计阶段代理 (Design-Phase Agents) — 双 JSON 架构

PM Agent pm

PMAgent — 产品需求文档 (PRD) 的创建和迭代管理。采用双 JSON 架构：prd-current.json (长期状态) + pm-turn-result-schema.json (单轮变更)。支持从原始文本或结构化字段生成，以及基于 RFC 6902 JSON Patch 的交互式修改。

534 行 | src/cogniforge/agents/pm_agent.py | DeepSeek API

Architect Agent architect

ArchitectAgent — 系统架构文档 (SAD) 的生成和增量架构治理。维护 CMP/CTR/DM 三套稳定 ID 体系。包含组件类型正规化、一致性检查和下游交接功能。

680 行 | src/cogniforge/agents/architect_agent.py | DeepSeek API

Design Agent (MDE) design

DesignAgent — 5 种模块类型的详细设计文档 (LLD) 生成。三阶段架构（蓝图 → 并行分段 → 组装 + 自校正），最大自校正循环10次。拥有 16 个子 Schema 文件，支持 database/service/gateway/frontend/infrastructure 五种模块类型。

1141 行 | src/cogniforge/agents/design_agent.py | DeepSeek API

Tech Lead Agent techlead

TechLeadAgent — WBS 任务分解、质量门禁评估、流程控制和复盘总结。5 种 action 路由（create_wbs / evaluate_quality / decide_next / control_flow / retro）。上游问题检测在 WBS 生成前拦截不完整设计。

552 行 | src/cogniforge/agents/techlead_agent.py | DeepSeek API

执行阶段代理 (Execution-Phase Agents) — Agentic 委派模式

Dev Agent dev

DevAgent — 结构化 Prompt 构建 + Claude Code 委派。从 TaskContext 提取 11 段设计约束（接口签名/数据模型/领域对象/业务规则/验收标准/外部契约），构建精确实现说明。

244 行 | src/cogniforge/agents/dev_agent.py | Claude Code CLI

Reviewer Agent reviewer

ReviewAgent — 代码评审委派给 Claude Code，阅读 LLD 了解设计意图后审查代码，生成 PASS/FAIL 标注的 CR 报告。支持多轮评审版本管理。

120 行 | src/cogniforge/agents/review_agent.py | Claude Code CLI

QA Agent qa

QAAgent — 混合模式：测试用例生成和报告委派给 Claude Code；测试执行（pytest）由子进程直接运行。3 种 action：generate_tests / report / execute_tests。

222 行 | src/cogniforge/agents/qa_agent.py | Claude Code CLI

DevOps Agent devops

DevOpsAgent — 混合模式：部署配置生成委派给 Claude Code；deploy/rollback 保留为操作存根。支持按环境分版本管理部署配置。

156 行 | src/cogniforge/agents/devops_agent.py | Claude Code CLI

两种代理模式

模式使用代理LLM 交互特征
模式 A — 文档代理 PM, Architect, Design, TechLead (部分) generate_think_then_json()
generate_interactive_patch()		 双 JSON 架构（长期状态 + Patch 变更）；JSON Schema 验证；DeepSeek 直接 API
模式 B — 委派代理 Dev, Reviewer, QA (部分), DevOps (部分) generate_agentic(prompt, role) 结构化 Prompt 构建；委派给 Claude Code CLI（工具使用模式）；文件系统操作权限
模式 C — 操作代理 QA (execute_tests), DevOps (deploy/rollback), TechLead (decide_next/control_flow/retro) 无 LLM 纯代码逻辑或子进程调用；确定性操作

LLM 提供者分配

代理提供者原因
PM, Architect, Design, TechLeadllm.deepseek需要先思考后输出结构化 JSON (think → JSON)，DeepSeek 的 API 模式更适合此范式
Dev, Reviewer, QA, DevOpsagent.claude_code需要文件系统操作能力（读写代码、运行测试），Claude Code CLI 提供完整工具使用权限
