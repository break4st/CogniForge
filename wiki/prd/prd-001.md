# 用户认证系统

## Overview
构建一套完整的用户认证系统，支持邮箱注册、登录、会话管理和密码重置功能。系统需提供安全的身份验证机制，包括密码加密存储、JWT Token 会话管理、邮箱验证等基础安全能力，为平台其他功能提供统一的认证入口。

## Requirements

### 1. 邮箱注册

用户通过邮箱地址注册新账号，系统发送验证邮件确认邮箱有效性

**Acceptance Criteria:**
- 用户输入邮箱、密码、昵称后提交注册
- 系统校验邮箱格式合法性及唯一性
- 密码强度校验（至少8位，含大小写字母和数字）
- 注册成功后发送邮箱验证邮件
- 未验证邮箱的用户无法登录

### 2. 邮箱登录

已注册用户通过邮箱和密码登录系统，获取访问令牌

**Acceptance Criteria:**
- 用户输入已注册的邮箱和正确密码后可登录
- 登录成功后返回 JWT Access Token 和 Refresh Token
- 连续5次登录失败后账号临时锁定15分钟
- 支持「记住我」功能，延长会话有效期
- 登录失败返回清晰的错误提示（账号不存在/密码错误/未验证）

### 3. 密码重置

用户忘记密码时可通过注册邮箱重置密码

**Acceptance Criteria:**
- 用户输入注册邮箱后收到密码重置链接
- 重置链接有效期24小时，一次性使用
- 重置密码需满足相同密码强度要求
- 重置成功后使所有活跃会话失效
- 新旧密码不能相同

### 4. 会话管理

管理用户登录会话，支持多设备登录和登出

**Acceptance Criteria:**
- 支持多设备同时登录
- 用户可查看所有活跃会话列表
- 用户可远程登出指定设备
- Refresh Token 有效期7天，过期需重新登录
- Access Token 有效期15分钟，自动刷新

### 5. 账号安全

基础安全防护机制

**Acceptance Criteria:**
- 密码使用 bcrypt 加密存储
- JWT 使用 RS256 签名算法
- 登录接口添加速率限制（每分钟最多10次）
- 所有认证接口支持 HTTPS
- 敏感操作记录审计日志

## User Stories

### As a 访客, I want to 使用邮箱注册账号
**So that**: 成为平台注册用户
### As a 注册用户, I want to 使用邮箱和密码登录
**So that**: 访问需要认证的功能
### As a 注册用户, I want to 忘记密码时重置密码
**So that**: 恢复对账号的访问权限
### As a 注册用户, I want to 查看和管理登录设备
**So that**: 确保账号安全
### As a 系统管理员, I want to 查看用户登录审计日志
**So that**: 监控异常登录行为
