# 用户认证系统

## Overview
创建一个用户认证系统，支持邮箱注册和登录

## Requirements

### 1. 邮箱注册

用户可以通过邮箱地址注册新账号

**Acceptance Criteria:**
- 用户输入邮箱和密码完成注册
- 注册后发送验证邮件
- 验证邮箱后账号激活

### 2. 邮箱登录

已注册用户可以通过邮箱和密码登录系统

**Acceptance Criteria:**
- 用户输入邮箱和密码进行登录
- 登录失败有错误提示
- 支持记住登录状态

## User Stories

### As a 普通用户, I want to 使用邮箱注册账号
**So that**: 快速创建个人账号
### As a 已注册用户, I want to 使用邮箱和密码登录
**So that**: 安全访问系统功能

## Priorities

- **邮箱注册**: 高
- **邮箱登录**: 高
