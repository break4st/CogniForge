概述

Security Module
⚡ 基础设施
Security Module 负责私钥的加密存储与安全使用。采用主密码或OS密钥环派生AES-256-GCM密钥，对私钥进行加密后以密文形式存入SQLite。解密时仅在内存中返回明文引用，调用方使用后必须调用安全销毁接口。同时记录审计日志到SQLite，包括操作类型、目标及结果，不包含私钥明文。
依赖: better-sqlite3（数据库访问）Node.js crypto模块（加密）Electron safeStorage或OS密钥环（可选，密钥派生）
TypeScript / Node.jsElectron 主进程SQLite (via better-sqlite3)Node.js crypto (AES-256-GCM)OS 密钥环（可选）或主密码派生密钥
基于: PRD prd-current v1 · SAD sad-001 v1
📐 模块边界
范围内: 私钥加密（AES-256-GCM） 私钥解密（内存明文，用后即毁） 安全擦除内存中的私钥 密钥派生（主密码或OS密钥环） 审计日志记录（action, target, result） 与SQLite交互存储密文和审计日志 实现CTR-007定义的接口
范围外: SSH连接管理 部署流程编排 环境连通性测试逻辑（非加密部分） UI交互 密钥生成（仅加解密存储）
拥有组件: CMP-007
实现契约: CTR-007

可靠性策略

Ack: manual DLQ: 无死信队列，采用同步重试 幂等: 审计日志写入：基于请求ID去重，防止重复记录；加密存储：通过密钥指纹检查是否已存在相同记录，存在则覆盖或跳过。 重试: max 3x, backoff exponential

编排流程

SecurityModuleInitialization

模块初始化流程：验证数据库连接，检查密钥环可用性，加载必要配置

1
OpenDatabase (10s 超时)
打开或创建SQLite数据库文件，执行建表语句
失败处理: 重试一次，仍失败则抛出致命错误，阻止模块启动
2
CheckKeyDerivation (5s 超时)
检测可用的密钥派生源（OS密钥环或主密码配置）
失败处理: 若两者均不可用，记录审计日志并提示用户配置
重试策略: 最多 1 次，间隔 5s
可重试错误: DATABASE_CONNECTION_ERROR
不可重试错误: KEY_DERIVATION_UNAVAILABLE

接口定义 (1)

安全服务接口，提供私钥加密、解密和安全销毁，以及审计日志记录功能。
Response 200

错误处理

处理策略

采用结构化错误码返回，所有接口异常均通过统一错误响应格式反馈调用方，记录详细审计日志。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
4xx
客户端错误
输入参数无效或缺失，返回400并提示具体错误信息；资源未找到返回404。
5xx
服务器错误
加密/解密/数据库操作等内部失败，返回500并记录错误详情到审计日志。
