概述

Deployment Orchestrator
部署流程编排引擎，管理部署任务的创建、调度和执行状态跟踪。接收部署请求后创建部署记录（持久化至 PostgreSQL），将部署任务拆分为多个步骤并发布到 RabbitMQ 供 SSH Execution Service 消费执行，通过 Redis 缓存实时部署状态，通过 WebSocket 向 Web Console 推送实时部署日志和进度更新。
依赖: RabbitMQRedisPrimary DatabaseSSH Execution ServiceAudit Service
PythonFastAPIPostgreSQL 15Redis 7RabbitMQ 3.12WebSocket (FastAPI WebSocket)

错误处理

Deployment Orchestrator 对各类异常进行统一处理：(1) 参数校验异常 — 请求体 JSON 解析失败、必填字段（version、environment_id）缺失或格式错误返回 400 Bad Request，附带具体校验错误详情；(2) 资源不存在 — 项目 ID 或环境 ID 在数据库中不存在时返回 404 Not Found；(3) RabbitMQ 异常 — 发布消息失败时最多重试 3 次（间隔 1s），全部失败则返回 502 Bad Gateway 并将部署记录标记为 failed；(4) Redis 缓存异常 — Redis 不可用时降级为直接查询数据库，核心部署功能不受影响但实时推送能力受限，错误记录到日志；(5) 数据库异常 — 部署记录写入失败返回 500 Internal Server Error，部署状态更新回滚并标记为 failed；(6) WebSocket 异常 — 客户端断连时清理连接资源并停止推送，异常关闭时记录错误上下文；(7) SSH Execution Service 回调异常 — 接收步骤执行结果时若返回非零退出码则标记该步骤为 failed 并终止后续步骤，整个部署标记为 failed；(8) 未捕获异常 — 统一返回 500 Internal Server Error 并在审计日志中记录错误上下文。所有错误响应体统一格式为: { code: integer, error: string, detail: string }。
