概述

后端 API 服务
⚙️ 业务服务
The backend API service provides RESTful endpoints for managing projects, environments, SSH keys, and deployments. It coordinates with the deployment executor for async deployment tasks and the encryption service for key management. WebSocket endpoints stream real-time deployment logs.
依赖: 部署执行器: internal_async asyncio task / background task - Execute deployment steps and stream logs密钥加密服务: internal_sync Python library call - Encrypt/decrypt SSH private keysSSH 客户端模块: internal_sync Paramiko library - Test SSH connectivityPostgreSQL 数据库: external SQL via async driver (asyncpg/SQLAlchemy) - Persist all data
Python 3.10+ - Primary languageFastAPI 0.95+ - Web frameworkPostgreSQL 14+ - Primary databaseasyncpg / SQLAlchemy[asyncio] latest stable - Async database accessParamiko 2.11+ - SSH connectivity testingcryptography 39.0+ - Encryption/decryption of keys (called via 密钥加密服务)Python asyncio stdlib - Async task management for deploymentsFastAPI BackgroundTasks built-in - Trigger background deployment tasks
基于: PRD prd-Deployment Dashboard-001 v1 · SAD sad-Deployment Dashboard-001 v1
📐 模块边界
范围内: Project CRUD operations Environment CRUD operations (scoped to project) SSH key management (CRUD, encryption delegation) Environment connectivity testing Deployment triggering (file upload, async task initiation) Real-time deployment log streaming via WebSocket Deployment history retrieval with pagination and filtering Rollback initiation (create rollback deployment record, async rollback task) Deployment cancellation (signal async task)
范围外: User authentication and authorization (delegated to external auth service/Nginx) Actual SSH command execution (delegated to 部署执行器 component) Key encryption/decryption implementation (delegated to 密钥加密服务) Frontend UI rendering Database schema definition (owned by Primary Database) Deployment package building
拥有组件: CMP-002

  • !BR-001: Project names must be unique per user
  • !BR-002: Environment names must be unique within a project
  • !BR-003: SSH key names must be unique per user
  • !BR-004: Deployments can only be created for existing projects and environments
  • !BR-005: A deployment cannot be rolled back unless it is in 'success' status
  • !BR-006: A deployment cannot be cancelled unless it is in 'pending' or 'in_progress' status
  • !BR-007: WebSocket connections for deployment logs require valid deployment_id
