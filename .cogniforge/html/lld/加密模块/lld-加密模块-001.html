概述

加密模块
⚡ 基础设施
负责主密码验证与派生、私钥内容的 AES-256-GCM 加解密。初始化时提示用户设置主密码，派生密钥存储在内存中，不落盘。
Node.js crypto (AES-256-GCM, PBKDF2)
基于: PRD prd-current v1 · SAD sad-001 v1
📐 模块边界
范围内: 主密码设置与验证 密钥派生（PBKDF2） 内容加解密（AES-256-GCM） 内存中密钥存储，不落盘
范围外: 主密码的持久化存储 用户界面 密钥管理模块的数据库操作
拥有组件: CMP-009
实现契约: CTR-009

可靠性策略

Ack: manual DLQ: 加密模块死信队列 幂等: 幂等性由调用方保证，加密操作本身无状态，解密操作依赖正确密钥，重复解密不会产生副作用 重试: max 3x, backoff exponential

编排流程

加密操作流程

主密码设置、验证、加密、解密流程

1
设置主密码 (30s 超时)
验证密码强度，派生密钥并保存在内存
失败处理: 返回错误码 MASTER_PASSWORD_NOT_SET
2
验证主密码 (10s 超时)
比较输入密码派生密钥与内存密钥
失败处理: 返回错误码 INVALID_PASSWORD，并记录尝试次数
3
加密数据 (60s 超时)
使用 AES-256-GCM 加密明文
失败处理: 返回错误码 ENCRYPTION_FAILED
4
解密数据 (60s 超时)
使用 AES-256-GCM 解密密文
失败处理: 返回错误码 DECRYPTION_FAILED
重试策略: 最多 3 次，间隔 30s
可重试错误: NETWORK_ERROR, TIMEOUT
不可重试错误: AUTH_ERROR, CONFIG_ERROR

接口定义 (1)

INTERNALN/A加密接口
提供主密码设置与验证、密钥派生以及基于 AES-256-GCM 的内容加解密功能。所有密钥仅存于内存，不落盘。
Response
字段类型
setMasterPasswordvoid，成功无返回
verifyMasterPasswordboolean，验证结果
encryptobject，{ ciphertext: string, iv: string }
decryptstring，解密后的明文
错误码
状态码说明
MASTER_PASSWORD_NOT_SET主密码尚未设置，请先调用 setMasterPassword
INVALID_PASSWORD密码验证失败
ENCRYPTION_FAILED加密过程发生错误
DECRYPTION_FAILED解密过程发生错误，可能密文损坏或密钥不匹配
KEY_DERIVATION_FAILED密钥派生失败
