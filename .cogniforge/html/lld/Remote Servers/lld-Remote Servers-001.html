概述

Remote Servers
⚙️ 业务服务
Remote Servers 是部署流程的外部目标环境，由用户自行管理的 SSH 可达服务器集群。本模块定义远程服务器的接入规范、预期运行环境、目录结构约定和执行契约。SSH Execution Service 通过 SSH-2 协议连接远程服务器，上传部署产物并执行部署脚本，获取命令执行结果。远程服务器本身不部署任何 CogniForge 组件，仅提供标准的 SSH-2 服务和 POSIX shell 环境。
SSH-2

📌 RemoteConnection值对象

远程服务器的 SSH 连接参数不可变值对象。封装建立 SSH 会话所需的所有连接信息，创建后不可修改，每次使用新建实例。连接参数来源于 Primary Database environments 表和解密后的密钥材料。

属性
属性名类型描述
host * 输入String远程服务器 IP 地址或 FQDN
port * 输入IntegerSSH 端口号，范围 1-65535
username * 输入StringSSH 登录用户名
privateKey * 输入String解密后的 PEM 格式私钥内容，使用后立即从内存清除
passphrase 输入String私钥保护口令（密钥导入时若设置了口令保护则需要）
timeoutSeconds * 输入Integer连接建立超时秒数，默认 10

📌 RemoteCommand值对象

要在远程服务器上执行的命令不可变值对象。封装命令字符串和执行参数，用于传递给 SSH channel 的 exec 请求。

属性

属性
属性名类型描述

服务接口 (2)

🔧 RemoteServerConnector 6 方法
connect
(connection: RemoteConnection) -> SSHClientSession
建立到远程服务器的 SSH-2 加密连接，执行 TCP 握手、SSH 协议版本协商、密钥交换和公钥用户认证。
前置条件
connection 所有必填字段通过基础校验（host 非空合法 FQDN/IP、port ∈ [1,65535]、privateKey 为合法 PEM 格式）。远程服务器已开机且端口对客户端 IP 开放。
后置条件
返回已认证的 SSHClientSession 实例，TCP 握手→SSH 协议协商→密钥交换→用户认证均成功完成。若 expectedFingerprint 提供则已校验一致。若连接失败不泄漏任何 TCP 或 SSH 会话资源。
ConnectionTimeoutException→ 504SSH 连接握手超过 timeoutSeconds 未完成AuthenticationFailedException→ 401私钥被远程服务器拒绝，所有认证方法均失败HostKeyMismatchException→ 403远程服务器主机密钥指纹与 expectedFingerprint 不匹配ConnectionRefusedException→ 502远程服务器主动拒绝 TCP 连接（端口未开放或防火墙拦截）ProtocolVersionException→ 500远程 SSH 服务协议版本不兼容（低于 SSH-2.0）
executeCommand
(session: SSHClientSession, command: RemoteCommand) -> CommandExecutionResult
在已建立的 SSH 会话中通过远程 shell 执行一条命令，收集 stdout、stderr 和退出码。
前置条件
session 为已认证的活跃 SSH 会话（is_active() == true）。command.commandLine 非空且长度 ≤ 65535 字符。远程服务器的默认 shell（/bin/bash）可用。
后置条件
命令在远程 shell 中以非交互模式完整执行。返回完整的 CommandExecutionResult（stdout、stderr、exitCode）。退出码非零不视为异常——退出码属于业务数据，由调用方根据上下文决定后续处理。
SessionClosedException→ 502SSH 会话在执行命令前已关闭或网络中断无法恢复CommandTimeoutException→ 504命令执行超过 timeoutSeconds 未返回，SSH channel 已关闭CommandInterruptedException→ 500命令被远程系统信号中断（SIGKILL/SIGTERM），非正常退出
uploadFile
(session: SSHClientSession, request: FileTransferRequest) -> FileTransferResult
通过 SFTP 子协议将本地文件传输到远程服务器的指定路径。支持自动创建父目录和设置文件权限。
前置条件
session 为已认证的活跃 SSH 会话。request.localPath 对应的本地文件存在且可读（由调用方确保）。request.remotePath 为合法 Unix 绝对路径。远程服务器 SFTP 子系统可用。
后置条件
文件通过 SFTP 协议传输到远程 request.remotePath 位置。若 parent 目录不存在则自动创建。返回 FileTransferResult（remotePath、size、checksum）。若 overwrite=false 且远程文件已存在则不覆盖并抛出异常。
SftpProtocolException→ 502SFTP 协议层错误（协议版本不兼容或传输中断）PermissionDeniedException→ 403远程用户对目标路径无写入权限DiskFullException→ 507远程服务器磁盘空间不足以存放传输文件FileExistsException→ 409远程文件已存在且 request.overwrite=false
testConnection
(connection: RemoteConnection) -> ConnectionProbeResult
快速探测远程服务器的连通性和认证有效性。用于 Web Console 的「测试连接」功能。自动清理所有临时会话资源。
前置条件
connection 必填字段通过基础格式校验（host 非空、port ∈ [1,65535]）。
后置条件
返回 ConnectionProbeResult 包含连通性、认证状态和基础环境信息。不抛出任何异常——所有 SSH 错误被内部捕获并映射为 result 字段（reachable=false、authenticated=false）。不保留任何 SSH 会话、连接或通道资源。
checkEnvironment
(session: SSHClientSession) -> ServerEnvironmentCheck
通过远程执行一系列探测命令，验证部署所需的基础工具、磁盘空间和路径可写性是否满足要求。
前置条件
session 为已认证的活跃 SSH 会话。
后置条件
通过远程执行探测命令（which bash、mkdir --version、df -h 等）收集环境信息。返回 ServerEnvironmentCheck 结果。不修改远程服务器任何状态。
SessionClosedException→ 502SSH 会话在执行探测命令前已关闭
closeSession
(session: SSHClientSession) -> void
关闭 SSH 会话，释放 TCP 连接和所有关联资源。幂等操作。
前置条件
session 非 null（已关闭或未关闭均可安全调用）。
后置条件
SSH 会话已关闭，TCP 连接已断开，所有相关资源（channel、socket 等）已释放。重复调用无副作用（幂等）。
🔧 RemoteDeployExecutor 3 方法
prepareDirectories
(session: SSHClientSession, layout: RemoteDirectoryLayout) -> void
在远程服务器上使用 mkdir -p 递归创建版本化的部署目录结构，包括产物、脚本和日志子目录。
前置条件
layout 所有字段已通过计算（versionDir、artifactDir、scriptDir、logDir 均有确定值）。session 对应远程用户对 layout.basePath 的父目录有写权限。

远程服务器上已通过 mkdir -p 创建 artifactDir、scriptDir、logDir 三个子目录。若目录已存在则静默跳过（幂等）。目录权限默认 0755。
DirectoryCreateFailedException→ 500远程 mkdir -p 命令返回非零退出码（权限错误或磁盘故障）SessionClosedException→ 502SSH 会话在目录创建操作期间关闭
executeDeployScript
(session: SSHClientSession, scriptContent: String, layout: RemoteDirectoryLayout, timeoutSeconds: Integer) -> CommandExecutionResult
将部署脚本写入远程服务器文件，设置可执行权限，在版本目录上下文中执行并收集结果。这是部署流程在远程环境中的核心步骤。
前置条件
scriptContent 为非空合法 bash 脚本。layout.versionDir 已通过 prepareDirectories 创建。session 为活跃 SSH 会话。
后置条件
脚本内容写入 layout.scriptDir/deploy.sh 文件 → chmod +x 设置可执行 → cd layout.versionDir → bash layout.scriptDir/deploy.sh 执行 → 返回 CommandExecutionResult。脚本文件保留在远程服务器上供后续审计。退出码非零时脚本文件仍保留。

updateCurrentSymlink
(session: SSHClientSession, layout: RemoteDirectoryLayout) -> void
原子性地更新 current 符号链接指向最新成功部署的版本目录。实现部署版本切换和快速回滚（只需重新指向旧版本目录）。
前置条件
layout.versionDir 目录在远程服务器上已存在且部署脚本已成功执行。layout.currentSymlink 路径已确定。
后置条件
远程 layout.currentSymlink 符号链接已原子性指向 layout.versionDir（ln -sfn）。之前的 current 目标（如有）维持不变——旧版本目录不被删除。

业务规则

不变量
  • !远程服务器的主机地址（host）和 SSH 端口（port）一旦在 environments 表中创建即不可修改——如需变更连接目标必须新建环境记录。
  • !同一时间最多只能有一个活跃的部署任务操作同一个远程服务器（由 SSH Execution Service 通过 RabbitMQ 队列 prefetch=1 保证）。
  • !远程服务器上的版本目录一旦由部署创建即进入只读状态——部署回滚通过切换 current 符号链接指向旧版本目录实现，不删除或修改已存在的版本目录。
  • !远程服务器的 SSH 密钥指纹必须在环境创建时记录，后续每次连接校验指纹一致性，防止中间人攻击。
  • !部署脚本在远程服务器上的执行必须设定最大超时时间（默认 600 秒，上限 1800 秒），防止脚本失控无限执行。

🚫 部署进行中（deploying 状态）不可强行关闭 SSH 连接——必须等待脚本正常完成或超时自动终止。🚫 版本目录一旦部署完成即不可被后续任何操作覆盖或删除——只能通过创建新版本目录实现更新。🚫 error 状态的远程服务器在人工确认前不可自动进入 deploying 状态。
⚡ 每个 RemoteServer（environments.id）同一时间只能被一个部署流程操作。SSH Execution Service 通过 RabbitMQ 队列消费者预取计数 prefetch=1 保证单消费者串行处理同一环境 ID 的部署任务。跨环境的部署任务可并行执行，并发数由 SSH Execution Service max_concurrent_tasks 配置控制（默认 5）。
跨服务规则
SSH Execution Service 必须在每次连接远程服务器前调用 Key Management Service 解密 SSH 私钥，禁止在本地持久化缓存私钥明文。私钥使用后立即从内存清除。
远程服务器上命令执行结果的 stdout/stderr 必须由 SSH Execution Service 转发到 Audit Service 进行持久化审计记录。
远程服务器的连接参数（host/port/username/key_id）的权威来源为 Primary Database 的 environments 表。SSH Execution Service 可以在 Redis 中缓存这些参数，但 TTL 不得超过 60 秒。
远程服务器的部署目录结构（RemoteDirectoryLayout）由 SSH Execution Service 在部署执行时按规范计算，目录布局参数（basePath）可通过 Project Management Service 的项目级配置定制。

错误处理

处理策略

Remote Servers 作为外部系统，错误以 SSH 协议异常的形式暴露。所有 SSH 操作（连接/命令/文件传输）必须设置超时，通过重试策略（最多 3 次，指数退避 1s/3s/9s）处理临时性网络故障。认证类和权限类错误不可重试，需直接上报给用户排查。非零退出码不自动视为系统错误，作为业务数据由上层（SSH Execution Service）记录和评估。stderr 输出按最大 1MB 截断。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
1
网络层错误
SSH 连接超时、连接被拒绝、网络中断。触发指数退避重试（最多 3 次），3 次后上报不可恢复错误。重试间隔 1s/3s/9s 并附加 20% 随机 jitter。
2
认证错误
私钥被远程服务器拒绝、用户不存在、主机密钥指纹不匹配。不可重试，必须由用户检查密钥绑定和远程 authorized_keys 配置。
3
文件传输错误
远程路径权限不足、磁盘空间不足、SFTP 协议错误。记录远程磁盘状态（df -h）到日志辅助排查，不可重试。磁盘满时触发告警。
4
命令执行错误
命令超时、退出码非零、被信号中断。stderr 和退出码完整记录到部署日志。超时（30 分钟上限）时自动终止远程进程。
5
环境预检错误
远程服务器缺少必需工具（bash、mkdir、chmod）、磁盘不足、基础路径不可写。在部署前置检查阶段识别，以 ConnectionProbeResult 或 ServerEnvironmentCheck 返回。
