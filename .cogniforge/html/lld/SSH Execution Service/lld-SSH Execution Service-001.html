概述

SSH Execution Service
远程命令执行服务，通过 SSH 连接到远程服务器并执行部署操作。从 RabbitMQ 消费部署任务，使用 asyncssh 建立并发 SSH 会话，在远程服务器执行目录创建、文件传输、脚本生成和命令执行等操作，并将执行结果实时回传。
依赖: RabbitMQKey Management ServiceFile Storage
PythonFastAPIasyncsshRabbitMQ 3.12
🗄️

配置定义 1

⚙️ ssh_session_config自有

SSH 会话默认配置，控制连接建立和命令执行的全局参数。服务启动时从配置中心加载，运行期间保持不变。

字段
字段名类型描述
default_timeout *integer默认命令执行超时时间（秒），接口未指定 timeout 时使用此值，默认 300
connection_retry_max *integerSSH 连接失败时的最大重试次数，默认 3
connection_retry_interval_base *integer重试间隔基准值（秒），实际间隔按指数退避计算，默认 1
keepalive_interval *integerSSH 连接保活心跳间隔（秒），默认 30
max_concurrent_sessions *integer最大并发 SSH 会话数，防止资源耗尽，默认 50

接口定义 (2)

POST/internal/ssh/executeExecuteSSHCommand
在远程服务器上执行一条 SSH 命令并返回执行结果。接收连接参数和命令内容，建立 SSH 会话并执行，等待命令完成后返回退出码和输出流。此接口为内部服务间调用，不通过 API Gateway 对外暴露。
参数类型描述
hoststring远程服务器主机名或 IP 地址
portintegerSSH 端口号，默认 22
usernamestringSSH 登录用户名
key_contentstring解密后的私钥内容（PEM 格式字符串）
commandstring待执行的远程 Shell 命令
timeoutinteger命令执行超时时间（秒），不传时使用全局默认配置
Response 200
字段类型
exit_codeinteger
stdoutstring
stderrstring
executed_atstring
错误码
状态码说明
400请求参数无效（host 为空、port 超出范围（1-65535）、key_content 非合法 PEM 格式）
401SSH 认证失败（私钥与用户名不匹配、私钥已吊销或格式错误）
408SSH 连接超时或命令执行超时（超过 timeout 参数指定的时间）
502SSH 连接失败（主机不可达、端口未开放、DNS 解析失败，重试耗尽后返回）

INTERNALAMQP exchange: deploy.taskDispatchDeployTask
从 RabbitMQ 的 deploy.task 交换机订阅并消费部署任务消息。SSH Execution Service 作为消费者绑定到队列，接收 Deployment Orchestrator 发布的部署步骤，依次执行远程操作（创建目录、传输文件、生成脚本、启停服务），并将每步执行结果发布回 MQ 供 Deployment Orchestrator 汇总。

file_pathstring可执行文件在 File Storage 上的存储路径，SSH ES 通过该路径读取文件并传输到远程服务器
versionstring部署版本号，用于在远程服务器上创建版本化目录结构
stepsarray<string>部署步骤顺序列表，如 ['create_directories','transfer_file','generate_script','execute_start']

⚠️

错误处理

SSH Execution Service 对运行时异常进行分级处理：(1) 参数校验异常 — 请求体 JSON 解析失败、必填字段缺失、host 为空、port 超出范围（1-65535）、key_content 非 PEM 格式时返回 400 Bad Request，附带具体校验错误详情；(2) SSH 连接阶段异常 — 主机不可达、DNS 解析失败、端口未开放时按指数退避重试（间隔 1s / 4s / 16s，最多 3 次），重试耗尽后返回 502 Bad Gateway 并在审计日志中记录连接失败上下文；(3) SSH 认证阶段异常 — 私钥格式错误、用户名不匹配、密钥已吊销等认证失败不进行重试（重试无意义），立即返回 401 Unauthorized；(4) 命令执行阶段异常 — 远程命令返回非零退出码时不视为服务异常，将 exit_code 和 stderr 原样封装在响应体中返回，由调用方判断业务成功与否；(5) 超时异常 — SSH 连接建立超过 30 秒或命令执行超过 timeout 参数时中断会话，清理连接资源，返回 408 Request Timeout；(6) 文件传输异常 — 从 File Storage 读取文件失败或 SCP/rsync 传输中断时记录错误细节，标记当前部署步骤为 failed 并跳过后续步骤；(7) 资源限制 — 当前并发 SSH 会话数达到 max_concurrent_sessions 时对新请求返回 503 Service Unavailable，等待其他会话释放后再接受；(8) MQ 消费异常 — 消息格式解析失败时记录错误日志并将消息投递至死信队列（DLQ），不阻塞后续消息消费；步骤执行中抛出的未捕获异常由消费处理器统一捕获，记录完整错误栈并将该部署步骤标记为 failed。所有错误响应体统一格式为: { code: integer, error: string, detail: string }。关键操作（连接建立、命令执行、文件传输）均记录审计追踪日志。
