概述

模块: SSH Execution Service
SSH执行服务，负责与远程服务器建立安全连接并执行命令。作为内部微服务，提供SSH连接池管理与复用、远程命令执行与结果返回、文件安全传输（SCP/SFTP）、连接超时与重试机制、连接日志记录等功能。被 Deployment Orchestrator 用于部署流程中的远程文件夹创建、文件传输、脚本推送和远程执行，被 Environment Management Service 用于环境连接验证。服务无状态，所有连接参数由调用方传入，不持久化存储任何敏感信息。
GoGin / Go-Zerogolang.org/x/crypto/sshSCP / SFTP

错误处理

所有内部接口统一返回 JSON 格式错误：{ code: int, message: string }。400 参数校验失败、401 SSH 认证失败、404 文件或路径不存在、408 连接或执行超时、413 文件大小超限、500 服务内部错误、507 磁盘空间不足。 【SSH 连接池管理】 连接池采用进程内 sync.Map + channel 实现，以 {username}@{host}:{port} 为键管理连接。获取连接时优先从池中取出空闲连接并发送 keepalive 心跳验证有效性，心跳失败则关闭该连接并创建新连接。连接使用完毕后归还池中而非关闭。空闲连接超过 idle_timeout_seconds（默认 300 秒）由后台 goroutine 定期扫描并关闭回收。最大连接数由 max_total_connections 控制，达到上限时请求阻塞等待（带超时）。sync.RWMutex 保证并发安全。 【命令执行流程】 1）解析请求参数，校验必填字段和取值范围（port 1-65535、timeout_seconds 1-3600）；2）从连接池获取或新建 SSH 连接（新建时执行 TCP 拨号 → SSH 握手 → 认证，步骤任一出错返回 401 或 500）；3）创建 ssh.Session，设置请求的超时上下文（context.WithTimeout）；4）组合 stdout 和 stderr 管道，通过 goroutine 并行读取以防死锁；5）session.Run(command) 同步等待命令执行完毕；6）生成 UUID 作为 execution_id，组装 SSHExecutionResult；7）将连接归还连接池（更新 last_used_at），返回响应；8）超时场景下 session.Signal(SIGKILL) 强制终止并关闭该连接。 【文件传输流程】 upload 方向：先校验本地 source_path 文件的可读性和大小，再通过 SCP 的 CopyFromRemote 对应方法（实际使用 SFTP 的 Open→io.Copy）将文件逐块传输到远程 target_path，每传输 64KB 更新 bytes_transferred。download 方向：先通过 SFTP 的 Stat 检查远程文件存在性和大小，再读取并写入本地 target_path。传输完成后校验两端文件大小。上传方向若远程磁盘空间不足（SCP 协议返回具体错误码）返回 507。 【重试机制】 可重试错误（网络抖动导致的 SSH 握手失败、瞬态超时）：自动重试最多 2 次，间隔指数退避（1 秒、2 秒）。不可重试错误（参数校验失败、私钥无效、文件不存在）：直接返回错误不重试。每次重试前关闭失效连接确保下次新建连接。 【安全与日志】 private_key 字段在任何日志输出中必须脱敏——日志中记录 key_hash（SHA256 指纹）而非密钥内容。所有 SSH 操作（连接建立/关闭、命令执行、文件传输）均记录结构化日志，包含：execution_id、host、command 摘要（截取前 128 字符）、exit_code、duration_ms。敏感信息（密钥内容、命令输出中的密码类文本）不在日志中明文记录。所有请求处理完毕后在内存中及时清除 private_key 引用，交由 GC 回收。 【并发安全】 连接池操作全程持有锁。同一 host:port 的多个并发请求共享同一连接（SSH 连接支持多 session 复用）。后台空闲回收 goroutine 每分钟扫描一次连接池，关闭 idle_timeout 超期的空闲连接。服务接收到 SIGTERM 信号时优雅关闭：停止接受新请求 → 遍历关闭连接池中所有活跃连接 → 等待进行中的请求完成（最多等待 30 秒）→ 退出。
