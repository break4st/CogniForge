概述

SSH Execution Service
SSH执行服务，负责通过Paramiko库建立SSH连接到远程服务器并执行部署操作。通过RabbitMQ异步消费部署任务，解析MQ消息中的连接参数和加密SSH私钥，调用Key Management Service解密私钥后建立SSH连接，在远程服务器上创建版本文件夹、上传可执行文件、生成并执行部署脚本，实时回传执行日志到Deployment Orchestrator，处理SSH连接异常和自动重试。
依赖: Deployment OrchestratorKey Management ServiceMessage Queue (RabbitMQ)
Python 3.11+ParamikoRabbitMQDocker 容器化部署

错误处理

SSH执行服务的错误处理分为六个层面： (1) MQ消息层 — 消息反序列化或格式校验失败时记录错误日志并确认消费（basic_ack），避免死信队列堆积；消息处理过程中发生异常时，根据异常类型决定是否重新入队（requeue）——连接类异常允许重试，格式类异常直接丢弃。 (2) 密钥解密层 — 调用Key Management Service解密SSH私钥失败时，记录错误日志（不泄露密钥材料），立即终止执行流程，将失败结果（deployment_id、success=false、error_message）投递到部署结果队列。 (3) SSH连接层 — 连接建立失败启用自动重试机制：最多重试3次，采用指数退避策略（2s/4s/8s退避间隔），每次重试前重新初始化Paramiko SSHClient避免连接状态污染；重试耗尽仍失败时在error_message中返回原因描述（如主机不可达、认证失败、连接超时），不暴露密钥材料或服务器敏感信息。 (4) 命令执行层 — 每条命令设置独立执行超时（由SSHExecutionConfig.command_timeout控制，默认300秒），超时后强制关闭SSH通道（channel.close）并终止后续命令执行；命令退出码非零时捕获标准错误输出写入stderr字段；执行过程中通过Report Execution Log接口实时推送日志片段。 (5) 文件操作层 — 远程版本文件夹创建失败（权限不足/路径冲突）、SFTP文件上传失败（磁盘空间不足/网络中断）等异常，捕获异常描述后终止执行并返回失败结果。 (6) 超时兜底层 — 命令执行超时或SSH连接空闲超时时关闭连接并清理资源（临时文件、SSH通道），防止远程服务器残留僵尸进程。所有异常处理路径最终收敛为统一的响应body格式（deployment_id、success、exit_code、stdout、stderr、error_message），通过AMQP确认机制（basic_ack）确保结果可靠投递到Deployment Orchestrator的结果消费队列。
