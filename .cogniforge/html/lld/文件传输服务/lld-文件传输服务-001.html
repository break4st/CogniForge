概述

文件传输服务
⚙️ 业务服务
负责将待部署的可执行文件通过SCP安全传输到远程服务器的指定部署目录，提供文件上传接收、完整性校验及远程传输能力。接收部署引擎服务下发的传输请求（含目标服务器连接参数和SSH密钥标识），内部通过Paramiko建立SCP连接完成文件推送，并返回传输结果
依赖: 部署引擎服务密钥管理服务PostgreSQL主数据库
PythonFastAPIParamikoREST + SSH/SCP
🗄️

数据模型 (1)

配置定义 1

⚙️ TransferConfig自有

文件传输服务内部运行时配置，定义SCP传输超时、重试策略、并发控制等参数，通过环境变量或配置文件注入

字段
字段名类型描述
scp_timeout_seconds *int单次SCP传输超时时间，默认60秒
max_retries *int传输失败最大重试次数，默认3
retry_delay_seconds *int重试间隔等待秒数，默认5
verify_checksum *bool传输完成后是否校验文件SHA256校验和，默认true
max_concurrent_transfers *int最大并发传输任务数，默认10
temp_dirstring本地临时文件目录，默认系统临时目录

领域对象 (5)

📋 TransferRequestDTO

文件传输请求DTO，封装SCP传输所需的全部参数，由部署引擎服务传入

属性
属性名类型描述
host * 输入String远程服务器IP或主机名
port * 输入IntegerSSH端口，默认22
login_user * 输入StringSSH登录用户名
key_id * 输入UUIDSSH密钥唯一标识，用于获取解密私钥
local_path * 输入String本地待传输文件绝对路径
remote_path * 输入String远程目标文件绝对路径

📋 TransferResultDTO

文件传输结果DTO，包含传输是否成功、传输字节数和耗时，返回给部署引擎服务

属性
属性名类型描述
success * 派生Boolean传输是否成功，true表示文件已完整到达远程路径
transferred_bytes * 派生Long实际传输的字节数，失败时可能为0或部分传输
elapsed_ms * 派生Long传输操作总耗时（毫秒），含SSH连接建立时间

📌 ScpConnectionConfig值对象

SCP连接配置值对象，由TransferRequest和SSH私钥组合构建，不可变，用于创建Paramiko SCP客户端实例

属性
属性名类型描述
host * 输入String远程服务器地址
port * 输入IntegerSSH端口
login_user * 输入StringSSH登录用户名
private_key * 派生String解密后的SSH私钥明文（PEM格式），从密钥管理服务获取
connect_timeout * 输入Integer连接超时秒数，从TransferConfig.scp_timeout_seconds获取

🔢 TransferStatus枚举

文件传输状态枚举，标识单次传输任务的执行阶段

值
pending connecting transferring success failed

🏷️ TransferRecord实体

文件传输记录实体，表征一次完整的文件传输任务的生命周期，在服务内存中维护

属性
属性名类型描述
id * 派生UUID传输记录唯一标识，自动生成
request * 输入TransferRequest原始传输请求
status * 派生TransferStatus当前传输状态
result 派生TransferResult传输结果，仅状态为success/failed时有值
started_at * 派生DateTime传输开始时间
finished_at 派生DateTime传输完成时间
retry_count * 派生Integer当前已重试次数，默认0

服务接口 (1)

🔧 FileTransferService 2 方法
transferFile
(request: TransferRequest) -> TransferResult
执行一次文件SCP传输：解析SSH密钥->建立SCP连接->传输文件->校验完整性->返回结果
前置条件
request 已通过参数校验（host/port/login_user/key_id/local_path/remote_path均非空合法）；local_path 指向的文件在本地文件系统真实存在且可读
后置条件
返回 TransferResult；success=true 时 remote_path 指向的文件在远程服务器上存在且字节数与 local_path 源文件一致；success=false 时已自动重试（最多 maxRetries 次），remote_path 不保证存在
ParameterValidationException→ 400request中必填字段缺失或格式不合法（如port<1或port>65535、local_path非绝对路径）KeyResolutionException→ 502调用密钥管理服务获取SSH私钥失败（key_id不存在或密钥状态不可用）AuthenticationException→ 401SSH密钥认证被目标服务器拒绝（密钥不匹配或login_user无权访问）ConnectionException→ 503无法连接到远程服务器（主机不可达、端口未开放、DNS解析失败）TransferTimeoutException→ 408SCP传输超过scp_timeout_seconds配置的超时时间FileNotFoundException→ 404local_path在本地文件系统中不存在或无权读取IntegrityCheckException→ 500传输完成后文件SHA256校验和不匹配，已自动重试但仍失败
verifyFileIntegrity
(localPath: String, remoteHost: String, remotePath: String, sshConfig: ScpConnectionConfig) -> Boolean
通过SSH连接远程服务器对已传输文件执行远程SHA256校验，与本地文件校验和对比，确认文件完整性
前置条件
localPath 指向的本地文件存在；remoteHost:remotePath 指向的远程文件存在且 sshConfig 认证信息有效
后置条件
返回 true 时本地文件与远程文件的 SHA256 校验和一致；返回 false 时不一致或校验过程中发生错误
ConnectionException→ 503校验过程中与远程服务器的SSH连接中断RemoteCommandException→ 500远程服务器上执行 sha256sum 命令失败或命令不存在
数据访问依赖
findDecryptedKeyById(keyId: UUID) -> String 通过密钥管理服务内部接口获取解密后的SSH私钥明文
📐

业务规则

不变量
  • !传输前必须确认 local_path 指向的本地文件在服务所在节点真实存在且可读
  • !传输完成后必须校验文件完整性（SHA256校验和对比），校验失败且重试耗尽后标记失败
  • !SSH私钥在服务内部仅用于建立SCP连接，不允许持久化或记录到日志中
  • !单次传输任务的并发数不得超过 max_concurrent_transfers 配置值
  • !同一目标服务器的连续传输失败次数超过阈值（默认连续5次）时应触发告警，避免无效重试
状态机
🎯 TransferRecord
pendingconnectingtransferringsuccessfailed
→resolveSshKeyby FileTransferService
→scpConnectedby FileTransferService
→connectionFailedby FileTransferService
→transferCompletedby FileTransferService
→transferFailedby FileTransferService
→retryAttemptby FileTransferService
→retryAttempt（retryCount < maxRetries）by FileTransferService
🚫 success 状态为终态，不可转换到其他任何状态🚫 failed 状态仅可转换到 connecting（重试），不可转换到 transferring 或 success🚫 pending 状态的传输请求若在10秒内未进入 connecting 状态，自动超时转为 failed
⚡ 单次TransferRecord实例的并发传输互斥；多个TransferRecord实例之间通过 max_concurrent_transfers 信号量控制并发上限，超限时请求排队等待
跨服务规则
密钥管理服务返回的解密SSH私钥仅限本次传输使用，传输完成后必须在内存中立即清除，不允许缓存或复用
部署引擎服务调用本服务前应确保目标服务器SSH端口已开放且密钥已正确绑定到目标环境
文件传输服务不感知部署版本和目录结构，remote_path 由部署引擎服务构造（含版本号标识），本服务仅执行文件推送

接口定义 (1)

POST/api/transfer/upload文件传输 API（内部）
内部接口，将文件通过SCP传输到远程服务器。由部署引擎服务调用，传输连接参数（host、port、login_user、key_id）由调用方从对应环境的配置中获取后传入
参数类型描述
hoststring远程服务器IP地址或主机名
portintSSH端口号，范围1-65535
login_userstringSSH登录用户名
key_iduuidSSH密钥ID，用于从密钥管理服务获取解密后的私钥进行SCP认证
local_pathstring本地待传输文件的绝对路径（文件传输服务所在节点的文件系统路径）
remote_pathstring远程服务器目标绝对路径，包含目标文件名
Response 200
字段类型
successbool
transferred_bytesint
elapsed_msint
错误码
状态码说明
400请求参数校验失败，如port超出范围、路径格式不合法、key_id非UUID格式
401SSH密钥认证失败，密钥无效或与目标服务器不匹配
404本地文件不存在或无法读取
408SCP传输超时，连接建立或数据传输超过scp_timeout_seconds配置
502密钥管理服务调用失败，无法获取SSH私钥
503远程服务器连接失败，主机不可达或端口未开放
⚠️

错误处理

处理策略

所有错误统一返回标准JSON错误响应。参数校验错误在请求入口层拦截；SSH认证/连接/传输错误按类型分类映射为对应HTTP状态码；密钥获取失败向上游透传502；重试逻辑在服务内部自动执行（最多max_retries次），超出后返回最后一次错误

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
4xx
客户端错误
参数校验失败、密钥认证失败、文件不存在等请求方错误，调用方需修正后重试
502
上游服务错误
对密钥管理服务的内部调用失败，由服务自动重试，重试耗尽后向上游报502
503
远程连接错误
目标服务器SSH端口不可达、连接被拒绝、DNS解析失败等，建议调用方检查目标服务器状态
504
传输超时
SCP数据传输超过配置的超时时间，可能原因包括大文件或网络带宽不足，调用方可根据transferred_bytes判断是否需断点续传
