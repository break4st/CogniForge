概述

ScriptManager
🖥️ 前端
运维人员编写、管理启动/停止脚本模板，并对目标环境远程执行这些脚本的前端界面。
依赖: EnvironmentManagerKeyManagerAPIGateway
React 18Ant DesignFastAPI WebSocket
基于: PRD prd-current v1 · SAD sad-001 v1
📐 模块边界
范围内: 脚本模板的创建、查看、编辑、删除 将模板与主机关联并远程执行启动/停止脚本 实时展示脚本执行标准输出/错误输出 提供执行过程中的状态指示
范围外: 主机/环境信息的维护 SSH 密钥的配置与管理 长期执行历史的存储与展示 用户认证与授权逻辑
拥有组件: CMP-001
🧩

ScriptExecutePage/scripts/:id/execute

选择目标主机并执行脚本，实时查看输出

State
template: ScriptTemplate | nullhosts: HostInfo[]selectedHostId: string | nullsession: ExecutionSession | nulloutput: stringexecuting: boolean
行为
  • 挂载时获取模板详情 GET /api/script-templates/:id
  • 获取主机列表 GET /api/hosts
  • 用户选择主机后点击执行按钮，调用 POST /api/execute-script
  • 获取 sessionId 后建立 WebSocket 连接 ws://<gateway>/ws/script-output/{sessionId}
  • 接收 onmessage 事件追加输出文本
  • 提供「中止执行」按钮，调用 POST /api/abort-execution
边界情况
  • ⚠️ 模板不存在（404）时提示并禁用执行
  • ⚠️ 主机列表加载失败时提示用户检查环境模块
  • ⚠️ WebSocket 连接失败时重试 3 次，均失败则提示用户手动刷新
  • ⚠️ 用户离开页面时弹出确认框「执行仍在进行，离开将断开连接」
  • ⚠️ 输出过大时采用虚拟滚动渲染

交互流程 (2)

创建并执行一个启动脚本

用户新建一个启动脚本模板，然后立即执行

1
步骤1: 用户从导航进入「脚本管理」路径 /scripts，列表为空
2
步骤2: 点击「新建脚本」跳转至 /scripts/new
3
步骤3: 输入名称「启动 Tomcat」，选择类型「启动」，填写脚本内容，保存
4
步骤4: 返回列表页 /scripts，新脚本出现，点击其「执行」按钮
5
步骤5: 页面跳转至 /scripts/:id/execute，显示模板详情和主机选择器
6
步骤6: 用户选择一个主机，点击「执行启动」，页面显示「连接中...」
7
步骤7: 输出面板开始滚动显示远程脚本的输出
8
步骤8: 脚本执行完毕，面板底部显示「执行成功」，用户可重新执行或返回列表
编辑现有脚本并测试

用户修改已有停止脚本并执行测试

1
步骤1: 在列表页点击某个停止脚本的「编辑」，跳转至 /scripts/:id/edit
2
步骤2: 表单预填充原有内容，用户修改脚本内容后保存
3
步骤3: 返回列表页后点击同一脚本的「执行」
4
步骤4: 选择主机，执行修改后的脚本，观察输出

编排流程

脚本执行前端流程

用户选择模板和目标主机，发起执行并通过 WebSocket 接收实时输出

1
进入执行页
从列表页跳转至 /scripts/:id/execute，获取模板详情和主机列表
失败处理: 获取失败提示错误，禁用执行操作
2
发起执行 (10s 超时)
用户选择主机并点击执行按钮，调用 POST /api/execute-script
失败处理: 展示错误信息，重置按钮状态
3
建立 WebSocket (5s 超时)
获取 sessionId 后连接 ws://<gateway>/ws/script-output/{sessionId}
失败处理: 重试 3 次，每次间隔 2 秒，全部失败则提示用户手动刷新
4
接收输出
WebSocket onmessage 事件追加输出文本，onclose 判断结束状态
失败处理: 连接异常关闭时若会话状态仍为 running，则自动重试连接
重试策略: 最多 3 次，间隔 2s
可重试错误: NETWORK_ERROR, TIMEOUT
不可重试错误: AUTH_ERROR, CONFIG_ERROR

错误处理

处理策略

axios 拦截器捕获 HTTP 错误，统一展示 message.error；WebSocket 异常在输出面板提示并尝试重连。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
4xx
客户端错误
用户操作错误（如模板不存在、参数非法），提示具体原因。
5xx
服务器错误
服务器内部错误，提示「服务暂时不可用，请稍后重试」。
Network Error
网络错误
网络连接异常，提示「网络连接异常，请检查网络」，WebSocket 连接失败自动重试最多 3 次。
