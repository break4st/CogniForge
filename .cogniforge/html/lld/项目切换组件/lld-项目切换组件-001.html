概述

项目切换组件
🖥️ 前端
全局导航组件，始终显示项目列表，点击切换后触发上下文更新。
依赖: ProjectService全局上下文（AppContext）
ReactAnt DesignElectron IPC
基于: PRD prd-current v1 · SAD sad-001 v1
📐 模块边界
范围内: 渲染项目列表 切换事件触发 高亮当前项目 加载状态与错误处理 与全局上下文同步选中项
范围外: 项目的创建、编辑、删除 项目详情展示 用户权限校验

消费契约: CTR-001

组件树 (1)

ProjectSwitcher/ (嵌入 MainLayout 顶部栏)

全局项目选择器，展示项目列表，支持切换并同步全局上下文。

Events
@onProjectChange(string (projectId))
State
projectList: Project[]loading: booleanerror: string | null
行为
  • mount 时自动请求 IPC: project:list
  • loading 为 true 时，Select 禁用并显示加载图标
  • error 存在时，Select 旁显示错误提示和重试按钮
  • 选中值变化时，若与当前上下文 projectId 不同，则调用上下文 setCurrentProjectId
边界情况
  • ⚠️ 项目列表为空：展示 Ant Empty 组件，提示「暂无项目，请先创建」
  • ⚠️ 请求失败：展示重试按钮，点击后重新加载
  • ⚠️ 当前选中的项目从列表中消失（被删除）：自动清空选中项，提示用户重选
  • ⚠️ 快速连续切换：使用 useEffect 依赖 currentProjectId 进行防抖，避免冗余请求
SelectAnt Design Select

展示项目下拉列表的 UI 组件

状态设计

全局状态
currentProjectId
全局当前选中的项目 ID，由 AppContext 提供，多个页面和组件依赖此值
string | null
ProjectSwitcher environmentPage deploymentPage deploymentHistoryPage
缓存策略

项目列表数据在组件挂载时获取，缓存在组件内部 state。当外部增删项目时，通过全局事件总线发送 'refreshProjects' 事件，组件监听该事件重新请求列表。不设置自动轮询或过期策略。

交互流程 (3)

正常切换项目

用户选择另一个项目，全局上下文更新，相关页面刷新数据

1
步骤1: 用户点击项目选择器下拉
2
步骤2: 列表展示所有已有项目（从 IPC 获取）
3
步骤3: 用户点击「生产环境项目」
4
步骤4: 组件高亮选中项，调用 context.setCurrentProjectId('prod-id')
5
步骤5: 环境配置页面监听到 projectId 变化，重新请求环境列表
无项目时的创建引导

列表为空时提供创建项目的引导入口

1
步骤1: 页面加载，IPC 返回空数组
2
步骤2: Select 显示占位文本「暂无项目，请先创建」
3
步骤3: 用户点击占位文本旁的「创建项目」链接（或按钮）
4
步骤4: 跳转到项目管理页面（由外部路由处理）
5
步骤5: 创建成功后，项目管理页发送 'refreshProjects' 事件
6
步骤6: ProjectSwitcher 监听到事件，重新请求列表，新项目自动高亮
加载失败后重试

IPC 调用失败，用户手动重试并成功

1
步骤1: 组件挂载，IPC 调用返回错误
2
步骤2: 组件显示错误信息及「重试」按钮
3
步骤3: 用户点击「重试」
4
步骤4: 重新发起 IPC 请求，成功后加载列表

编排流程

项目切换与列表加载流程

组件挂载时请求项目列表，用户选择后触发上下文更新，并处理异常与重试。

1
组件挂载与初始化 (10s 超时)
useEffect 调用 IPC: project:list，设置 loading=true，error=null。
失败处理: 设置 error 状态，结束 loading
2
接收项目列表
将返回的 projects 存入 state，loading=false；若无数据则展示空状态。
失败处理: 无单独失败处理，依赖前一步错误捕获
3
默认选中当前项目
从全局上下文读取 currentProjectId，若存在且列表中包含，则设为选中。
失败处理: 若不存在则无需选中
4
用户切换项目
用户点击 Select 的 Option，检查 value 是否变化。若变化，调用上下文 setCurrentProjectId。
失败处理: 静默失败，上下文方法可能同步更新，记录警告
5
错误重试 (10s 超时)
当 error 不为空时，用户点击 Retry 按钮，重置 error 并重新执行步骤 1。
失败处理: 再次进入错误状态
重试策略: 最多 3 次，间隔 5s
可重试错误: NETWORK_ERROR, TIMEOUT, INTERNAL_ERROR
不可重试错误: AUTH_ERROR

通过 Electron IPC 获取所有项目列表，封装为内部调用，匹配契约 CTR-001
Response 200
字段类型
projectsProject[]
错误码
状态码说明
INTERNAL_ERROR服务端未预期错误，请稍后重试
NETWORK_ERRORIPC 通信超时或连接断开
AUTH_ERROR未授权，需要重新登录

错误处理

处理策略

IPC 调用失败时，组件进入错误状态，展示错误提示并允许手动重试；空列表不视为错误，展示占位引导。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
4xx
网络/连接类错误
IPC 超时、断开连接，提示用户检查主进程状态，提供重试按钮。
5xx
服务端内部错误
主进程抛出未预期异常，显示通用错误信息，记录日志。
401
认证错误
若项目服务要求鉴权且失效，则清空项目列表并引导重新登录。
EMPTY_LIST
空列表
成功返回但 projects 为空，展示「暂无项目」引导。
