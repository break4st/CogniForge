概述

模块: Project Management Service
项目管理服务，负责部署项目的全生命周期管理，包括项目的创建、查询、编辑、删除，项目下关联环境的管理，以及项目维度的权限控制。作为部署系统的核心业务入口，为上层 API Gateway 提供项目 CRUD 接口，所有写操作同步调用 Audit Service 记录审计日志。
依赖: Audit Service
GoGin / Go-ZeroPostgreSQL 15+Redis 7+

错误处理

所有接口统一返回 JSON 格式错误：{ code: int, message: string }。400 参数校验失败、404 资源不存在、409 资源冲突、500 服务内部错误。所有写操作（创建/删除/编辑）在业务事务内同步调用 Audit Service 的 POST /api/audit/logs 记录审计日志（action 区分 create/delete/update，resource_type 固定为 project），若审计日志写入失败则回滚业务事务并返回 500，确保业务操作与审计记录的原子一致性。分页参数在接口层校验，越界时直接返回 400 而非截断处理。数据库写操作统一使用事务，任一 SQL 步骤失败即回滚。Redis 缓存用于项目列表查询加速，缓存键格式 projects:list:{status}:{keyword_hash}:{page}:{page_size}，写操作后采用 Write-Through 策略主动失效或刷新相关缓存条目。
