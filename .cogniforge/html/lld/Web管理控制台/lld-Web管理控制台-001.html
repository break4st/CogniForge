概述

模块: Web管理控制台

基于SPA的浏览器端管理界面，提供项目管理、环境配置、部署触发、日志查看等交互功能。前端采用 SPA 架构，通过 REST API 与后端服务交互，使用 WebSocket 实现部署日志实时推送。整个控制台围绕「项目 → 环境 → 部署」三层模型组织页面结构。

接口定义 (9)

PageProjectList

/

项目列表首页。渲染所有项目的表格/卡片列表，提供创建项目入口和项目搜索/分页。调用 ListProjects 接口加载数据。

参数类型描述
pagenumber页码，默认 1
page_sizenumber每页条数，默认 20

PageCreateProject

/projects/new

创建项目表单页。收集项目名称和描述，提交时调用 CreateProject 接口。创建成功后跳转至项目详情页。

参数类型描述
namestring项目名称（必填）
descriptionstring项目描述（选填）

PageProjectDetail

/projects/:projectId

项目详情页。展示项目基本信息、环境列表、部署历史。提供环境管理入口和触发部署入口。

参数类型描述
projectIdnumber项目 ID（路径参数）

PageEnvironmentList

/projects/:projectId/environments

环境管理列表页。展示指定项目的所有部署环境，提供新建环境和配置 SSH 密钥的入口。

参数类型描述
projectIdnumber项目 ID（路径参数）

PageCreateEnvironment

/projects/:projectId/environments/new

新建环境表单页。收集服务器连接参数，提交时调用 CreateEnvironment 接口。创建成功后可选跳转至 SSH 密钥配置。

参数类型描述
projectIdnumber项目 ID（路径参数）
namestring环境名称（必填）
tagstring环境标签（必填）
server_hoststring服务器地址（必填）
server_portnumberSSH 端口（必填，默认 22）
usernamestringSSH 用户名（必填）

PageConfigureSSHKey

/projects/:projectId/environments/:envId/ssh-key

SSH 密钥配置页。上传私钥文件或粘贴私钥内容，可选填写口令。提交时调用 ConfigureSSHKey 接口。

参数类型描述
projectIdnumber项目 ID（路径参数）
envIdnumber环境 ID（路径参数）

PageTriggerDeployment

/projects/:projectId/deployments/new

触发部署页。选择目标环境、填写可执行文件路径和版本号，提交时调用 TriggerDeployment 接口。

参数类型描述
projectIdnumber项目 ID（路径参数）
environment_idnumber目标环境 ID（必填）
artifact_pathstring可执行文件路径（必填）
versionstring版本号（必填）

PageDeploymentDetail

/projects/:projectId/deployments/:depId

部署详情页。展示部署状态和实时日志。页面加载时通过 GetDeploymentLogs 轮询或 WebSocket 接收日志，部署完成后展示最终结果。

参数类型描述
projectIdnumber项目 ID（路径参数）
depIdnumber部署记录 ID（路径参数）

LayoutSidebar

/_layout/sidebar

全局侧边栏导航组件。从 ListProjects 加载项目列表，支持项目间切换。点击项目名称导航至该项目详情页。当前选中项目高亮显示。

参数类型描述
activeProjectIdnumber当前选中项目 ID

错误处理

统一错误处理策略： 1. API 错误：所有 HTTP 请求通过统一的封装层发起，非 2xx/3xx 响应统一捕获后解包错误体 { code, message }，通过全局 Store 按页面维度记录错误信息，页面组件从 Store 读取并展示错误提示。 2. 网络异常：请求超时或断网时捕获网络错误，展示「网络连接异常，请检查网络后重试」的 Toast 提示，不影响其他页面状态。 3. 表单校验：前端在提交前对必填字段、格式（端口号范围、版本号格式）进行校验，校验失败时对应字段下方展示红色提示文字，不发起请求。 4. WebSocket 异常：连接断开时自动重连（指数退避，最大间隔 30s），重连期间展示「连接断开，正在重连...」提示条；重连成功后自动恢复日志显示。 5. 部署失败：部署状态变为 failure 时，在部署详情页以红色横幅展示失败原因，同时标记部署记录状态为失败，日志区保留最终日志供排查。 6. 空状态处理：列表无数据时展示空状态占位图与引导文案（如「暂无项目，点击创建」），避免页面空白。 7. 全局兜底：未捕获异常通过 window.onerror 捕获并上报，同时在页面顶部展示全局错误条「系统异常，请刷新页面重试」。
