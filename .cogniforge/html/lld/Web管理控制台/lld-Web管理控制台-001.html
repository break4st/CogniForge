概述

模块: Web管理控制台
用户交互界面，提供项目管理、环境配置、部署操作和状态查看等功能。作为系统的展示层，通过API网关与后端业务服务通信，并通过WebSocket接收实时部署进度推送。采用前后端分离的单页应用架构。
依赖: API网关文件存储部署编排服务
Vue 3TypeScriptPinia（状态管理）Vue RouterWebSocketSCSS

错误处理

前端统一错误处理策略：1）所有API请求通过axios拦截器统一捕获HTTP错误，4xx错误展示用户友好的提示消息，5xx错误展示'服务器异常，请稍后重试'；2）网络断连时展示断网提示条，自动重连后恢复；3）表单提交前进行字段校验（必填项、格式、范围），校验不通过时在表单项旁展示具体错误文案；4）WebSocket连接异常时自动重连，指数退避（1s/2s/4s/8s，最大30s），重连期间展示'连接中...'状态提示；5）文件上传进度条展示实时上传百分比，上传失败保留已填表单数据并提供重新上传按钮；6）全局错误边界（ErrorBoundary）捕获未预期组件异常，避免白屏，展示'页面出错了，请刷新重试'。
