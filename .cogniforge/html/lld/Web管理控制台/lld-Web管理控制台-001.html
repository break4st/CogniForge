概述

Web管理控制台
🖥️ 前端
用户交互界面，提供项目管理、环境配置、部署操作的可视化操作面板，采用 Vue 3 SPA 架构。用户通过浏览器访问，所有请求通过 API 网关转发至后端业务服务。实时日志通过 WebSocket 从部署引擎服务推送至前端。
依赖: API网关
Vue 3Element PlusRESTWebSocketJWT

DeployLogViewercomponents/DeployLogViewer.vue

实时日志查看器，通过 WebSocket 接收并展示部署日志

Props
deploymentId: uuid *
State
logs: string[]connected: booleanautoScroll: booleanreconnectTimes: intdeployFinished: boolean
行为
  • prop deploymentId 变化时关闭旧连接并建立新 WebSocket 连接：WS /ws/deployments/{id}/logs
  • 连接成功后设置 connected=true 并在顶部展示绿色「已连接」状态徽标
  • 收到消息时追加到 logs 数组，autoScroll=true 时自动滚动到底部
  • autoScroll 默认为 true，用户手动向上滚动时暂停自动滚动
  • 用户点击「回到底部」按钮恢复自动滚动
  • 连接断开时自动重连，指数退避 1s/2s/4s/8s，最大 30s
  • 部署结束时（收到特定消息标识）关闭 WebSocket 连接并标记 deployFinished=true
边界情况
  • ⚠️ 日志缓冲区上限 5000 行，超出时丢弃最旧的行并提示「日志过长，已截断」
  • ⚠️ WebSocket 连接异常关闭（非正常关闭码 1000）时立即尝试重连
  • ⚠️ 重连超过 5 次后停止自动重连，展示「连接已断开，请手动刷新」按钮
  • ⚠️ 组件卸载（unmount）时主动关闭 WebSocket 连接防止内存泄漏
  • ⚠️ 用户关闭页面/路由跳转时未完成的部署仍继续执行，但前端不再接收日志

状态设计

全局状态
useAuthStore
认证状态：token、用户名、角色、权限列表。存储在 Pinia store 中，token 同时持久化到 localStorage
AuthState
App Navbar Sidebar DefaultLayout
useAppStore
应用级 UI 状态：侧边栏折叠状态。不持久化，刷新恢复默认
AppState
DefaultLayout Sidebar
缓存策略

项目列表缓存 5 分钟，切换路由不主动刷新，返回时若未过期直接展示缓存。环境列表缓存 5 分钟。SSH 密钥列表缓存 5 分钟。部署历史不做缓存，每次进入页面重新请求。审计日志不做缓存，每次查询按条件实时请求。部署状态（正在运行的部署）每 10 秒轮询刷新或通过 WebSocket 实时推送。所有缓存使用 sessionStorage 而非 localStorage，浏览器标签页关闭即失效。

交互流程 (5)

一键部署流程

从选择项目和环境开始，到实时查看部署日志的完整部署体验

1
用户点击左侧导航「一键部署」进入 DeployPage
2
系统 mount 时加载项目列表和可选环境列表填充下拉选择器
3
用户选择目标项目，系统自动过滤展示该项目绑定的环境列表
4
用户选择目标环境
5
用户填写待部署文件的下载 URL（以 http/https 开头）
6
用户编写或粘贴部署执行脚本（shell 命令序列）
7
用户点击「开始部署」按钮
8
系统校验表单必填字段，通过后调用 POST /api/deployments
9
后端返回 202 包含 deployment_id 和 version
10
系统展示部署标识信息（版本号、任务 ID）并展开 DeployLogViewer
11
DeployLogViewer 自动建立 WebSocket 连接至 WS /ws/deployments/{id}/logs
12
连接成功后日志区域开始实时滚动展示部署执行日志
13
部署完成（收到完成标识或 WebSocket 连接关闭），日志区域展示最终状态
14
用户可选择点击「部署历史」查看该条部署的完整信息

错误处理

处理策略

前端通过 Axios 拦截器统一捕获 HTTP 错误，根据状态码分类处理：4xx 展示用户可理解的错误提示，5xx 展示服务不可用提示并引导重试。WebSocket 断线自动重连，重连间隔指数退避（1s/2s/4s/8s，最大 30s）。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
400
请求参数错误
表单校验未通过或参数非法，在表单字段旁展示具体错误信息
401
未授权
JWT token 过期或无效，清除本地 token 并重定向至登录页
403
权限不足
当前用户无操作权限，展示「无权限」提示弹窗
404
资源不存在
请求的资源不存在或已被删除，展示空状态占位图
409
资源冲突
创建/更新操作与其他资源冲突，展示冲突详情
422
表单校验错误
提交的数据校验失败，在表单字段下方展示具体错误信息
500
服务器内部错误
后端服务异常，展示「服务暂时不可用，请稍后重试」全局提示
502
网关错误
API 网关不可达或超时，展示「网络连接异常」提示
0
WebSocket 断线
实时日志连接断开，自动尝试重连并在界面展示「重新连接中…」状态
