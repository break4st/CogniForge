概述

Web管理控制台
基于React 18的SPA应用，使用Ant Design 5.x组件库构建，提供项目管理、部署环境配置、SSH密钥管理、一键部署触发与进度展示、部署历史查看、审计日志查询等可视化界面。通过WebSocket实时接收部署进度推送，采用组件化路由架构按业务域划分页面模块。
依赖: API网关项目管理服务环境管理服务密钥管理服务部署编排服务审计服务
React 18Ant Design 5.x

错误处理

处理策略

前端通过统一的HTTP响应拦截器捕获所有API错误，按HTTP状态码分类处理：4xx错误在UI中展示Ant Design Message组件提示用户可理解的错误信息；5xx错误展示「服务暂不可用，请稍后重试」；网络异常展示断网提示并支持恢复后自动刷新。表单级校验由Ant Design Form组件在客户端侧即时校验必填字段和格式，避免无效请求发送到后端。WebSocket连接采用指数退避重连策略，断连期间在页面上方展示连接状态提示条。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
400
请求参数错误
前端表单提交前已进行Ant Design表单校验，后端返回400时在前端Message.error中展示具体错误信息
401
认证失败
用户未登录或JWT令牌过期，前端全局拦截器检测到401后跳转至登录页或触发令牌刷新
403
权限不足
当前用户无权限执行操作，前端展示无权限提示并禁用对应操作入口按钮
404
资源不存在
请求的目标资源不存在，页面加载时检测到404后展示Ant Design Empty空态或Result组件的404提示
409
资源冲突
创建资源时与已有资源冲突，在前端Message.warning中展示具体冲突原因
5xx
服务端错误
后端服务异常，前端统一展示「服务暂不可用，请稍后重试」，不暴露后端错误详情
WS
WebSocket连接异常
WebSocket连接断开或连接失败，前端自动采用指数退避策略重连（1s / 2s / 4s / 8s / 16s 最大30s），重连期间在页面顶部展示黄色提示条，重连成功后自动隐藏并重新同步进度数据
NETWORK
网络异常
浏览器请求超时或网络断开，前端监听window.online/offline事件，断网时展示全屏遮罩提示，网络恢复后自动刷新当前页面数据
