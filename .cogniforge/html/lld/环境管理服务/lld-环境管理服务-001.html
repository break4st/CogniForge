概述

环境管理服务
⚙️ 业务服务
环境管理服务负责目标服务器连接信息的CRUD，协调密钥服务与部署引擎，保证环境配置的唯一性与安全性。
依赖: 密钥管理服务SSH连接管理器部署引擎
Python 3.11+FastAPISQLAlchemySQLiteasyncio
基于: PRD prd-current v1 · SAD sad-001 v1
📐 模块边界
范围内: 环境的创建、查询列表、按ID查询、更新、删除 创建/更新时对关联密钥的校验 删除前检查环境是否被部署引用 提供测试SSH连接端点
范围外: 密钥本身的增删改查 部署记录的创建与状态流转 实际SSH握手指令执行 项目本身的CRUD
拥有组件: CMP-004
实现契约: CTR-002
消费契约: CTR-011 CTR-012
