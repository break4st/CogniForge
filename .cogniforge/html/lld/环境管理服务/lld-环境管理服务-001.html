概述

模块: 环境管理服务
环境管理服务负责管理部署环境的完整生命周期，提供部署环境的创建、编辑、删除等CRUD操作，SSH密钥信息的AES-256-GCM加密存储与安全管理，远程服务器连接测试，以及环境与项目的关联管理功能。作为部署编排服务的下游依赖，为其提供目标环境的连接配置信息。
依赖: 关系型数据库（MySQL）SSH执行服务
Java 17Spring Boot 3Spring Data JPAMySQL 8AES-256-GCM（SSH密钥加密）REST (JSON)

错误处理

环境管理服务采用分层错误处理策略：1）参数校验层——创建和更新接口对请求参数进行非空校验、类型校验和枚举值校验（环境类型仅允许test/staging/production、连接状态仅允许unknown/connected/disconnected），校验失败统一返回400 Bad Request，响应体包含field和message指明具体问题；2）业务逻辑层——环境名称唯一性通过项目ID+名称的联合唯一索引保障，违反时返回409 Conflict并提示'同一项目下已存在同名环境'；创建环境时通过project_id外键校验项目是否存在，不存在时返回404 Not Found；删除环境前查询部署编排服务确认无关联部署记录，有关联时返回409 Conflict；3）数据安全层——SSH密钥在持久化前使用AES-256-GCM算法加密，密钥加密密钥（KEK）由系统配置管理，加密后的密文以Base64编码存入数据库；所有查询接口的响应中均不返回ssh_key_encrypted字段，防止密钥泄露；4）跨服务调用层——连接测试接口同步调用SSH执行服务的连接测试接口，设置5秒超时，调用失败或超时返回502 Bad Gateway并记录下游服务错误；5）全局异常处理——所有未捕获异常统一返回500 Internal Server Error，服务端记录完整错误堆栈。所有错误响应统一采用格式：{"error": {"code": "string错误码", "message": "string错误描述"}}。
