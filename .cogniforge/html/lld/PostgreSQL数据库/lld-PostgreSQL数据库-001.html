概述

PostgreSQL数据库
系统的主数据库，存储项目、环境、部署记录、密钥、用户及权限等所有结构化业务数据。采用 PostgreSQL 关系型数据库，通过 SQLAlchemy ORM 为上层服务提供统一的数据访问层，保障事务性数据的一致性和完整性，支持历史数据的查询与归档。

错误处理

处理策略

数据库层错误统一由 SQLAlchemy ORM 捕获并转化为业务异常，按错误类别分别处理：连接错误触发重试和告警，约束违规返回明确的业务错误码，死锁和序列化冲突自动重试最多 3 次。各服务层通过 try-except 捕获 ORM 异常后转换为标准 API 错误返回。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
08000
连接异常
数据库连接失败或超时，触发连接池重试并记录告警日志
23000
约束违规
唯一约束、非空约束等完整性约束违反，返回冲突字段信息给调用方
23503
外键违规
引用的外键记录不存在，返回关联资源缺失信息
40001
序列化冲突
可序列化隔离级别下的并发写入冲突，自动重试事务
40P01

检测到死锁，自动回滚并重试事务，最多 3 次
22000

JSONB、数组等特殊类型的数据格式校验失败
57014
