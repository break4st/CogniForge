概述

EnvironmentManager
🖥️ 前端
环境管理界面，展示项目下的所有环境卡片，提供增删改查、测试连接功能。用户可通过表单配置环境连接信息并上传私钥。
依赖: EnvironmentService（CMP-012）提供环境CRUD接口KeyManagementService（CMP-013）提供密钥上传接口更新接口（PUT /api/environments/{id}）和删除接口（DELETE /api/environments/{id}）待后端补充
React 18Ant Design
基于: PRD prd-current v1 · SAD sad-001 v1
📐 模块边界
范围内: 展示指定项目的环境卡片列表（名称、IP、端口、认证类型、密钥指纹、最后测试状态） 提供新建环境表单（含密钥上传/密码输入） 提供编辑环境功能（复用表单，支持密钥更新） 提供测试连接功能（弹窗展示OS信息和状态） 提供删除环境功能（二次确认） 支持拖拽/点击选择私钥文件上传并展示指纹
范围外: 后端SSH连接测试逻辑 私钥加密存储细节 部署执行流程 项目管理、脚本管理等其他模块功能
消费契约: CTR-005 CTR-006 CTR-007 CTR-008

组件树 (1)

EnvironmentManagerPage/projects/:projectId/environments

环境管理主页面，负责加载列表、管理弹窗状态、分发操作

State
environments: Environment[]loading: booleanerror: string | nullformVisible: booleaneditingEnv: Environment | nulltestResultModal: { visible: boolean, envId: number, result: TestResult | null, error: string | null }
行为
  • 挂载时调用 GET /api/projects/{projectId}/environments 获取列表
  • 新建按钮点击：设置 formVisible=true，editingEnv=null
  • 编辑按钮点击：设置 formVisible=true，editingEnv=当前环境
  • 删除按钮点击：弹出 Popconfirm 确认后调用 DELETE /api/environments/{id}（待后端实现），成功刷新列表
  • 测试按钮点击：设置 testResultModal.visible=true，envId 为环境ID，调用 POST /api/environments/{id}/test-connection，根据结果更新 result 或 error
  • 表单提交回调：调用创建或更新接口（更新接口待后端实现），成功后关闭弹窗并刷新列表
边界情况
  • ⚠️ 列表加载失败：显示错误信息和重试按钮
  • ⚠️ 空列表：显示 Ant Design Empty 组件和新建按钮
  • ⚠️ 删除失败：弹出错误提示，列表保持不变
  • ⚠️ 测试连接超时：显示连接超时提示

EnvironmentFormModal页面内条件渲染

新建或编辑环境的表单弹窗

Props
visible: boolean *editingEnv: Environment | null *onClose: () => void *onSubmit: (values: FormData) => void *
State
uploadingKey: booleankeyFingerprint: string | nullselectedFile: File | null
行为
  • 根据 editingEnv 设置标题和表单初始值
  • 表单包含：name, ip, port（默认22）, authType（Select：password/key）, deployRootPath
  • authType 为 key 时显示 KeyUploader 子组件，否则显示 password 输入框
  • 编辑模式下显示已有指纹并提供「更新密钥」按钮
  • 提交时校验所有必填项，组装 FormData（包含文件）调用 onSubmit
边界情况
  • ⚠️ 端口号范围校验（1-65535），IP 格式校验
  • ⚠️ 密钥上传失败时提示错误，不阻塞表单提交（可改用密码）
  • ⚠️ 编辑环境下更新密钥成功后更新本地指纹显示
KeyUploaderEnvironmentFormModal 的子组件

拖拽/点击上传私钥文件，返回指纹

Props
environmentId: number | nullonFileSelected: (file: File) => voidonUploadSuccess: (fingerprint: string) => voidonUploadError: (error: string) => void
State
uploading: booleanerror: string | null
行为
  • 使用 Ant Design 的 Upload.Dragger 组件，限制文件类型为 .pem/.key 等
  • 编辑模式下选择文件后自动调用 POST /api/environments/{environmentId}/key 上传，成功后回调 onUploadSuccess
  • 新建模式下选择文件后调用 onFileSelected 将 File 对象传给父组件，由父组件在表单提交时一并处理
边界情况
  • ⚠️ 文件大小限制 16KB，格式校验
  • ⚠️ 上传超时：显示超时提示，允许重试

交互流程 (5)

环境列表加载流程

进入页面后自动加载指定项目的环境列表

1
用户通过导航或路由进入 /projects/:projectId/environments
2
页面组件挂载，useEffect 调用 GET /api/projects/{projectId}/environments
3
显示 loading 状态
4
成功：渲染 EnvironmentCard 列表
5
失败：显示错误信息与重试按钮
新建环境流程（含密钥）

用户打开新建弹窗填写信息并可能上传私钥

1
点击「新建环境」按钮，打开空白表单弹窗
2
用户填写名称、IP、端口、认证方式、部署根路径；若选密钥认证则通过 KeyUploader 选择私钥文件
3
点击确定
4
前端组装 FormData（含文件），调用 POST /api/projects/{projectId}/environments
5
成功：获得新环境 id，关闭弹窗，提示成功，刷新列表
6
失败：显示错误信息，保留弹窗，用户可重试
编辑环境流程

用户编辑已有环境信息，可能更新密钥

1
在卡片上点击「编辑」按钮，传入环境对象
2
打开表单弹窗，预填现有数据
3
用户修改信息；如需更新密钥，点击「更新密钥」激活上传组件选择文件
4
点击确定，调用 PUT /api/environments/{id}（待后端实现）提交修改
5
若同时更新了密钥，在编辑提交前或后调用 POST /api/environments/{id}/key 上传新密钥
6
成功后关闭弹窗，刷新列表
测试连接流程

测试某个环境的 SSH 连接

1
在卡片上点击「测试连接」按钮
2
调用 POST /api/environments/{id}/test-connection
3
弹出结果弹窗，显示 loading
4
收到成功响应：显示 os_info 和 status，更新卡片上的最新测试状态
5
失败：显示错误信息与重试按钮
删除环境流程

用户删除一个环境

1
在卡片上点击「删除」按钮，弹出 Popconfirm 二次确认
2
确认后调用 DELETE /api/environments/{id}（待后端实现）
3
成功：提示已删除，从列表中移除
4
失败：提示错误信息

错误处理

处理策略

封装统一的请求函数，自动解析后端规范错误格式 { code, error, detail }，网络错误提示通用消息，业务错误根据场景使用 message.error 或表单字段错误提示。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
400
参数校验错误
表单字段格式校验失败，在对应字段下方显示错误消息，不关闭弹窗。
404
资源不存在
项目或环境ID不存在，弹出全局提示并可能重定向。
502
连接测试失败
在测试结果弹窗中展示具体原因，如认证失败、超时等。
500
服务器错误
全局提示「服务器繁忙」，保留当前状态让用户重试。
NETWORK
网络异常
提示「网络连接失败，请检查网络」，不阻塞功能。
