概述

模块: SSH执行代理

SSH执行代理是一个无REST接口的后台工作服务，通过AMQP消费部署编排服务投递至 deployment.tasks 主题的 DeploymentTaskMessage，在远程服务器上执行完整的部署操作。内部处理流程：1) 接收到任务消息后进行反序列化与参数校验；2) 使用消息中携带的服务器地址、端口、用户名、SSH私钥建立 SSH 安全连接；3) 在远程服务器创建版本文件夹（路径格式 /opt/deploy/{version}/）；4) 通过 SCP/SFTP 将 artifact_path 对应的可执行文件传输至远程版本文件夹；5) 自动生成启动脚本 start.sh（包含设置可执行权限、后台运行、输出重定向、PID 记录等逻辑）并写入远程服务器；6) 通过 SSH remote exec 执行启动脚本；7) 整个过程中边执行边通过 deployment.logs 主题回写 DeploymentLogMessage（type=log 实时日志行、type=status_change 状态变更），供部署编排服务消费后推送 WebSocket 及更新数据库。支持并行消费多个部署任务，每个任务独占一个 SSH 连接，任务完成后自动关闭连接。连接中断或执行失败时自动回写 ERROR 级别日志与 failure 状态，不阻塞其他任务。

接口定义 (2)

ConsumeDeploymentTask

INTERNAL (MQ consumer) — deployment.tasks

内部消费者，订阅消息队列 deployment.tasks 主题。接收部署编排服务投递的 DeploymentTaskMessage，执行完整的远程部署流程。处理步骤：1) 反序列化消息为 DeploymentTaskMessage；2) 发送 type=status_change status=running 至 deployment.logs 通知状态变更；3) 根据 server_host/server_port/username/ssh_private_key 建立 SSH 连接（超时15s）；4) 执行 mkdir -p /opt/deploy/{version} 创建版本文件夹；5) 通过 SFTP 将 artifact_path 文件传输至远程 /opt/deploy/{version}/；6) 远程写入 start.sh 启动脚本（包含 chmod +x、nohup 启动、PID 记录等）；7) 远程执行 chmod +x /opt/deploy/{version}/start.sh && /opt/deploy/{version}/start.sh；8) 校验进程启动状态（ps 检查）；9) 成功后发送 type=status_change status=success；10) 任一环节失败发送 type=status_change status=failure 及 error_message。每执行一个步骤前/后发送 type=log 报告进度。消息消费确认方式：步骤7执行完成（即脚本已启动）后手动 ack 消息。

参数类型描述
message:task_idstring任务唯一标识，用于幂等去重，重复的 task_id 直接 ack 丢弃
message:deployment_idinteger部署记录ID，日志和状态回写的关联键
message:project_idinteger项目ID，日志记录用
message:server_hoststring远程服务器地址
message:server_portintegerSSH端口
message:usernamestringSSH登录用户名
message:ssh_private_keystring解密后的SSH私钥内容
message:ssh_passphrasestring密钥口令
message:artifact_pathstring可执行文件路径
message:versionstring版本号

ReportDeploymentLog

INTERNAL (MQ producer) — deployment.logs

内部生产者，由 ConsumeDeploymentTask 流程中触发。在执行部署的各个阶段发送日志行和状态变更至 deployment.logs 主题。每次发送包含当前操作的日志行（INFO 级别报告进度、WARN 级别报告警告、ERROR 级别报告失败），以及在关键里程碑（开始执行、完成、失败）发送 status_change 消息。sequence 从0开始随每个 log 消息递增，保证日志有序性。发送失败时不影响部署执行（降级记录本地日志），但状态变更消息发送失败视为严重事件（可能导致前端无法感知部署完成，此时在本地重试至多3次）。

参数类型描述
message:typestring消息类型，log 或 status_change
message:deployment_idinteger部署记录ID
message:sequenceinteger日志行序号（type=log 时必填）
message:log_linestring日志行内容（type=log 时必填）
message:levelstring日志级别（type=log 时必填），INFO / WARN / ERROR
message:statusstring部署状态（type=status_change 时必填），running / success / failure
message:error_messagestring错误信息（type=status_change 且 status=failure 时必填）
message:timestampstring消息产生时间，ISO8601 格式
⚠️

错误处理

统一错误处理策略，所有异常捕获后通过 deployment.logs 回写 ERROR 日志和 failure 状态： 1. MQ消息反序列化失败：ConsumeDeploymentTask 接收的消息 JSON 格式错误或字段缺失，记录错误日志并 nack 消息（requeue=false 直接丢弃或投递死信队列），错误码 MSG_DESERIALIZE_FAILED。 2. MQ消费重试：消息处理抛出异常时 nack 并 requeue，最多重试3次，超过3次后投递死信队列人工排查，错误码 MSG_RETRY_EXCEEDED。 3. SSH连接失败：连接远程服务器时网络不可达、端口未开放或连接超时（15s），回写 ERROR 日志并发送 type=status_change status=failure error_message=SSH_CONNECTION_FAILED，释放连接资源，错误码 SSH_CONNECTION_FAILED。 4. SSH认证失败：私钥格式错误、用户名错误、密钥不匹配导致认证拒绝，回写 ERROR 日志（不暴露私钥内容）并发送 failure，错误码 SSH_AUTH_FAILED。 5. 版本文件夹创建失败：远程 mkdir 命令返回非0，磁盘空间不足或权限不足，回写 ERROR 日志并发送 failure 及错误输出内容，错误码 REMOTE_MKDIR_FAILED。 6. 文件传输失败：SFTP 上传时源文件不存在、传输中断或磁盘空间不足，回写 ERROR 日志并发送 failure，错误码 FILE_TRANSFER_FAILED。 7. 源文件不可读：artifact_path 指定的文件在本地不存在或无读取权限，回写 ERROR 日志并发送 failure，错误码 ARTIFACT_NOT_FOUND。 8. 启动脚本写入失败：远程 echo/cat 写入 start.sh 失败，回写 ERROR 日志并发送 failure，错误码 SCRIPT_WRITE_FAILED。 9. 启动脚本执行失败：远程执行 start.sh 返回非0退出码，回写 ERROR 日志并发送 failure 附带 stderr 内容，错误码 SCRIPT_EXEC_FAILED。 10. 进程启动确认失败：执行 start.sh 后等待2s通过 ps 检查不到目标进程，回写 WARN 日志（不判定为 failure，因部分应用启动较慢），发送 status=success 但附带 WARN 日志，错误码 PROCESS_START_WARN。 11. SSH会话超时：单次 SSH 命令执行超过 session_timeout(300s) 未返回，断开连接并发送 failure，错误码 SSH_SESSION_TIMEOUT。 12. SSH连接意外断开：执行命令过程中 SSH 连接被远程关闭或网络中断，尝试重连1次，重连失败则发送 failure，错误码 SSH_CONNECTION_LOST。 13. 日志发送失败：ReportDeploymentLog 发送至 MQ 时连接异常，降级处理（重试3次，间隔500ms），不影响主流程继续执行。status_change 消息发送失败时重试3次，仍失败则记录本地日志告警，错误码 LOG_SEND_FAILED。 14. 并发控制：同一 deployment_id 重复消费时通过 task_id 幂等去重（维护内存中的已处理 task_id 集合，定期清理过期记录），避免重复部署。 15. 优雅关闭：收到 SIGTERM 时停止消费新消息，等待正在执行的 SSH 任务完成（最多等待 30s），超时未完成的标记为 failure 后退出，防止部署任务悬空，错误码 SHUTDOWN_TIMEOUT。
