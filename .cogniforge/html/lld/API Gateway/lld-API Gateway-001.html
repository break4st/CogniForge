概述

模块: API Gateway

API Gateway 是系统的统一入口层，采用网关路由模式，所有客户端请求（来自 Web UI）统一经过 Gateway 进行路由转发。核心职责包括：1）请求路由——将外部 REST 请求转发至对应后端微服务（Student Service、Class Service、Grade Service、Statistics Service）的内部接口；2）身份认证——处理用户登录并签发 JWT Token，对受保护接口进行 Token 校验与角色鉴权；3）限流与访问控制——按用户角色（admin/teacher/student）控制接口访问权限；4）协议转换——统一请求/响应格式，将内部服务的数据拼装组合（如学生列表中的 class_name 从班级服务关联获取）后返回给前端。Gateway 本身不包含业务逻辑，所有业务处理委托给下游微服务。

接口定义 (22)

用户登录认证

POST /api/auth/login

用户登录认证接口，接收用户名、密码和角色，校验身份后签发 JWT Token 返回。Token 有效期通过 expires_in 字段指定，后续请求需在 Authorization Header 中携带 Bearer token。此接口为 Gateway 自身处理，不转发至下游服务。

参数类型描述
usernamestring用户名
passwordstring密码
rolestring角色枚举: admin|teacher|student

学生创建

POST /api/students

创建新的学生信息。Gateway 接收请求后校验 Token 和角色权限（仅 admin），将请求体透传转发至 Student Service 内部接口 POST /internal/students，响应原路返回。学号 student_no 全局唯一性校验由 Student Service 负责。

参数类型描述
namestring学生姓名，必填
student_nostring学号，全局唯一，必填
contact_phonestring联系电话，必填
contact_emailstring联系邮箱，必填
class_idnumber所属班级 ID，选填

学生更新

PUT /api/students/{id}

更新指定学生的信息。Gateway 校验权限后转发至 PUT /internal/students/{id}。仅可修改姓名、联系方式、班级等非学号字段。

参数类型描述
idnumber学生 ID，路径参数
namestring学生姓名，选填
contact_phonestring联系电话，选填
contact_emailstring联系邮箱，选填
class_idnumber所属班级 ID，选填

学生删除

DELETE /api/students/{id}

删除指定学生信息。Gateway 校验权限后转发至 DELETE /internal/students/{id}。仅 admin 角色可操作。

参数类型描述

学生列表查询

GET /api/students

按条件分页查询学生列表。Gateway 将查询参数透传转发至 GET /internal/students。响应结果中需要回填 class_name 字段，Gateway 根据 items 中的 class_id 批量调用 Class Service 内部接口 GET /internal/classes/{id} 获取班级名称后组装返回。支持姓名、学号、班级模糊匹配。

参数类型描述
namestring按姓名筛选，选填
student_nostring按学号筛选，选填
class_idnumber按班级筛选，选填
pagenumber页码，默认 1，选填
page_sizenumber每页条数，默认 20，选填

学生详情查询

GET /api/students/{id}

查询指定学生的详细信息。Gateway 转发至 GET /internal/students/{id}，根据返回的 class_id 调用 GET /internal/classes/{id} 回填 class_name 后返回。

参数类型描述
idnumber学生 ID，路径参数

学生分班

PUT /api/students/{id}/class

将学生分配到指定班级。Gateway 转发请求至 Student Service 内部接口 PUT /internal/students/{id}（更新 class_id），同时 Gateway 需先调用 Class Service 内部接口 GET /internal/classes/{id}/exists 校验班级存在性，若班级不存在则返回 404。

参数类型描述
idnumber学生 ID，路径参数
class_idnumber目标班级 ID

错误处理

API Gateway 作为统一入口，需在网关层统一处理以下异常场景：1）认证异常——请求未携带 Token 或 Token 过期/无效时，返回 401 Unauthorized，响应体为 {"error": "unauthorized", "message": "无效或过期的 Token"}；2）鉴权异常——Token 有效但角色无权限访问接口时，返回 403 Forbidden；3）参数校验异常——请求体缺少必填字段或字段格式非法时，返回 422 Unprocessable Entity，返回具体字段错误信息；4）资源不存在——下游服务返回 404 时，Gateway 透传返回 404，不擅自篡改错误信息；5）下游超时——调用后端微服务超过 10 秒未响应时，Gateway 熔断并返回 504 Gateway Timeout；6）下游不可用——后端服务返回 5xx 时，Gateway 统一返回 502 Bad Gateway，避免暴露内部错误详情；7）限流——单 IP 超过 QPS 阈值（暂定 100/s）时，返回 429 Too Many Requests；8）跨域——统一配置 CORS 头，允许 Web UI 所在域名的跨域请求。所有异常情况均需记录结构化日志，包含请求路径、方法、状态码、耗时和用户标识。
