概述

API Gateway
🔀 网关层
系统的统一入口网关，基于 Nginx + OpenResty 实现高性能反向代理与限流，内嵌 FastAPI 服务处理认证逻辑与 Token 管理。前端所有 REST API 请求统一经过 API Gateway 进行身份认证、访问控制、限流检测后转发至下游微服务，并对响应做统一格式封装与跨域处理。
依赖: Project Management ServiceEnvironment Management ServiceSSH Execution ServiceDeployment OrchestratorAudit ServiceKey Management ServiceRedisPrimary Database
Python 3.11+FastAPIasyncio + uvicornRedis 7Nginx + OpenResty

中间件链

Request → CORS (跨域检测与响应头注入)→CORS → AccessLog (请求日志记录)→AccessLog → Auth (JWT Token 校验与角色提取)→Auth → RateLimiter (全局/IP/用户三级限流检测)→RateLimiter → Router (路径匹配与上游转发)→Router → Upstream (upstream 服务代理转发)→Upstream → Response (响应结果统一封装与返回)

限流规则

全局 每 IP 100 req/s，全局 500 req/s（OpenResty lua-resty-limit-traffic 实现，计数器模式，超出返回 429）
每用户 每 user 1000 req/min（基于 user_id 从 JWT 中提取，Redis 滑动窗口计数器，超出返回 429）
端点限制
POST /api/v1/auth/login每 IP 10 req/min（防暴力破解，超出返回 429 + 60s 冷却）
POST /api/v1/environments/{id}/test每 user 30 req/min（连接测试资源消耗较大）
POST /api/v1/projects/{project_id}/deploy每 user 10 req/min（部署操作影响面广）
GET /api/v1/deployments/{deployment_id}/status每 user 60 req/min（轮询接口适当放宽）

错误处理

处理策略

网关层统一捕获所有请求异常，按照固定 JSON 格式返回错误响应。认证错误由网关自身直接拦截返回；业务错误由上游服务返回后网关原样透传；网关内部异常（限流、超时、上游不可达）由 OpenResty 返回标准错误码。

统一错误响应体
字段类型
codeinteger (HTTP 状态码)
errorstring (错误分类标识)
detailstring (详细错误信息)
400
参数校验错误
请求参数格式不合法或缺失必填字段，网关直接校验后拦截返回
401
未授权
缺少 Authorization header、token 过期、token 格式无效，网关认证中间件拦截
403
无权限
用户角色不满足接口要求的角色白名单，网关鉴权中间件拦截
404
资源不存在
上游服务返回资源不存在，网关原样透传
408
上游超时
网关向上游服务发起请求后超过配置超时时间（默认 30s）未收到响应
409
资源冲突
上游服务返回唯一性冲突或状态冲突，网关原样透传
422
请求体解析失败
请求体 JSON 格式错误或字段类型不匹配
429
请求过频
触发限流规则（全局/IP/用户级别任一阈值），网关限流中间件拦截
500
上游服务异常
上游微服务返回 5xx 错误，网关原样透传
502
上游服务不可达
网关无法连接到上游服务（服务宕机或网络不通）
503
网关过载
全局限流触发或网关内部资源耗尽
