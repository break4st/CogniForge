概述

模块: API Gateway
系统统一入口网关，负责请求路由、身份认证、限流和日志记录
依赖: Project Management ServiceEnvironment Management ServiceDeployment OrchestratorKey Management ServiceAudit Service
GoGin / Go-ZeroRedis 7+

配置定义 3

⚙️ UserAccount

用户账号配置，用于网关层身份认证

字段
字段名类型描述
id *string用户唯一标识
username *string用户名
password_hash *string密码哈希值

⚙️ RouteRule

路由规则配置，定义请求路径到后端服务的映射关系

字段
字段名类型描述
path_pattern *string路径匹配模式，如 /api/projects/*
methods *[]string允许的 HTTP 方法列表
target_service *string目标服务名称
target_path *string目标服务路径模板
require_auth *boolean是否需要认证
rate_limitinteger每秒最大请求数，0 表示不限

⚙️ RateLimitRule

限流规则配置，支持基于用户和 IP 的请求限流

字段
字段名类型描述
key *string限流键，格式为 user:{user_id} 或 ip:{client_ip}
max_requests *integer时间窗口内最大请求数
window_seconds *integer时间窗口大小（秒）
状态存储 1

字段

错误处理

API Gateway 作为系统统一入口，采用分层错误处理策略：1）认证层：JWT Token 校验失败返回 401，角色权限不足返回 403；2）限流层：请求超过限流阈值返回 429，响应头携带 Retry-After 字段；3）路由层：路径不匹配返回 404，后端服务不可达返回 502 Bad Gateway，并在日志中记录上游错误；4）参数校验层：请求参数格式或必填项缺失返回 400，响应体附带具体校验错误信息。所有错误响应遵循统一格式：{"code": int, "message": string}。网关内部异常（如 panic、超时）由 recovery 中间件统一捕获记录，不向客户端暴露内部堆栈信息。后端请求超时默认 30 秒，超时返回 504 Gateway Timeout。审计日志由 Audit Service 异步写入，失败仅记录告警不阻塞业务。
