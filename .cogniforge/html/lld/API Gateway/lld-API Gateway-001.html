概述

API Gateway
系统统一API入口，基于FastAPI实现，负责请求路由分发、用户身份认证、接口权限校验、请求限流与防护。前端所有API请求经由API Gateway路由到下游服务，Gateway承担认证拦截与路由转发职责。认证令牌使用JWT签发，黑名单与限流计数器基于Redis实现。
依赖: Project Management ServiceEnvironment Management ServiceDeployment OrchestratorKey Management ServiceAudit ServiceFile Storage
PythonFastAPIRedis
🗄️

数据模型 (3)

状态存储 1

🗃️ auth_token自有

用户认证令牌（JWT）。用户登录后签发，后续请求在Authorization头携带Bearer token。令牌中编码用户身份（user_id）与角色（role）。Redis缓存黑名单令牌用于登出失效，Redis设置过期时间与令牌自身exp一致。

字段
字段名类型描述
token *stringJWT令牌字符串
user_id *string用户唯一标识
role *string用户角色：developer/ops/manager
expires_at *datetime令牌过期时间
配置定义 2

⚙️ route_rule自有

路由规则配置表。定义前端请求路径到下游目标服务的映射关系，同时配置该路由是否需要认证及允许访问的角色。Gateway启动时加载到内存。

字段
字段名类型描述
route_id *string路由规则唯一标识
path_pattern *string匹配路径模式，如/api/projects/*
method *stringHTTP方法(GET/POST/PUT/DELETE)或ANY
target_service *string下游目标服务名称
require_auth *boolean是否要求认证
allowed_rolesarray[string]允许访问的角色列表，为空表示所有已认证用户均可访问

⚙️ rate_limit_rule自有

限流规则配置。基于Redis计数器实现滑动窗口算法，支持按接口维度和用户维度分别限流。Gateway启动时加载到内存。

字段
字段名类型描述
rule_id *string限流规则唯一标识
path_pattern *string匹配路径模式
method *stringHTTP方法
limit *integer时间窗口内允许的最大请求数
window_seconds *integer时间窗口长度（秒）
scope *string限流维度：global（全局）或 per_user（按用户）

错误处理

处理策略

API Gateway作为统一入口，采用中间件管道（Middleware Pipeline）模式对请求进行认证、限流、路由三层处理，每层失败即返回不转发下游。下游服务返回的错误码原样透传，同时统一注入trace_id便于链路追踪。网关自身接口（登录/登出/健康检查）的错误由网关直接处理。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
400
请求参数错误
请求体校验失败、缺少必填字段、参数格式错误或枚举值不合法。Gateway在AuthMiddleware之后、路由转发之前进行基础参数格式校验，校验不通过直接返回400，不转发到下游服务。
401
未认证
请求未携带Authorization头、Token格式错误、Token已过期或Token已被加入黑名单（登出后）。Gateway在AuthMiddleware中统一拦截，不满足认证条件的请求直接拒绝，detail字段说明具体原因。
403
权限不足
用户已认证通过但当前角色（developer/ops/manager）不满足接口在route_rule中配置的allowed_roles要求。Gateway在AuthMiddleware中完成角色校验，不满足时直接返回403。
404
路由不存在
请求的HTTP方法+路径组合未匹配到任何route_rule。Gateway返回标准404响应，附带当前请求路径信息，避免无效请求到达下游服务。
409
资源冲突
下游服务返回的资源冲突错误（如创建项目时名称已存在、重复创建环境配置等）。Gateway原样透传409状态码及下游返回的error与detail信息。
413
请求体过大
上传文件或请求体超出Gateway配置的最大限制（默认100MB）。Gateway在请求体读取阶段直接拒绝并返回413，不转发到下游。响应头中的detail字段提示当前限制值。
429
请求限流
请求频率超过rate_limit_rule配置的限制。Gateway基于Redis自增计数器实现滑动窗口算法，超出阈值时返回429状态码，并在响应头中携带Retry-After字段（秒数）告知客户端何时可以重试。登录接口（/api/auth/login）有独立的严格限流规则，防止暴力破解。
502
下游服务不可达
Gateway转发请求到下游服务时发生连接拒绝、DNS解析失败或请求超时（默认5秒）。返回502状态码，记录完整错误日志及trace_id便于排查。不包含下游内部网络拓扑信息在响应体中。
504
下游服务响应超时
Gateway成功连接到下游服务但在超时时间（默认30秒）内未收到完整响应。返回504状态码，detail中注明超时时间，响应中携带trace_id。
500
网关内部错误
Gateway自身在请求处理过程中发生未捕获异常（如JSON解析失败、中间件执行异常等）。返回统一错误格式，记录完整异常堆栈到服务器日志并关联trace_id。
