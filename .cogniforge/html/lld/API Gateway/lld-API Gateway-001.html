概述

模块: API Gateway

系统的统一入口，负责请求路由、身份认证、权限校验、流量控制与请求日志记录。所有客户端请求必须经过 API Gateway 才能访问后端微服务。Gateway 对外暴露 AuthVerifyAPI（登录认证），其余请求按路由规则转发至 Student Service、Class Service、Grade Service、Statistics Service。采用过滤器链模式处理横切关注点：CORS → 请求日志 → 限流 → JWT 鉴权（除登录接口）→ 路由转发 → 响应封装。

接口定义 (17)

AuthVerifyAPI

POST /api/v1/auth/login

（Provider）用户登录认证接口，由 API Gateway 直接处理。接收用户名与密码，校验通过后签发 JWT Token 并返回用户角色。该接口不经过 JWT 鉴权过滤器。

StudentInfoAPI

GET /api/v1/students

（路由转发 → Student Service）分页查询学生列表，支持按姓名、学号、年级、班级等多条件组合筛选

StudentDetailAPI

GET /api/v1/students/{id}

（路由转发 → Student Service）根据 ID 获取单个学生的完整详细信息

CreateStudentAPI

POST /api/v1/students

（路由转发 → Student Service）创建新学生记录，学号必须唯一

UpdateStudentAPI

PUT /api/v1/students/{id}

（路由转发 → Student Service）更新学生信息，支持部分字段更新

DeleteStudentAPI

DELETE /api/v1/students/{id}

（路由转发 → Student Service）根据 ID 删除学生记录

StudentImportAPI

POST /api/v1/students/import

（路由转发 → Student Service）批量导入学生信息，支持 CSV/Excel 文件上传，Gateway 不做解包直接转发二进制流

StudentExportAPI

GET /api/v1/students/export

（路由转发 → Student Service）导出学生信息为 CSV/Excel 文件

ClassInfoAPI

GET /api/v1/classes

（路由转发 → Class Service）分页查询班级列表，支持按年级过滤

ClassDetailAPI

GET /api/v1/classes/{id}

（路由转发 → Class Service）根据 ID 获取班级详细信息，包括班主任和学生人数

CreateClassAPI

POST /api/v1/classes

（路由转发 → Class Service）创建新班级

ClassStudentsAPI

GET /api/v1/classes/{id}/students

（路由转发 → Class Service）查询指定班级的学生名单

GradeInfoAPI

GET /api/v1/grades

（路由转发 → Grade Service）分页查询年级列表，支持按学年和学段过滤

GradeDetailAPI

GET /api/v1/grades/{id}

（路由转发 → Grade Service）根据 ID 获取年级详细信息

CreateGradeAPI

POST /api/v1/grades

（路由转发 → Grade Service）创建新年级

StatisticsAPI

GET /api/v1/statistics/overview

（路由转发 → Statistics Service）获取统计概览数据，支持按学生/班级/年级维度查看

StatisticsExportAPI

GET /api/v1/statistics/export

（路由转发 → Statistics Service）导出统计报表，支持 CSV/PDF 格式

⚠️

错误处理

API Gateway 采用过滤器链统一处理异常：1）JWT 校验失败或 Token 过期返回 401 Unauthorized，响应体包含错误码 'AUTH_TOKEN_INVALID'。2）权限不足（角色不匹配路由白名单）返回 403 Forbidden，错误码 'AUTH_FORBIDDEN'。3）请求超出限流阈值返回 429 Too Many Requests，响应头附加 Retry-After 指示重试等待秒数。4）后端服务熔断开启或连接超时（超时阈值 10 秒）返回 504 Gateway Timeout。5）后端服务返回 5xx 时 Gateway 透传状态码并记录错误日志，不修改下游响应体。6）请求体超过 10MB 返回 413 Payload Too Large。所有异常统一封装为 {"code": "错误码", "message": "错误描述"} 格式。每个请求生成唯一 request_id（UUID），贯穿请求链路，便于日志关联与问题追踪。
