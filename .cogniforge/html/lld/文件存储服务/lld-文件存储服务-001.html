概述

文件存储服务
⚙️ 业务服务
存储用户上传的可执行文件包，支持版本化管理和按需下载。作为基础设施层服务，负责文件在磁盘上的物理存储和元数据管理，为部署引擎提供文件包获取能力，为 Web 控制台提供上传和查询接口
依赖: PostgreSQL数据库审计日志服务
GoGinGo 1.22+PostgreSQL 15RESTful JSON API

业务规则

不变量
  • !每个文件包在磁盘上对应唯一物理文件，路径格式固定为 {storage_root_path}/{project_id}/{file_package_id}/{file_name}，路径生成后不可变更
  • !文件包在同一项目内版本号唯一——当 version 不为空时，禁止同一项目中存在两个 version 相同的文件包
  • !文件包的 SHA256 校验和贯穿全生命周期：上传时计算→持久化→返回给消费者→下载时校验，任何环节发现不一致即为数据损坏
  • !同一项目下所有文件包 size 之和不得超过该项目的存储配额
  • !文件包元数据记录与磁盘物理文件必须一一对应，缺少或多余任意一方均为系统不一致状态
跨服务规则
上传文件包完成后，必须同步调用审计日志服务记录 file.upload 操作，包含项目 ID、文件包 ID、文件名和大小
删除文件包前，必须通过部署引擎服务的查询接口确认该文件包未被任何活跃或历史部署任务引用，被引用时拒绝删除并返回 409
删除文件包完成后，必须同步调用审计日志服务记录 file.delete 操作
GetFilePackageBinary 在返回文件数据前必须校验 SHA256 一致性，确保部署引擎使用的文件未被篡改
文件包是否可删除的校验依赖部署引擎服务提供的查询能力，文件存储服务自身不维护引用关系
审计日志服务调用失败时，文件上传/删除操作本身不应回滚（保证主流程可用），但需记录 warn 级别系统日志提示审计记录缺失

错误处理

处理策略

错误分为四类：请求参数校验错误返回 4xx；文件 I/O 错误（磁盘读写失败、路径不可用）返回 500 并记录系统错误日志；存储配额和文件大小超限返回 413；文件包被引用拒绝删除返回 409。文件上传过程中若磁盘部分写入后发生错误，需清理已写入的临时文件避免残留

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
400
请求参数错误
请求体缺少必填字段或字段格式不正确，由 Gin binding 校验拦截并返回第一个校验失败详情
404
资源不存在
引用的项目 ID 或文件包 ID 在数据库中不存在
