概述

环境管理模块
⚙️ 业务服务
管理环境配置（名称、IP、端口、远程路径、关联密钥），提供测试连接功能。运行在 Electron 主进程中，通过 IPC 与 GUI 前端通信，依赖本地数据库进行持久化，调用 SSH 客户端模块执行连接测试。
依赖: 本地数据库（CTR-007）SSH 客户端模块（CTR-008）
Node.js (主进程)ElectronSQLitessh2
基于: PRD prd-current v1 · SAD sad-001 v1
📐 模块边界
范围内: 环境配置的增删改查（名称、IP、端口、远程路径、关联密钥） 测试 SSH 连接功能 环境与密钥的关联管理 服务内部领域对象定义 服务层方法契约（创建、更新、删除、列表、测试连接）
范围外: 密钥的加密存储与解密（由密钥管理模块负责） SSH 连接的底层实现（由 SSH 客户端模块负责） 数据库表结构定义（由 Primary Database LLD 负责） GUI 界面渲染
拥有组件: CMP-003
实现契约: CTR-003
消费契约: CTR-007 CTR-008

跨服务规则
创建或更新环境时，必须通过密钥管理模块验证密钥 ID 的有效性，若密钥不存在则操作失败。
测试连接时，必须将解密后的密钥传递给 SSH 客户端模块，不得直接传递密钥密文。
删除环境时，若密钥删除模块通知密钥已被删除，则本模块应允许环境记录存在但标记密钥为无效，以便后续清理。
环境列表查询时，可联合密钥管理模块获取密钥的显示名称或指纹，但不允许直接暴露密钥内容。

编排流程

环境管理流程

环境管理模块的核心操作流程，包括创建、更新、删除和测试连接。

1
验证输入 (30s 超时)
校验客户端传入的参数格式和业务规则
失败处理: 返回 400 错误
2
执行操作 (60s 超时)
调用相应的服务方法处理业务逻辑
失败处理: 根据异常类型返回相应错误码
重试策略: 最多 3 次，间隔 30s
可重试错误: NETWORK_ERROR, TIMEOUT
不可重试错误: AUTH_ERROR, CONFIG_ERROR

错误处理

处理策略

统一通过标准API响应格式返回错误，区分客户端错误(4xx)与服务端错误(5xx)，并在日志中记录详细异常信息以便排查。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
400
请求参数错误
当传入的 DTO 校验失败时返回，如必填字段缺失、格式不符合要求、IP地址非法等。detail 中包含具体的校验失败信息。
404
环境不存在
根据 ID 查询、更新或删除环境时，若数据库中不存在对应记录则返回。detail 中包含不存在的环境ID。
409
环境名称冲突
创建或更新环境时，若名称在系统中已存在则返回。detail 中包含冲突的名称。
422
SSH连接测试失败
测试连接时，SSH 客户端返回连接错误（如认证失败、超时、拒绝连接等），错误信息从底层 ssh2 库获取并包装在 detail 中。
500
内部服务错误
数据库操作异常、SSH 客户端不可用或其他未预期的运行时错误。detail 中提供通用错误提示，具体异常记录到日志。
