概述

Environment Management Service
⚙️ 业务服务
管理部署环境的微服务，提供环境的创建、编辑、删除、查询、环境连接参数管理、SSH 密钥与环境绑定、以及连接测试触发能力。接收来自 API Gateway 的 RESTful 请求，直接操作 Primary Database 持久化环境数据，关键操作同步发送审计日志至 Audit Service。连接测试通过调用 SSH Execution Service 在远程服务器上执行轻量探测命令完成。SSH 密钥绑定通过内部调用 Key Management Service 实现密钥导入与关联。
依赖: API GatewayPrimary DatabaseSSH Execution ServiceAudit ServiceKey Management ServiceProject Management Service
Python 3.11+FastAPIasyncio + uvicornPostgreSQL 15Docker + Docker Compose

业务规则

不变量
  • !同一项目下环境名称唯一，比较不区分大小写
  • !环境名称长度 1-100 字符，不可为纯空白字符串
  • !环境标签必须为 test、gray、prod 之一，不可扩展
  • !主机地址必须为合法的 IPv4 地址或 DNS 域名格式
  • !SSH 端口号必须在 1-65535 范围内
  • !SSH 登录用户名长度 1-100 字符，不可为纯空白字符串
  • !环境可无绑定 SSH 密钥（key_id 可为 null），但在执行连接测试和部署时必须已绑定有效密钥
  • !一个 SSH 密钥可绑定到多个环境（多对一关系）
  • !删除环境时，必须确保不存在关联该环境的活跃部署记录

跨服务规则
环境创建前通过直接查询 Primary Database projects 表校验 project_id 存在且项目状态为 active（不经过 HTTP 级联调用），与 Project Management Service 共享数据库视图
环境创建时若传入 key_id，通过直接查询 Primary Database keys 表校验密钥存在性，与 Key Management Service 共享数据库视图
环境删除前通过直接查询 Primary Database deployments 表校验是否存在关联该环境的活跃部署记录，与 Deployment Orchestrator 共享数据库视图
环境创建/更新/删除后同步发送审计事件到 Audit Service 的 POST /internal/audit/log 接口，审计调用失败不影响主流程（异步 fire-and-forget，本地记录失败日志）
连接测试通过调用 SSH Execution Service 的 POST /internal/ssh/execute 接口执行探测命令。该调用同步等待结果，超时时间由 EnvironmentConnectionConfig 配置控制（默认 30s）
SSH 密钥导入操作委托给 Key Management Service 的 POST /internal/keys/import 接口处理，Environment Management Service 仅存储 key_id 引用，不直接接触私钥明文

POST/api/v1/environments/{id}/testTestConnection
测试指定环境的 SSH 连接可达性。服务内部根据环境 ID 查询主机地址、端口、用户名和 SSH 密钥绑定信息，然后调用 SSH Execution Service 的 POST /internal/ssh/execute 接口执行轻量探测命令，收集连接延迟和结果。
参数类型描述
idstring (uuid)环境 ID（路径参数）
Response 200
字段类型
successboolean
messagestring
latency_msint (optional)

状态码说明
401未授权，请求未携带有效身份凭证

错误处理

处理策略

Environment Management Service 对所有请求参数进行前置校验，校验失败返回 400；业务逻辑错误（环境名称重复、密钥未绑定、活跃部署阻止删除）返回 409；资源不存在返回 404；认证和鉴权委托 API Gateway 处理，本服务不直接签发或验证 JWT，但仍实现内部角色检查返回 403。连接测试相关的 SSH 执行失败返回 503（服务不可用）或 408（超时）。所有未预期异常由全局异常处理器捕获，返回 500 并记录错误日志，同时向 Audit Service 发送失败审计事件。
