概述

模块: SSH执行服务
SSH执行服务是CogniForge远程服务器操作的核心引擎，负责与远程服务器建立SSH连接并执行三大类操作：1）连接测试——验证SSH连接配置（主机、端口、用户名、密钥）是否可用并返回延迟；2）远程命令执行——在远程服务器上执行Shell命令（创建目录、执行部署脚本等），返回标准输出、标准错误和退出码；3）文件传输——通过SCP/SFTP将可执行文件上传到远程服务器指定目录，支持大文件分片传输。通过连接池管理SSH会话，减少重复握手开销，支持并发连接复用。
Java 17Spring Boot 3Apache MINA SSHD / JSch连接池（池化管理）SCP/SFTP协议REST (JSON)

字段
字段名类型描述

状态存储 1

🗃️ ssh_session_pool

SSH会话池运行时状态，管理按(host:port:username)三元组分组的SSH会话连接。每个池化Session在闲置超时后自动关闭释放，请求时先尝试复用空闲会话，无空闲则创建新连接（不超过max_total限制）

字段
字段名类型描述
pool_key *string连接池分组键，格式为username@host:port
session *SSH Session对象SSH会话实例，封装了底层的Socket连接和认证状态
last_used_at *datetime最近一次使用时间，用于空闲超时检测
idle_timeout_ms *int空闲超时阈值，超过此时间未使用则关闭释放

⚠️

错误处理

SSH执行服务采用分层错误处理策略：1）参数校验层——三个接口对host、port、username、ssh_key四个连接参数统一校验，以及command和remote_path等业务参数的非空校验，host格式（IP地址或域名）和port范围（1-65535）校验，校验失败统一返回400 Bad Request并指明具体问题字段；2）连接管理层——连接池获取会话时如果达到max_total上限且等待超过max_wait_ms则返回502并提示连接池已满；SSH连接建立失败（TCP超时、认证拒绝、协议不兼容）时记录错误详情并返回502；空闲连接检测到会话异常（连接断开、超时关闭）时自动从池中移除并关闭释放，下次请求重新建立新连接；3）命令执行层——命令执行时设置channel级别的timeout（由请求参数timeout控制），超时后强制关闭channel并记录执行上下文（已执行命令内容、执行时长），返回504 Timeout；命令执行后读取exit_code，非0退出码不视为异常——success字段置false并将exit_code、stdout、stderr一起返回给调用方由调用方决定处理策略；4）文件传输层——文件上传前检查remote_path父目录是否存在，不存在则自动mkdir -p创建；上传过程捕获SFTP协议异常（Permission denied导致写入失败、No space left on device磁盘满、连接中断），返回502并记录具体失败原因；大文件分片传输时每片写入后立即flush确保数据落盘，避免最后flush失败导致文件损坏；5）全局异常处理——所有未捕获异常统一返回500 Internal Server Error，服务端记录完整错误堆栈。所有错误响应统一采用格式：{"error": {"code": "string错误码", "message": "string错误描述"}}。
