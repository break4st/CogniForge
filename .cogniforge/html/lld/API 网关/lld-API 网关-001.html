概述

API 网关
⚙️ 业务服务
系统统一流量入口，负责请求认证（JWT验证）、根据URL路径将请求路由至对应的下游微服务（项目管理服务、环境管理服务、部署编排服务等），提供基础限流和访问控制，并将前端WebSocket连接代理至部署编排服务的实时日志流，同时记录请求访问日志供审计。
依赖: 项目管理服务 (CMP-003)环境管理服务 (CMP-004)部署编排服务 (CMP-006)日志与审计服务 (CMP-007)
Nginx + Lua/OpenResty (或 Kong)
基于: PRD prd-Gateway-001 v1 · SAD sad-Gateway-001 v1
📐 模块边界
范围内: 请求认证 (JWT 验证) 路由转发 (REST + WebSocket) 限流控制 WebSocket 代理至部署编排服务实时日志 请求访问日志记录
范围外: JWT 签发 (由认证服务负责) 业务逻辑处理 数据库直接操作 用户管理 项目管理 环境管理 密钥管理 部署编排 日志审计存储
拥有组件: CMP-001
消费契约: CTR-001 CTR-002 CTR-004 CTR-005

错误处理

处理策略

网关层对下游服务错误进行统一封装，返回标准 JSON 错误体，包含错误码、错误信息和详情。对于认证失败和限流触发直接由网关返回错误，下游服务错误则透传并根据需要转换。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
401
认证失败
JWT 令牌缺失、无效或过期，网关直接返回 401，提示需要有效认证。
403
权限不足
令牌有效但角色或权限不匹配，网关返回 403，禁止访问。
429
请求限流
客户端请求频率超过配置的限流阈值，网关返回 429，并在 Retry-After 头中指明等待时间。
502
下游服务不可用
网关无法连接到下游服务或连接超时，返回 502，提示目标服务暂时不可用。
503
服务暂时过载
下游服务返回 503 或由于限流导致服务不可用，网关返回 503，提示稍后重试。
504
下游服务响应超时
下游服务在规定时间内未返回响应，网关返回 504，提示上游超时。
500
网关内部错误
网关自身发生未预期异常，如配置加载失败或 Lua 脚本错误，返回 500，并记录详细日志。
