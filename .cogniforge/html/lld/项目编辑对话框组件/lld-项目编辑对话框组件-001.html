概述

项目编辑对话框组件
🖥️ 前端
一个基于 Ant Design 的 React 对话框组件，用于新建项目或编辑项目名称与描述。它嵌入在项目列表页面中，通过父组件控制显隐，调用项目管理服务的 REST API 完成数据持久化。
依赖: 项目管理服务（CMP-300）
React 18Ant Design
基于: PRD prd-current v1 · SAD sad-001 v1
📐 模块边界
范围内: 项目创建/编辑的模态对话框UI 表单验证（名称必填，描述可选） 调用项目管理API（创建/更新） 提交状态与错误处理
范围外: 项目列表展示 项目删除或归档 用户登录及权限校验 后端业务逻辑
消费契约: CTR-001 CTR-002

组件树 (1)

ProjectEditDialog/projects (父页面)

项目新建或编辑的模态对话框

Props
visible: boolean *mode: string *project: object|nullonClose: function *onSuccess: function *
Events
@onClose(void)@onSuccess(void)
State
loading: booleanerror: string|null
行为
  • visible 变为 true 时：若 mode='edit' 且 project 存在，用 form.setFieldsValue 设置初始值；create 模式则重置表单。
  • 点击确定按钮：先表单验证，通过后置 loading=true，调用对应 API。
  • API 成功：调用 onSuccess，父组件关闭对话框。
  • API 失败：设置 error 状态，显示 Alert，loading 置 false。
  • visible 变为 false 或点击取消：重置表单和 error 状态。
边界情况
  • ⚠️ 编辑模式下 project 为 null 或缺少 id：设置 error 为「项目数据错误」并直接关闭对话框。
  • ⚠️ loading 状态下重复点击确定：不做任何操作。
  • ⚠️ 网络异常或 API 返回错误：解析统一错误体 {code, error, detail} 并在 Alert 中展示。
  • ⚠️ 对话框关闭（取消/遮罩）：立即重置表单和错误，不保留未提交修改。

交互流程 (2)

新建项目流程

用户从项目列表页面触发新建操作，填写表单并提交。

1
步骤1: 用户在项目列表页点击「新建项目」按钮。
2
步骤2: 父组件设置 visible=true, mode='create'，打开对话框。
3
步骤3: 对话框显示空表单，用户填写项目名称（必填）和描述（可选）。
4
步骤4: 用户点击「确定」，组件执行表单验证。
5
步骤5: 验证通过后调用 POST /api/projects，传递 name 和 description。
6
步骤6: 成功：触发 onSuccess，父组件关闭对话框并刷新项目列表。
7
步骤6a: 失败：从响应中提取错误信息，对话框顶部显示 Alert，用户可修改后重试。
编辑项目流程

用户从项目列表中选择一个项目进行编辑。

1
步骤1: 用户在项目列表中找到目标项目，点击其「编辑」按钮。
2
步骤2: 父组件设置 visible=true, mode='edit', project=所选项目数据。
3
步骤3: 对话框表单自动填充当前项目的名称和描述。
4
步骤4: 用户修改信息后点击「确定」。
5
步骤5: 验证通过后调用 PUT /api/projects/{projectId}。
6
步骤6: 成功：触发 onSuccess，父组件关闭对话框并刷新列表。
7
步骤6a: 失败：处理错误（如 404 提示项目不存在），对话框保持打开。

编排流程

项目编辑提交流程

用户在对话框内填写/修改信息并提交，组件完成验证与API调用的内部编排。

1
表单验证
执行 Ant Design Form 校验规则，不通过则中止。
失败处理: 停止提交，高亮错误字段。
2
调用API (30s 超时)
根据 mode 选择 POST /api/projects 或 PUT /api/projects/{projectId}，携带表单数据。
失败处理: 显示错误 Alert，恢复按钮可点击。
3
成功回调
调用 props.onSuccess()，由父组件关闭对话框并刷新列表。
失败处理: 不适用，仅成功时执行。
重试策略: 最多 0 次，间隔 0s
可重试错误: 无
不可重试错误: 无

接口定义 (2)

frontend#project-edit-dialog-create创建项目触发点
前端打开对话框的新建模式入口，后续将通过 POST /api/projects 调用后端。
frontend#project-edit-dialog-update更新项目触发点
前端打开对话框的编辑模式入口，后续将通过 PUT /api/projects/{projectId} 调用后端。

错误处理

处理策略

前端先通过 Ant Design Form 验证规则拦截无效输入；API 调用错误统一显示在对话框顶部的 Alert 中，并根据错误码归类提示，网络异常给出通用重试提示。

0

网络异常或超时，提示「网络连接失败，请稍后重试」。
