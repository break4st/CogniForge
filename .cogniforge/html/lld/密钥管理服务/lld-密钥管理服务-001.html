概述

密钥管理服务
⚙️ 业务服务
SSH密钥的加密存储、生命周期管理和安全审计。提供密钥的上传、查询、更新、吊销、删除等全生命周期管理，以及解密后的私钥按需安全下发。所有密钥写入时使用AES-256-GCM加密，解密操作必须通过访问策略校验并记录完整审计日志。
依赖: PostgreSQL主数据库加密密钥存储
PythonFastAPIPostgreSQL 15AES-256-GCMgRPC

服务接口 (1)

🔧 KeyService 6 方法
createKey
(request: KeyCreateRequest) -> KeyResponse
上传并注册新的SSH密钥。自动检测密钥算法类型并计算指纹，使用当前主密钥加密私钥后存储。
前置条件
request.name 非空且唯一；request.private_key 为合法 PEM 格式私钥（RSA/ECDSA/ED25519）；request.passphrase 正确（如果私钥有密码保护）
后置条件
密钥已使用 AES-256-GCM 加密持久化到 ssh_keys 表；返回 KeyResponse 中 fingerprint 已按 SHA256 算法计算；审计日志已写入 key_audit_log（action=key_create）
InvalidKeyFormatException→ 400私钥格式非法或算法不支持DuplicateKeyException→ 409密钥名称或指纹已存在EncryptionException→ 500AES-256-GCM 加密失败
getKey
(keyId: String) -> KeyResponse
查询指定密钥的详细信息，仅返回元数据不返回私钥内容。
前置条件
keyId 为有效 UUID 格式；调用方已通过身份认证
后置条件
返回密钥的完整元数据（不含私钥）；bound_environments 通过查询 environments 表实时获取
KeyNotFoundException→ 404指定 keyId 的密钥不存在
listKeys
(query: KeyListQuery) -> PageResult[KeyResponse]
分页查询密钥列表，支持按名称、算法和状态多维度过滤。
前置条件
query.page >= 1；query.page_size 在 1-100 范围内
后置条件
返回分页的密钥元数据列表，按 created_at 降序排列
InvalidQueryException→ 400分页参数超出范围
updateKey
(keyId: String, request: KeyUpdateRequest) -> KeyResponse
更新密钥的元信息或替换密钥内容。替换私钥时将重新计算指纹并使用主密钥重新加密。
前置条件
keyId 有效且密钥状态为 active；如果更新私钥，新私钥必须为合法 PEM 格式
后置条件
更新后的密钥元数据已持久化；如果更新了私钥，fingerprint 已重新计算；审计日志已写入（action=key_update）
KeyNotFoundException→ 404指定 keyId 的密钥不存在InvalidKeyFormatException→ 400新私钥格式非法InvalidStateException→ 409密钥已吊销（revoked）无法更新
deleteKey
(keyId: String, reason: Optional[String]) -> KeyResponse
吊销指定密钥（软删除）。标记密钥为 revoked 状态，禁止后续解密操作，但保留历史审计数据。
前置条件
keyId 有效且密钥状态不为 revoked
后置条件
密钥状态已变更为 revoked；审计日志已写入（action=key_revoke）；历史数据和审计日志保留
KeyNotFoundException→ 404指定 keyId 的密钥不存在InvalidStateException→ 409密钥已处于 revoked 状态
getDecryptedKey
(keyId: String, requestor: String, requestId: String) -> DecryptedKeyResult
从数据库取出加密密钥，校验访问策略后解密，返回明文私钥。私钥仅在内存中使用，不写入磁盘。
前置条件
keyId 为有效 UUID；requestor 为已注册的服务标识；密钥状态为 active（非 revoked/expired）；调用方在 key_access_policies 中具有 decrypt 权限
后置条件
解密成功时：返回 DecryptedKeyResult 包含明文私钥和指纹；解密操作已记录审计日志（action=key_decrypt）；访问策略校验失败时：拒绝访问并记录审计日志（action=access_denied）；私钥明文仅在内存中临时存在，调用方使用后应主动清除
KeyNotFoundException→ 404指定 keyId 的密钥不存在AccessDeniedException→ 401调用方在 key_access_policies 中无 decrypt 权限InvalidStateException→ 403密钥状态非 active（已吊销或已过期）DecryptionException→ 500AES-256-GCM 解密失败或主密钥不可用

业务规则

不变量
  • !所有 SSH 私钥在持久化到数据库时，必须使用 AES-256-GCM 加密，禁止明文存储私钥
  • !密钥指纹（SHA256）在系统中必须唯一，防止相同密钥被重复注册
  • !吊销（revoked）的密钥不可被重新激活，不可用于解密操作
  • !解密后的私钥明文仅在服务内存中临时使用，使用完毕后调用方必须主动清除内存中的私钥内容，不得写入磁盘或日志
  • !密钥的解密操作必须经过访问策略（key_access_policies）校验，未授权的解密请求必须被拒绝并记录审计日志
  • !密钥生命周期中的所有状态变更（创建、吊销、过期）必须记录审计日志，不可跳过
  • !密钥名称在同一范围内（如全局）必须唯一，避免混淆
状态机
🎯 SshKey
activerevokedexpired
→管理员执行吊销操作（deleteKey）by 系统管理员
→密钥超过有效期自动过期by 系统（定时任务）
→吊销状态为终态，不可转换by 无
→过期状态为终态，不可转换by 无
🚫 revoked 和 expired 均为终态，一经进入不可回退到 active🚫 吊销操作不可撤销，如需恢复必须重新上传密钥（新记录、新指纹）
⚡ 密钥状态变更使用数据库乐观锁（version 字段或 WHERE status=active 条件更新），防止并发吊销和更新冲突导致状态不一致
跨服务规则
密钥管理服务与 SSH连接池服务: SSH连接池服务通过 GetDecryptedKey 接口获取解密后的私钥明文，必须在连接使用完毕后立即清除内存中的私钥内容，不得缓存或写入磁盘
密钥管理服务与 API网关: 密钥的 CRUD 管理操作通过 API 网关暴露给前端控制台，API 网关负责 JWT 身份认证和 RBAC 权限校验，密钥管理服务负责密钥自身的访问策略（key_access_policies）校验
密钥管理服务与 环境管理服务: 密钥与环境的绑定关系存储在 environments.ssh_key_id 字段中，由环境管理服务维护；密钥管理服务通过只读查询获取密钥绑定的环境列表（bound_environments），通过检查 environments.ssh_key_id 判断密钥是否被引用后，阻止对有环境引用的密钥执行吊销（防止密钥吊销导致现有环境连接中断）
密钥管理服务与 审计日志服务: 所有密钥操作审计日志写入 key_audit_log 表，审计日志服务可跨服务查询密钥操作记录用于安全合规审查

错误处理

处理策略

密钥管理服务的错误处理按安全敏感度分层：参数校验和格式错误直接返回 4xx；权限校验失败返回 401/403 并写入审计日志（action=access_denied）；密钥状态冲突返回 409 并指导调用方检查当前状态；加密/解密/数据库等基础设施错误返回 500 并包含错误追踪ID供运维排查。所有操作失败均记录审计日志。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
400
参数校验失败
请求参数缺失、密钥格式不合法或字段违反约束时触发。调用端需根据 detail 修正请求后重试。
401
访问未授权
请求方未通过身份认证或未配置对应的密钥访问策略。此错误同时写入 key_audit_log（action=access_denied）。
403
操作被禁止
密钥状态不允许执行请求操作时触发，如对已吊销密钥执行解密、对过期密钥执行更新等。

指定的 key_id 在 ssh_keys 表中不存在时触发。
