概述

密钥管理服务
⚙️ 业务服务
安全存储和管理 SSH 密钥，提供密钥的上传、绑定和验证功能。所有 SSH 私钥在落库前使用 AES-256-GCM 算法加密，仅在部署时由部署引擎通过内部接口获取解密后的密钥会话。
依赖: PostgreSQL 15审计日志服务
GoGinGo 1.22+PostgreSQL 15golang.org/x/crypto/sshRESTful JSON API

服务接口 (1)

🔧 KeyService 6 方法
BindKey
(ctx context.Context, req BindKeyRequest, environmentId int64, actor string) -> BindKeyResponse
解析并校验 SSH 私钥，提取公钥指纹，AES-256-GCM 加密私钥后落库并绑定到指定环境
前置条件
environmentId 对应的环境必须存在于 environments 表中；该环境下不存在同名 (key_name) 密钥；private_key 必须是有效的 PEM 格式 SSH 私钥
后置条件
私钥已通过 AES-256-GCM 加密后写入 ssh_keys 表；密钥已与环境绑定 (bound_at 已设置为当前时间)；审计日志已记录 key.bind 操作
EnvironmentNotFound→ 404environmentId 在 environments 表中不存在KeyNameConflict→ 409同一环境下已存在同名密钥InvalidPrivateKeyFormat→ 400private_key 不是有效的 PEM 格式或无法从私钥中解析出公钥InvalidPassphrase→ 400私钥需要 passphrase 但提供的 passphrase 不正确，无法解密私钥EncryptionFailure→ 500AES-256-GCM 加密过程中发生错误（如密钥衍生失败）
ListKeysByEnvironment
(ctx context.Context, environmentId int64) -> []KeyInfo
查询指定环境下的所有 SSH 密钥摘要信息
前置条件
environmentId 对应的环境必须存在
后置条件
返回该环境绑定的所有密钥摘要列表（按 bound_at 降序排列），每个 KeyInfo 不包含私钥内容
EnvironmentNotFound→ 404environmentId 在 environments 表中不存在
GetKeyDetail
(ctx context.Context, keyId int64) -> KeyDetail
获取单个密钥的详细元信息，仅返回可见元数据不返回私钥
前置条件
keyId 对应的密钥记录必须存在于 ssh_keys 表中
后置条件
返回密钥的完整元信息 KeyDetail（不含 encrypted_private_key 和 passphrase_salt）
KeyNotFound→ 404keyId 在 ssh_keys 表中不存在
DeleteKey
(ctx context.Context, keyId int64, actor string) -> void
物理删除指定的 SSH 密钥及其环境绑定关系。删除后不可恢复。
前置条件
keyId 对应的密钥记录必须存在于 ssh_keys 表中
后置条件

VerifyKeyConnection
(ctx context.Context, keyId int64, serverHost string, serverPort int) -> VerificationResult
解密指定密钥，尝试 SSH 连接到目标服务器，验证密钥有效性和服务器可达性
前置条件
keyId 对应的密钥必须存在且可解密；serverHost 和 serverPort 必须来自已验证的环境配置
后置条件
密钥已解密并建立 SSH 连接尝试。Success=true 时表示连接成功；Success=false 时 Message 包含具体失败原因。不修改任何持久化数据。
KeyNotFound→ 404keyId 在 ssh_keys 表中不存在DecryptionFailure→ 500密钥解密失败（加密密钥错误或数据损坏）ConnectionFailed→ 502SSH 连接握手失败（认证被拒、主机密钥不匹配、连接超时等）

(ctx context.Context, keyId int64) -> DecryptedKeySession
内部方法。解密指定密钥并返回完整的密钥会话信息，供部署引擎建立 SSH 连接
前置条件
keyId 对应的密钥必须存在于 ssh_keys 表中且可正常解密

业务规则

不变量
  • !所有 SSH 私钥在写入数据库前必须经过 AES-256-GCM 加密，禁止明文存储私钥
  • !同一环境下密钥名 (key_name) 必须唯一，由数据库唯一索引 uq_ssh_keys_environment_key 保证
  • !公钥指纹 (fingerprint) 必须可溯源：每次绑定密钥时从私钥中提取公钥并计算 SHA256 指纹，禁止手动指定或修改
  • !所有密钥相关的对外响应 DTO 永远不包含私钥内容 (encrypted_private_key) 和盐值 (passphrase_salt)
  • !解密后的密钥会话 (DecryptedKeySession) 仅限部署引擎内部使用，不得暴露给 Web 控制台或写入审计日志
  • !密钥删除操作不可逆，物理删除后无法恢复
状态机
🎯 SshKey
activedeleted
→BindKey 成功执行by 用户（Web 控制台）
→DeleteKey 成功执行by 用户（Web 控制台）
🚫 active -> deleted 转换不可逆：密钥一旦删除无法恢复，部署引擎将无法使用该密钥建立连接。如需重新使用必须上传新密钥。
⚡ 同一环境下并发绑定同名密钥时，由数据库唯一索引 (environment_id, key_name) 保证只插入成功一条，其余请求返回 409 Conflict。并发删除操作基于 PostgreSQL 行级锁保护，同一时刻只有一个删除请求能成功。
跨服务规则
绑定密钥 (BindKey) 完成后必须同步调用审计日志服务记录 key.bind 操作，请求参数为：action=key.bind, actor=当前用户, resource_type=key, resource_id=新密钥 ID, detail={key_name, environment_id, fingerprint}
删除密钥 (DeleteKey) 完成后必须同步调用审计日志服务记录 key.delete 操作，请求参数为：action=key.delete, actor=当前用户, resource_type=key, resource_id=被删除密钥 ID, detail={key_name, environment_id}
获取解密密钥会话 (GetDecryptedKeySession) 由部署引擎在部署流程中内部调用，密钥管理服务本身不记录该操作的审计日志（由部署引擎统一记录部署过程），但需在应用日志中记录脱敏操作轨迹（仅记录 key_id 和时间，不记录私钥内容）
环境管理服务删除环境时，必须先清理该环境下的所有密钥绑定，否则数据库外键约束会阻止删除。环境管理服务应在事务中先调用本服务的 DeleteKey 接口再删除环境。

错误处理

处理策略

采用分层错误处理。API 层通过 Gin 内置绑定校验捕获参数格式错误返回 400/422；服务层捕获业务逻辑冲突（如密钥名重复）返回 409；资源不存在返回 404；加密/解密基础设施异常返回 500 并记入日志（脱敏，不记录密钥内容）。所有错误统一通过标准化 JSON 响应体返回。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
400
Bad Request
请求参数或 SSH 密钥格式无效。包括：私钥格式无法解析、passphrase 错误、路径参数类型错误。由 API 层校验逻辑捕获后返回。
404
Not Found
请求的资源不存在。包括：环境 ID 无效、密钥 ID 无效。服务层查询数据库未找到对应记录时返回。
409
Conflict
业务冲突。仅当同一环境下尝试绑定同名密钥时触发，由数据库唯一约束 (environment_id, key_name) 保证。
422
Unprocessable Entity
请求体字段校验失败。包括：key_name 为空、private_key 为空、字段类型不匹配、key_name 超长。由 Gin ShouldBindJSON 内置校验器捕获。
500
Internal Server Error
服务端内部错误。包括：AES-256-GCM 加密/解密失败、数据库连接异常、密钥衍生失败。日志记录详细错误栈，响应体返回通用错误信息避免泄露敏感细节。
502
Bad Gateway
上游 SSH 连接失败。仅用于「验证密钥连接」接口：目标服务器不可达、认证失败或握手超时。
