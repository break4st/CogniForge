概述

密钥管理服务
⚙️ 业务服务
管理SSH密钥的全生命周期，保障密钥安全存储和使用。提供密钥的创建、更新、删除、查询等管理功能，基于AES-256算法对密钥内容进行加密存储，通过SSH连接测试验证密钥有效性，并维护密钥与部署环境的绑定关系。
依赖: PostgreSQL主数据库环境管理服务SSH连接池服务审计日志服务
GoGinPostgreSQL 15+golang.org/x/crypto/sshcrypto/aescrypto/sha256JWT
🗄️

服务接口 (1)

🔧 KeyService 9 方法
CreateKey
(req: CreateKeyRequest, ctx: AuthContext) -> KeyDetailResponse
创建并存储一个新的SSH密钥。先校验输入参数，解析私钥提取公钥和指纹，使用AES-256-GCM加密私钥内容，写入数据库。
前置条件
请求者已通过JWT认证且有密钥管理权限（admin或manager角色）；密钥内容为合法的PEM格式私钥；key_type与私钥实际类型一致；如passphrase不为空则私钥必须使用该口令加密
后置条件
SSH密钥已创建，明文内容经过AES-256-GCM加密后持久化到ssh_keys表；密钥指纹已计算并确保全局唯一；返回的KeyDetailResponse不含私钥内容
ErrInvalidKeyFormat→ 400私钥内容无法解析为合法PEM格式ErrUnsupportedKeyType→ 400密钥类型不是rsa/ecdsa/ed25519中之一ErrInvalidPassphrase→ 400提供的passphrase无法解密私钥ErrDuplicateFingerprint→ 409计算得到的fingerprint与数据库中已有记录重复
GetKey
(keyId: UUID) -> KeyDetailResponse
根据ID查询密钥详情，同时查询环境管理服务获取绑定信息。
前置条件
keyId不为空
后置条件
返回不含私钥内容的密钥详情，包括绑定的环境列表（通过环境管理服务查询）；如密钥不存在则返回KeyNotFoundError
ErrKeyNotFound→ 404指定keyId在数据库中不存在
ListKeys
(filter: KeyFilter) -> PaginatedResult<KeySummary>
分页查询密钥列表，支持按key_type/status/search进行筛选。
前置条件
分页参数在合法范围内（page >= 1, 1 <= page_size <= 100）
后置条件

UpdateKey
(keyId: UUID, req: UpdateKeyRequest) -> KeyDetailResponse
更新密钥名称和/或密钥内容。内容变更会触发重新加密和指纹重算。
前置条件
keyId在数据库中已存在；修改content时新密钥内容须为合法PEM格式
后置条件
密钥信息已更新；如content变更则重新加密存储并更新fingerprint；name变更则直接更新；bound_environments不受影响

DeleteKey
(keyId: UUID) -> void
物理删除指定密钥。执行前检查环境绑定状态，有绑定则拒绝删除。
前置条件
keyId在数据库中已存在；该密钥未绑定任何环境（bound_count = 0）
后置条件
密钥已从ssh_keys表物理删除；关联的审计日志不受影响

ValidateKeyConnection
(keyId: UUID, host: string, port: int, username: string) -> KeyValidationResult
测试密钥能否成功SSH连接到目标服务器。解密密钥后调用SSH连接池服务建立连接，返回测试结果。
前置条件
keyId在数据库中已存在；host和username不为空；port在1-65535范围内
后置条件

业务规则

不变量
  • !同一密钥指纹在ssh_keys表中必须全局唯一，防止同一SSH密钥被重复录入
  • !密钥内容在持久化前必须经过AES-256-GCM加密，任何未经加密的明文密钥不得写入数据库
  • !密钥内容被解密后只能在内存中临时使用，使用完毕必须立即清除（将内存置零）
  • !前端API不得返回decrypted_content字段，密钥私钥内容仅通过内部凭据接口返回给部署编排服务
  • !密钥被物理删除前必须已从所有环境中解绑（bound_count = 0）
  • !所有密钥管理操作（创建/更新/删除/验证/绑定/解绑/凭据获取）必须记录审计日志
  • !密钥类型必须为rsa、ecdsa、ed25519三选一，不接受其他类型
状态机
🎯 SshKey
activeinactivecompromised
→管理员手动禁用密钥by 运维管理员
→管理员启用密钥by 运维管理员
→安全事件：密钥泄露或疑似泄露by 安全管理员/自动检测
→安全审查发现密钥曾泄露by 安全管理员
→安全审查完成，密钥被确认安全但暂不启用by 安全管理员
🚫 active -> compromised 为不可逆转换，一旦标记为compromised不可直接恢复为active；必须先转为inactive，经安全审查后再决定是否重新启用🚫 密钥处于compromised状态时，即使环境仍绑定此密钥，SSH连接池也必须拒绝使用该密钥建立连接
⚡ 密钥状态转换使用乐观锁（version字段），更新时校验version值，冲突时返回409提示重试。compromised转换由安全管理员触发，具有最高优先级，可覆盖其他状态的并发操作。
跨服务规则
绑定/解绑操作：密钥管理服务通过HTTP API调用环境管理服务的接口更新environments.key_id字段，调用失败时返回502并回滚操作。不支持分布式事务，采用最终一致性模型。
密钥验证操作：密钥管理服务解密密钥后，调用SSH连接池服务的SSH连接测试接口完成验证。SSH连接池服务不存储密钥内容，验证完成后立即丢弃。
密钥删除前检查：删除密钥时，密钥管理服务必须调用环境管理服务的查询接口确认该密钥未绑定任何环境。若环境管理服务不可用，删除操作将被拒绝。
审计日志：所有密钥写操作（创建/更新/删除/绑定/解绑）以及凭据获取操作，密钥管理服务同步调用审计日志服务的记录接口。若审计日志服务不可用，写操作仍继续完成，但返回警告信息并在本地日志中标记待同步。
关联查询：密钥详情接口中的bound_environments列表通过调用环境管理服务获取，环境管理服务根据key_id反向查询所有绑定了该密钥的环境记录。

错误处理

处理策略

密钥管理服务采用分层错误处理策略：输入校验层在请求到达前拦截格式错误并返回400；业务逻辑层捕获密钥加密/解密、SSH验证、环境绑定等操作中出现的业务异常，映射到对应的HTTP状态码和业务错误码；数据访问层捕获数据库驱动错误并转换为统一响应格式。密钥解密失败时记录安全告警日志，触发告警通知。加密密钥操作使用重试机制（最多1次），解密操作不重试以防止安全漏洞。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
400
请求参数错误
输入参数校验失败，如密钥类型不支持、host为空、分页参数超出范围等。处理方式：返回detail字段说明具体校验失败原因，引导前端修正输入。
401
认证失败
内部接口调用时内部认证Token无效或缺失，或JWT Token过期/无效。处理方式：拒绝请求，返回详细错误描述，记录安全告警日志。
404
资源不存在
请求的密钥ID在数据库中不存在。处理方式：返回404，detail字段指明不存在的资源类型和ID。
409
资源冲突
操作违反业务约束：密钥指纹重复（唯一约束冲突）、密钥仍有环境绑定无法删除、环境已绑定其他密钥等。处理方式：返回409，detail字段说明冲突的具体内容和建议操作。
422
密钥内容异常
密钥内容格式正确但无法处理的异常：无法解析PEM格式、无法提取公钥、密钥口令错误、公钥指纹计算失败等。处理方式：返回422，detail字段提供具体的密钥格式诊断信息。
500
加密/解密失败
AES-256-GCM加密或解密过程中发生错误，通常由加密数据损坏、密钥配置错误或系统异常引起。处理方式：记录安全告警日志，触发告警通知，返回500不透露具体加密细节。
502
下游服务不可用
调用环境管理服务或SSH连接池服务时失败。处理方式：返回502，detail字段说明具体的下游服务和错误原因，建议用户稍后重试。
