概述

API网关
🔀 网关层
统一API入口，负责请求路由、认证鉴权、流量控制。作为系统的唯一外部访问点，所有客户端请求必须经过API网关转发到对应的下游微服务。核心职责包括：请求路由转发到对应微服务、用户身份认证和权限校验、请求日志记录、限流和熔断保护。
依赖: 项目管理服务环境管理服务部署执行服务密钥管理服务审计日志服务
PythonFastAPIRedis 7RabbitMQ
🔀

/api/deployments/**部署执行服务部署任务的创建、查询、取消接口，转发到部署执行服务处理
/api/internal/**内部服务调用（禁止外部访问）内部服务间通信接口，从外部路由表中排除，仅允许内部网络访问

限流规则

全局 每 IP 100 req/s
每用户 每 user 1000 req/min
端点限制
POST /api/auth/login每 IP 5 req/min（防止暴力破解）
POST /api/deployments每 user 10 req/min
POST /api/environments/{environment_id}/test每 user 30 req/min
GET /api/health每 IP 60 req/min（宽松限制）

⚙️ GatewayRoute自有

路由规则配置，定义路径模式与上游服务的映射关系，支持路径变量提取和转发

字段
字段名类型描述
id *UUID路由规则唯一标识
path_pattern *string路径匹配模式，如 /api/projects/**
upstream *string上游服务名称，如 project-service

rate_limit_profilestring限流策略引用名，如 default / strict / relaxed
timeout_ms *integer上游请求超时时间（毫秒），默认 30000
enabled *boolean路由是否启用

⚙️ RateLimitPolicy自有

限流策略配置，定义不同维度的速率限制规则，存储于网关本地配置，运行时计数器存于 Redis

字段

global_rps *integer全局每秒请求数上限
per_ip_rps *integer每 IP 每秒请求数上限

错误处理

处理策略

API网关采用统一错误处理策略：请求校验失败返回 4xx 错误码及具体校验信息；认证失败返回 401 并提示登录；权限不足返回 403 并注明所需角色；限流触发时返回 429 及 Retry-After 头部；上游服务调用失败返回 502/503 并附带错误详情。所有错误统一封装为标准化 JSON 响应格式，确保前端消费一致性。

400
参数校验失败
请求体字段缺失、类型不匹配、格式错误或约束校验不通过，如 name 超长、UUID 格式无效、枚举值不合法
401
未认证
请求未携带 JWT Token、Token 已过期或 Token 签名验证失败。响应包含 WWW-Authenticate 头部指示认证方式
403
权限不足
用户已认证但角色不满足接口所需权限等级（如非 admin 尝试删除项目），detail 中注明所需最低角色
404
资源不存在
上游服务返回资源不存在错误，网关原样透传 404 及错误详情
409
业务冲突
资源状态不允许当前操作，如部署任务状态冲突、项目名重复、密钥已吊销等业务层面冲突
429
请求限流
触发限流规则时返回此状态码，同时设置 Retry-After 头部指示客户端等待时间（秒）
502
上游服务故障
下游微服务返回错误响应或请求超时（超过 upstream_read_timeout_ms）
503
服务暂不可用
网关自身过载（如连接池耗尽）或关键依赖（Redis）不可用
