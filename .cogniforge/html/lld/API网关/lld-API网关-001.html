概述

API网关
🔀 网关层
REST API 统一入口，负责请求路由、认证鉴权、请求校验和响应封装。作为系统接入层核心组件，所有客户端请求必须经过网关转发到对应业务服务
依赖: Redis 7
GoGinGo 1.22+Redis 7RESTful JSON API
🔀

认证授权

公开端点: /api/v1/auth/login POST /api/v1/auth/refresh GET /api/v1/health
认证方式: JWT Bearer Token，Token 通过 Authorization 请求头传递，格式为 Bearer {access_token}。认证中间件自动校验 Token 有效性、过期时间和黑名单状态，校验通过后将用户身份注入请求上下文
Token 策略: access_token 2 小时，refresh_token 7 天。access_token 过期后可使用 refresh_token 通过 /api/v1/auth/refresh 接口刷新，refresh_token 过期后需要重新登录。Token 可通过登出操作即时加入 Redis 黑名单撤销

限流规则

全局 每 IP 100 req/s，超出返回 429。全局限流在 CORS 中间件之后、Auth 中间件之前执行，对所有请求（包括公开端点）生效
每用户 每用户 1000 req/min，基于用户 ID 维度统计。超出返回 429 并在响应头携带 Retry-After 字段。用户维度限流在 Auth 中间件解析身份后执行，仅对已认证请求生效
端点限制
POST /api/v1/auth/login每 IP 5 req/min，防止暴力破解
POST /api/v1/deploy每用户 10 req/min，防止重复提交部署请求
GET /api/v1/deploy/:taskId/status每用户 60 req/min，轮询场景允许更高频率
GET /api/v1/audit-logs每用户 30 req/min

⚙️ RouteRule自有

路由规则定义，描述请求路径到上游服务的映射关系。由网关启动时加载，支持热更新

字段
字段名类型描述
id *string路由规则唯一标识
path_pattern *string请求路径匹配模式，支持 :param 和 * 通配符
methods *[]string允许的 HTTP 方法列表，空数组表示匹配所有方法
upstream_service *string目标上游服务名称
strip_prefixstring转发时移除的路径前缀
auth_required *boolean是否需要认证
rate_limit_profilestring限流策略配置名称

⚙️ RateLimitProfile自有

限流策略配置，定义接口级别的请求频率限制规则，底层基于 Redis + 滑动窗口算法实现

字段
字段名类型描述
name *string限流策略唯一名称
global_req_per_sec *integer全局每秒最大请求数
per_user_req_per_min *integer每用户每分钟最大请求数
per_ip_req_per_sec *integer每 IP 每秒最大请求数
burst_size *integer突发流量允许的额外请求数
window_seconds *integer滑动窗口时间窗口大小（秒）

错误处理

处理策略

网关层统一捕获所有请求处理过程中的异常，按照标准化 JSON 格式返回错误响应。认证失败返回 401，权限不足返回 403，资源不存在返回 404，参数校验失败返回 400，资源冲突返回 409，频率限制返回 429，服务器内部错误返回 500。网关不泄露内部调用链路的细节错误信息，上游服务返回的 5xx 错误统一转换为网关层 502 或 500

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
400
参数校验错误
请求体缺少必要字段、字段格式不符合要求或路径参数类型错误时触发。detail 字段指明具体错误字段和原因
401
认证失败
未提供 Authorization 请求头、Token 格式无效、Token 已过期或被加入黑名单时触发。detail 指明具体原因
403
权限不足
当前用户角色不满足接口所需的角色权限时触发。由认证中间件在角色鉴权阶段拦截
404
资源不存在
请求的资源（项目、环境、密钥、部署任务）不存在时触发。网关透传上游服务的 404 响应
409
资源冲突
创建资源时唯一约束冲突、状态冲突导致操作无法执行时触发。detail 指明冲突原因
429
请求频率限制
超出限流策略允许的请求速率时触发。响应头携带 Retry-After 字段告知客户端等待时间
500
网关内部错误
网关自身逻辑异常、Redis 连接失败等不可预知的内部错误。记录详细错误日志后返回泛化信息
502
上游服务错误
上游业务服务返回非预期响应或连接超时。网关记录上游错误日志后统一转换为 502 返回客户端
