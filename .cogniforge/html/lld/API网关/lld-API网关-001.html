概述

API网关
🔀 网关层
统一API入口，负责请求路由、认证鉴权与流量控制。作为整个系统的前端门户，所有客户端请求首先到达API网关，网关完成JWT身份认证、RBAC权限校验、三级限流检查后将请求路由至对应的下游微服务。同时提供跨域处理（CORS）、请求日志审计记录和统一的错误响应格式。网关自身提供登录认证接口（颁发JWT令牌），其余业务接口均为透传代理至后端服务。
依赖: 项目管理服务环境管理服务部署引擎服务缓存
Python 3.11+FastAPIRedis 7

限流规则

全局 每 IP 100 req/s（Redis滑动窗口计数器，全局限流保护网关不被DDoS）
每用户 每 user 1000 req/min（基于JWT sub声明标识，超出返回429）
端点限制
POST /api/v1/auth/login每 IP 5 req/min（防暴力破解，超出返回429）
POST /api/v1/deployments每 user 10 req/min（部署操作频率限制，防止误操作）
POST /api/v1/deployments/{deployment_id}/rollback每 user 3 req/min（回滚操作频率限制）
POST /api/v1/environments/{env_id}/test每 user 30 req/min（连接测试频率限制）
GET /api/v1/health每 IP 200 req/s（健康检查放宽限流）

错误处理

处理策略

采用统一错误处理策略。所有下游微服务返回的错误被网关透传至客户端，保持原始错误码和消息结构。网关自身产生的错误（认证失败、限流触发、请求超时）在网关层拦截并以标准格式返回。认证失败返回401，权限不足返回403，资源不存在返回404，速率超限返回429，上游服务不可达返回502。所有错误响应均记录审计日志，包括客户端IP、请求路径、用户标识和错误详情。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
400
请求参数错误
请求参数缺失、格式错误或值不合法，由网关层Pydantic模型校验触发，返回第一个校验失败的字段名和原因
401
认证失败
JWT令牌缺失、无效、已过期或已被加入黑名单。包括：token格式错误（40101）、token过期（40102）、token已撤销（40103）
403
权限不足
用户身份认证通过但无权访问指定资源或执行指定操作，由网关RBAC校验触发
404
资源不存在
请求的资源在对应上游服务中不存在，由上游服务返回后网关透传
409
资源冲突
创建资源时名称/标识重复或删除资源时存在关联引用，由上游服务返回后网关透传
429
请求速率超限
触发全局、每用户或特殊端点的限流策略。响应头包含 X-RateLimit-Reset 字段告知客户端重试时间
500
网关内部错误
网关自身未预期的运行时异常，记录错误详情到审计日志并返回通用错误消息，不暴露内部实现细节
502
上游服务不可达
网关无法连接到上游微服务（连接超时、连接拒绝、DNS解析失败），返回上游服务名称便于运维排查
504
上游请求超时
上游服务处理时间超过网关配置的超时阈值（默认30秒）
