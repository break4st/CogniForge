概述

API网关
基于Spring Cloud Gateway构建的统一API入口，作为系统所有外部请求的唯一接入点。负责将前端HTTP/WebSocket请求按路由规则转发至对应的业务服务，并在转发前完成JWT令牌校验、RBAC权限校验、接口级限流与熔断保护、全量请求日志记录。对外暴露统一REST API契约和WebSocket端点，对下游服务通过服务发现进行负载均衡路由。
依赖: 项目管理服务环境管理服务密钥管理服务部署编排服务审计服务Redis
Java 17Spring Boot 3.x + Spring CloudSpring Cloud GatewayRedis 7.x

数据模型 (4)

配置定义 3

⚙️ RouteRule自有

网关路由规则表，定义外部请求到下游服务的映射关系，每条规则包含路由ID、目标服务名、路径断言、过滤器链和熔断配置。配置存储在网关自身配置文件中（application.yml / Nacos），运行时由Spring Cloud Gateway路由表加载。

字段
字段名类型描述
id *string路由规则唯一标识，格式为 route_{service}_{serial}
target_service *string下游目标服务名（如 project-service, environment-service, key-service, deployment-service, audit-service）
path_pattern *string路径匹配表达式（如 /api/projects/**）
methodsArray<string>允许的HTTP方法列表，为空表示允许所有方法
filtersArray<string>应用到此路由的过滤器链（如 JwtAuthFilter, RateLimitFilter, RequestLogFilter）
circuit_breaker_enabled *boolean是否启用熔断保护
timeout_msinteger转发超时时间（毫秒），默认5000

⚙️ RateLimitConfig自有

接口级限流配置，基于Redis + RequestRateLimiter过滤器实现令牌桶算法。每条配置针对一个路由或一组API定义QPS上限和突发流量容量，运行时从Redis加载或通过配置中心动态更新。

字段
字段名类型描述
route_id *string关联的路由规则ID
replenish_rate *integer令牌桶补充速率（每秒补充的令牌数），对应稳定QPS上限
burst_capacity *integer令牌桶容量，对应突发流量的最大QPS
key_resolver *string限流key解析策略（IP / USER / URL），用于区分不同的限流维度
enabled *boolean是否启用限流

⚙️ AuthWhitelist自有

认证白名单配置，定义无需JWT令牌校验即可公开访问的路径列表（如登录接口、静态资源等）。配置存储在网关配置文件中，启动时加载到JwtAuthFilter的跳过列表。

字段
字段名类型描述
path_pattern *string无需认证的路径匹配表达式（如 /api/auth/login, /api/auth/refresh, /actuator/health）
descriptionstring白名单条目说明
状态存储 1

🗃️ AccessLog自有

网关请求访问日志记录，每次经过网关的请求将被结构化记录。日志通过Spring Cloud Gateway的GlobalFilter采集，异步写入日志文件或发送到审计服务持久化。

字段
字段名类型描述
trace_id *string全链路追踪ID（UUID），跨服务传递用于日志关联
method *stringHTTP请求方法
path *string请求路径
query_paramsstringURL查询参数（JSON格式）
user_idinteger经过认证的用户ID，未认证请求为空
usernamestring经过认证的用户名
source_ip *string客户端IP地址
user_agentstring客户端User-Agent
target_service *string路由目标服务名称
request_bodytext请求体内容（可截断，最大4KB）
response_status *integer响应HTTP状态码
response_bodytext响应体内容（可截断，最大4KB）
duration_ms *integer请求处理耗时（毫秒）
timestamp *datetime请求时间

错误处理

处理策略

网关采用GlobalFilter拦截所有请求异常，统一按错误类型分类处理。认证/授权错误由JwtAuthFilter在网关层直接拦截返回；下游服务返回的错误由网关透传并统一封装为标准响应格式；限流触发时由RequestRateLimiter过滤器直接返回429状态码；熔断器触发时返回503状态码。所有错误响应统一使用三层结构: code（业务码）、error（简短错误名）、detail（详细描述，生产环境可脱敏）。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
400
请求参数错误
请求参数校验失败。网关对必需参数缺失、格式错误等直接返回400，不转发到下游服务。detail字段中说明具体哪个参数不合法。
401
认证失败
JWT令牌缺失、过期或无效。JwtAuthFilter在网关层直接拦截并返回401，响应头设置 WWW-Authenticate: Bearer。前端应捕获401并跳转至登录页或触发令牌刷新流程。
403
权限不足
JWT令牌有效但当前用户无权限访问目标资源或执行操作。网关层通过RBAC过滤器校验用户角色权限，校验失败时直接返回403，detail字段说明所需权限。
404
资源不存在
请求的目标资源不存在。网关本身的路由表找不到匹配路径时返回404；路由到下游服务后，下游服务返回的资源不存在错误由网关透传返回404。
409
资源冲突
创建或更新资源时发生唯一键冲突（如项目名称重复、密钥名称重复）。网关透传下游服务返回的409响应。
429
请求限流
请求频率超过接口限流阈值。由RequestRateLimiter过滤器在网关层直接返回429，响应头设置 Retry-After 建议重试时间（秒）。限流key按接口配置使用IP或用户ID维度。
500
下游服务内部错误
下游业务服务返回5xx错误时的统一透传。网关捕获下游服务HTTP 500响应后封装为标准错误格式返回，detail字段下游服务错误信息在生产环境脱敏为 「服务内部错误，请稍后重试」。
502
网关代理错误
网关无法连接到下游服务（服务未注册或网络不可达）。网关直接返回502，detail为「目标服务不可达」，同时触发告警通知运维。
503
服务不可用（熔断）
下游服务连续超时或错误率超过阈值，熔断器（Spring Cloud Circuit Breaker）开启后直接返回503，detail为「服务暂不可用，请稍后重试」。熔断器进入半开状态后定期探测下游服务健康状态。
504
网关超时
请求转发到下游服务超过路由配置的超时时间（默认5000ms）。网关返回504，detail中注明超时的目标服务名和超时时间。
