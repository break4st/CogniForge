概述

模块: API网关
API网关是CogniForge系统的统一入口层，部署于Web管理控制台与后端业务服务之间，负责处理所有外部HTTP请求。核心功能包括：用户身份认证（JWT令牌颁发与校验）、接口级权限校验、请求路由和负载均衡、流量控制（滑动窗口限流）、操作日志记录。作为系统边界守卫，API网关对前端屏蔽后端服务拓扑细节，提供统一的认证鉴权和请求入口。
依赖: 项目管理服务环境管理服务部署编排服务
GoGin/Go HTTP RouterJWTRedis（令牌黑名单/限流计数器）MySQL（用户/日志）Prometheus（请求指标）

错误处理

API网关采用分层错误处理策略：1）请求校验层——校验请求参数合法性、HTTP方法匹配和Content-Type，校验失败返回400 Bad Request，响应体包含error_code和message字段；2）认证鉴权层——JWT令牌校验（签名验证+过期检查+Redis黑名单检查）失败返回401 Unauthorized，权限不足返回403 Forbidden；3）限流层——基于Redis滑动窗口计数器实现，超过阈值返回429 Too Many Requests，响应头携带Retry-After字段指示重试时间；4）路由转发层——后端服务连接超时（5秒）或连接拒绝时返回502 Bad Gateway，响应体携带后端服务名称便于排查；5）全局异常捕获——所有未捕获异常统一返回500 Internal Server Error，日志记录完整堆栈但不将内部细节暴露给客户端。所有错误响应统一格式：{"error": {"code": "string错误码", "message": "string错误描述", "request_id": "string请求追踪ID"}}，其中request_id与access_log中的日志ID对应，便于问题追溯。
