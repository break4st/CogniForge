概述

API网关
🔀 网关层
统一API入口，负责请求路由分发、身份认证、权限校验、跨域管理和访问控制。接收Web管理控制台的所有前端请求，进行JWT令牌验签与身份认证，按路由规则将请求转发到对应的后端微服务，聚合统一错误响应格式，记录请求日志。
依赖: 项目管理服务环境配置服务部署引擎服务密钥管理服务审计日志服务Redis缓存
PythonFastAPIRedis 7RESTWebSocketJWT

错误处理

处理策略

网关层统一拦截所有请求和响应，按标准化格式返回错误信息。认证失败返回401，权限不足返回403，请求速率超限返回429，参数校验失败返回400，资源不存在返回404，业务冲突返回409。上游服务返回的错误码和消息透传到客户端。网关内部错误（路由失败、上游超时）返回502或504。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
400
请求参数错误
请求体格式错误、缺少必填字段、字段类型或范围不合法，由FastAPI Pydantic校验器在网关层拦截
401
认证失败
JWT令牌缺失、过期、签名无效或已被加入黑名单（登出后），网关Auth中间件拦截
403
权限不足
当前用户角色无权访问目标接口或操作目标资源，网关Auth中间件根据role_path_map校验后拒绝
404
资源不存在
请求的路径或引用的资源ID在后端服务中不存在，由上游服务返回，网关透传
409
业务冲突
请求与当前业务状态冲突（如名称重复、存在进行中的部署），由上游服务返回，网关透传
429
请求速率超限
超过全局或用户级别的速率限制，网关RateLimiter中间件拦截，响应头携带 Retry-After
502
上游服务不可用
网关转发请求到上游服务时连接失败或被拒绝，返回502 Bad Gateway
504
上游服务响应超时
网关转发请求到上游服务后在配置的超时时间内未收到响应，返回504 Gateway Timeout
