概述

API网关
🔀 网关层
系统的统一入口网关，负责前端请求的路由分发、用户身份认证与会话管理（JWT）、基于角色的接口访问控制（RBAC）、请求速率限制和防滥用，以及WebSocket连接管理。所有前端请求首先到达API网关，经过认证→鉴权→限流→路由后转发到对应业务服务。
依赖: Web控制台项目管理服务环境管理服务部署编排服务密钥管理服务文件存储
PythonFastAPIRedisJWT + RBAC

中间件链

Request → AccessLog（请求日志记录） → Auth（JWT校验与解析） → RateLimiter（三级限流） → Router（路径匹配与路由） → 转发 Upstream（HTTP/gRPC） → 汇聚 Response → PostLog（响应日志记录） → Response

认证授权

公开端点: POST /api/v1/auth/login POST /api/v1/auth/refresh GET /api/v1/health
认证方式: JWT Bearer Token，签发算法RS256，access_token有效期2小时，refresh_token有效期7天。令牌负载包含sub（用户ID）、username、roles（角色列表）、token_type。网关验证签名后从roles字段提取角色进行RBAC鉴权
Token 策略: access_token 2小时，refresh_token 7天

限流规则

全局 每IP 100 req/s（基于客户端IP的全局限流，超过返回429）
每用户 每user 1000 req/min（基于JWT sub字段的每用户限流，未认证请求按IP计入全局限流）
端点限制
POST /api/v1/auth/login每IP 5 req/min，防止暴力破解
POST /api/v1/deploys每user 10 req/min，防止频繁发起部署
POST /api/v1/files/upload每user 30 req/min，每文件最大100MB
WS /api/v1/deploys/*/status每user 10并发连接数

错误处理

处理策略

API网关作为系统入口，错误处理按层次递进：1）接入层——请求格式错误、JSON解析失败返回400；2）认证层——token缺失/无效/过期返回401，token被吊销返回401且记录审计日志；3）鉴权层——用户无目标接口权限返回403；4）限流层——请求速率超限返回429，并在响应头附加Retry-After；5）路由层——路径不匹配返回404；6）转发层——上游服务返回的错误码透传给前端，上游服务不可达（连接超时/拒绝）返回502，网关自身转发超时（默认30秒）返回504。所有错误统一使用JSON格式响应，错误详情中不泄露服务内部实现细节。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
400
请求参数错误
请求体JSON解析失败、必填字段缺失、字段类型或格式不符合约束；multipart边界格式错误
401
认证失败
Authorization头缺失、token格式无效、签名校验失败、token已过期、token已被吊销
403
权限不足
认证通过但用户角色不满足接口要求的角色矩阵（role_path_map中未匹配到对应角色）
404
路由未匹配
请求路径在route_table中无匹配的path_pattern；或上游服务返回404时透传
429
请求限流
全局/每用户/每IP的请求速率超过配置阈值，响应头附加X-RateLimit-Remaining和Retry-After
500
网关内部错误
网关自身异常（如内存溢出、未捕获的运行时异常），不暴露堆栈信息
502
上游服务不可达
转发请求到上游服务时连接失败、DNS解析失败、TLS握手失败
504
上游服务超时
转发请求到上游服务后30秒内未收到响应
