概述

API网关
🔀 网关层
统一API入口，负责请求路由、认证鉴权和限流。作为系统的接入层，所有外部请求首先到达API网关，经身份认证、请求校验和速率限制后，按路由规则转发至对应的后端业务服务。网关不处理业务逻辑，仅负责协议转换、请求转发和横切关注点（认证、限流、审计日志记录）。
依赖: 项目管理服务环境管理服务部署编排服务密钥管理服务版本管理服务审计日志服务
GoGinJWTRedis 7+gorilla/websocket
🔀

中间件链

Request → CORS (跨域处理) → RequestLogger (请求日志) → Auth (JWT认证) → RateLimiter (速率限制) → Router (路由分发) → UpstreamCall (上游调用) → ResponseLogger (响应日志) → Response

限流规则

全局 每IP 100 req/s，基于Redis滑动窗口计数器
每用户 每user 1000 req/min，基于JWT中的用户身份标识
端点限制
POST /api/v1/deploy每user 10 req/min
POST /api/v1/deploy/:taskId/rollback每user 5 req/min
POST /api/v1/keys每user 30 req/min
GET /api/health不限流

数据模型 (2)

配置定义 2

⚙️ route_rules自有

网关路由规则配置，定义路径模式与上游服务的映射关系。存储在本地配置文件中，启动时加载到内存。

字段
字段名类型描述
id *string (UUID)路由规则唯一标识
path_pattern *string路径匹配模式，支持:param和**通配符
methods[]string允许的HTTP方法列表，为空则匹配所有
upstream *string上游服务名称，与服务发现注册名一致
auth_required *boolean是否要求身份认证
rate_limit_profilestring引用的限流策略名称
enabled *boolean是否启用该路由
descriptionstring路由规则说明

⚙️ rate_limit_profiles自有

限流策略配置，基于Redis滑动窗口实现速率限制。存储在本地配置文件中。

字段
字段名类型描述
name *string策略唯一名称
type *string限流维度: global / per_user / per_ip
requests *integer时间窗口内允许的最大请求数
window *string时间窗口长度，如 1s / 1m / 1h
burstinteger突发流量允许值，超出窗口速率时的短期上限

错误处理

处理策略

网关层统一捕获所有上游服务的错误响应，转换为标准JSON错误格式后返回给客户端。认证错误、限流触发、请求校验由网关中间件直接拦截，不转发到上游。上游服务返回的业务错误通过网关透传，不修改状态码和错误消息。

统一错误响应体
字段类型
codeinteger (HTTP状态码)
errorstring (错误类型名称)
detailstring (详细错误描述，非敏感信息)
400
BadRequest
请求参数校验失败：必填参数缺失、参数格式错误、UUID格式不合法、JSON解析失败等
401
Unauthorized
认证失败：Authorization头缺失、Token格式错误、Token已过期、Token签名无效
403
Forbidden
权限不足：用户角色不满足路径要求、资源不属于用户上下文
404
NotFound
资源不存在：路由匹配不到、请求的资源ID在数据库中不存在
409
Conflict
资源冲突：名称重复、有关联资源阻止操作、有正在执行的冲突任务
429
TooManyRequests
速率限制触发：全局IP限流、用户级限流或特殊端点限流，响应头包含Retry-After

503
