概述

模块: API网关

API网关作为系统的统一入口层，基于Fastify网关框架实现，位于Web管理控制台与后端服务之间。职责涵盖：HTTP请求路由转发（将前端请求分发至项目管理服务、环境管理服务、部署编排服务）、JWT令牌认证与RBAC访问控制、基于令牌桶算法的请求速率限制、CORS跨域策略管理、全量请求/响应审计日志记录。网关不包含业务逻辑，仅做协议转换与横切关注点处理。

字段类型描述

字段类型描述

接口定义 (7)

Login

POST /api/auth/login

用户登录认证，校验用户名密码后签发 JWT 访问令牌。网关自身提供的认证入口，不依赖后端服务

Response: {token: {'type': 'string', 'description': 'JWT 访问令牌'}, expires_in: {'type': 'integer', 'description': '令牌过期时间（秒）'}, user_id: {'type': 'integer', 'description': '用户 ID'}, roles: {'type': 'array', 'item_type': 'string', 'description': '用户角色列表'}}

参数类型描述
body:usernamestring用户名
body:passwordstring密码（传输过程中要求 HTTPS 加密）

CreateProject

POST /api/projects

代理创建项目请求。网关鉴权通过后路由至项目管理服务（CreateProject），请求体透传

Response: {id: {'type': 'integer', 'description': '项目ID'}, name: {'type': 'string', 'description': '项目名称'}, description: {'type': 'string', 'description': '项目描述'}, created_at: {'type': 'datetime', 'description': '创建时间'}}

参数类型描述
header:AuthorizationstringBearer JWT 令牌，必需
body:namestring项目名称，必需
body:descriptionstring项目描述，可选

ListProjects

GET /api/projects

代理获取项目列表请求。网关鉴权后路由至项目管理服务（ListProjects），支持分页参数

Response: {total: {'type': 'integer', 'description': '项目总数'}, items: {'type': 'array', 'item_type': 'object', 'description': '项目列表'}}

参数类型描述
header:AuthorizationstringBearer JWT 令牌，必需
query:pageinteger页码，默认 1
query:page_sizeinteger每页条数，默认 20

CreateEnvironment

POST /api/projects/{projectId}/environments

代理创建部署环境请求。网关鉴权后路由至环境管理服务（CreateEnvironment），路径参数与请求体透传

Response: {id: {'type': 'integer', 'description': '环境ID'}, name: {'type': 'string', 'description': '环境名称'}, tag: {'type': 'string', 'description': '环境标签'}, server_host: {'type': 'string', 'description': '服务器地址'}, server_port: {'type': 'integer', 'description': 'SSH端口'}, username: {'type': 'string', 'description': 'SSH用户名'}, created_at: {'type': 'datetime', 'description': '创建时间'}}

参数类型描述
header:AuthorizationstringBearer JWT 令牌，必需
path:projectIdinteger所属项目 ID
body:namestring环境名称，如 测试线，必需
body:tagstring环境标签，如 test/canary/production，必需
body:server_hoststring远程服务器 IP 或域名，必需
body:server_portintegerSSH 端口，默认 22，必需
body:usernamestringSSH 登录用户名，必需

ConfigureSSHKey

PUT /api/projects/{projectId}/environments/{envId}/key

代理配置 SSH 密钥请求。网关鉴权后路由至环境管理服务（ConfigureSSHKey），路径参数与请求体透传

Response: {status: {'type': 'string', 'description': '配置结果，success/failure'}, fingerprint: {'type': 'string', 'description': '密钥指纹'}}

参数类型描述
header:AuthorizationstringBearer JWT 令牌，必需
path:projectIdinteger项目 ID
path:envIdinteger环境 ID
body:private_keystringSSH 私钥内容（传输时加密），必需
body:passphrasestring密钥口令，可选

TriggerDeployment

POST /api/projects/{projectId}/deployments

代理触发部署请求。网关鉴权后路由至部署编排服务（TriggerDeployment），路径参数与请求体透传

Response: {deployment_id: {'type': 'integer', 'description': '部署记录ID'}, status: {'type': 'string', 'description': '初始状态，pending'}, created_at: {'type': 'datetime', 'description': '创建时间'}}

参数类型描述
header:AuthorizationstringBearer JWT 令牌，必需
path:projectIdinteger项目 ID
body:environment_idinteger目标环境 ID，必需
body:artifact_pathstring可执行文件路径，必需
body:versionstring版本号，用于创建版本文件夹，必需

HealthCheck

GET /api/health

网关健康检查端点，返回网关自身及各后端服务的连通性状态，无需认证

Response: {status: {'type': 'string', 'description': '网关自身状态，ok / degraded / down'}, services: {'type': 'object', 'description': '各后端服务连通性状态映射，如 { "project-service": "ok", "environment-service": "ok" }'}, timestamp: {'type': 'datetime', 'description': '检查时间'}}

⚠️

错误处理

网关层统一捕获所有异常并返回标准化 JSON 错误响应，格式为 { "error": { "code": "...", "message": "...", "request_id": "..." } }。各场景处理策略： 1. 401 未认证：JWT 缺失、过期或签名无效时返回，前端应跳转至登录页。 2. 403 无权限：JWT 有效但当前用户角色不满足 required_roles 时返回。 3. 429 限流触发：令牌桶取令牌失败时返回，响应头附加 X-RateLimit-Remaining: 0 和 Retry-After 秒数。 4. 502 后端不可达：路由目标服务连接超时或拒绝连接时返回，触发自动重试机制（最多 1 次，间隔 500ms），重试仍失败则降级返回。 5. 504 后端超时：后端服务处理超过 30s 阈值时返回，同时记录超时审计日志以便排查。 6. 404 未知路由：无匹配 RouteRule 时返回。 7. CORS 预检：OPTIONS 请求直接返回 204 并写入 CORS 头后结束，不经过认证与路由。 8. 请求体校验：Content-Type 非 application/json 时返回 415，必填字段缺失时返回 422 并指明缺失字段名。
