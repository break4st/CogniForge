概述

模块: Statistics Service

学习统计模块，负责数据的聚合计算与统计分析。采用 异步计算 + 缓存加速 架构：用户请求统计时优先查缓存（Redis），缓存命中直接返回；未命中则投递消息到消息队列（Message Queue），由异步 Worker 消费消息执行聚合计算，结果写入数据库（MySQL/PostgreSQL）和缓存，前端通过轮询或 WebSocket 获取计算结果。缓存键策略采用 'stats:{type}:{dimensionId}' 格式，TTL 1800 秒。聚合计算支持按学生、班级、年级三个维度进行汇总，包括学生人数统计、性别分布、趋势分析等。分层设计：Controller 层处理 HTTP 请求与参数校验 → Service 层实现统计业务逻辑（缓存读取/写入、异步任务投递、聚合计算编排） → Repository 层封装数据库访问。

接口定义 (13)

仪表盘概况查询

GET /api/statistics/dashboard

获取全校统计概况数据，用于首页仪表盘展示，包括学生总数、班级总数、性别分布、全校平均成绩、及格率、优秀率和各年级简要统计。优先查缓存，缓存键 'stats:dashboard:{period}'，TTL 1800 秒。未命中时聚合计算（遍历各年级统计数据求和）后回填缓存。如果所有统计数据均未计算（DB 中无统计记录），返回默认零值而非报错

学生统计查询

GET /api/statistics/students/:studentId

查询单个学生的学习统计数据，包含各项指标及班级内排名。优先查缓存，缓存键 'stats:student:{studentId}:{period}'，TTL 1800 秒。未命中时查 DB 返回，若 DB 中也无数据（从未计算过）则返回 404 并提示'该学生统计数据尚未生成，请触发刷新'。关联 student 表和 class 表获取学生姓名和班级名称

班级统计查询

GET /api/statistics/classes/:classId

查询指定班级的聚合统计数据，包含班级学生总数、性别分布、平均成绩、及格率、优秀率、班级第一名等信息。优先查缓存，缓存键 'stats:class:{classId}:{period}'，TTL 1800 秒。未命中时查 DB。关联 class 表和 grade 表获取班级名称和所属年级名称。班级不存在返回 404（'班级不存在'）

年级统计查询

GET /api/statistics/grades/:gradeId

查询指定年级的聚合统计数据，包含年级下班级总数、学生总人数、性别分布、平均成绩、及格率、优秀率等。优先查缓存，缓存键 'stats:grade:{gradeId}:{period}'，TTL 1800 秒。未命中时查 DB。年级不存在返回 404

成绩分数段分布查询

GET /api/statistics/classes/:classId/score-distribution

查询指定班级的成绩分数段分布，按 '90-100'、'80-89'、'70-79'、'60-69'、'0-59' 五个分数段统计学生人数和占比。优先查缓存，缓存键 'stats:class:{classId}:distribution:{period}'。适用于前端图表展示（柱状图/饼图）。班级不存在返回 404。该接口不存储在 DB 中，每次从 student_statistics 表实时聚合计算

年级分数段分布查询

GET /api/statistics/grades/:gradeId/score-distribution

查询指定年级的成绩分数段分布，逻辑同上，聚合该年级下所有学生数据。缓存键 'stats:grade:{gradeId}:distribution:{period}'

班级趋势查询

GET /api/statistics/classes/:classId/trend

查询指定班级的跨周期趋势数据，返回多个周期的 avgScore、passRate、excellentRate 等指标，用于前端折线图趋势展示。从 class_statistics 表按 class_id 和多个 stat_period 查询。默认返回最近 6 个周期的数据。班级不存在返回 404。缓存键 'stats:class:{classId}:trend'，TTL 3600 秒（趋势数据变更频率低，缓存时间相对更长）

年级趋势查询

GET /api/statistics/grades/:gradeId/trend

查询指定年级的跨周期趋势数据，逻辑同班级趋势。从 grade_statistics 表查询。缓存键 'stats:grade:{gradeId}:trend'，TTL 3600 秒

全局趋势查询

GET /api/statistics/trends/overall

查询全校总体趋势数据，聚合所有年级的统计结果。缓存键 'stats:overall:trend'，TTL 3600 秒。无参数，返回最近 6 个周期的全校级趋势

统计计算刷新（触发异步任务）

POST /api/statistics/refresh

触发统计数据异步重新计算。在 statistics_task 表创建一条任务记录（status='pending'），投递消息到消息队列后立即返回 taskId。前端可轮询任务状态接口获取计算结果。同一个 dimension 不允许并发：如果该 dimension 已有 status='pending' 或 'processing' 的任务，返回 409（'该维度已有正在执行的统计任务'）。type='all' 时刷新全量统计（无需校验并发），但 type='all' 的频率限制为每 5 分钟最多触发一次（使用 Redis 分布式锁，锁键 'stats:refresh:lock'，TTL 300 秒）

统计任务状态查询

GET /api/statistics/tasks/:taskId

查询统计刷新任务的当前状态和进度。用于前端轮询获取异步任务结果。任务不存在返回 404。任务状态为 'completed' 时返回 resultSummary 摘要；'failed' 时返回 errorMessage 供排查

统计周期列表查询

GET /api/statistics/periods

获取所有可用的统计周期列表，用于前端下拉选择器切换统计周期。从 student_statistics 表 DISTINCT stat_period 获取。按周期标识降序排列（最近的在最前）。无参数。缓存键 'stats:periods'，TTL 3600 秒

班级统计列表查询

GET /api/statistics/classes

分页查询所有班级的统计数据概览，每项包含班级基本信息+核心统计指标（学生数、平均分、及格率等）。该接口不查缓存，直接从 class_statistics 表分页查询，支持按 gradeId 过滤。适用于班级统计概览页面

⚠️

错误处理

全局统一返回标准 JSON 格式：{ code: number, message: string, details?: any }。4xx 错误：统计数据未生成返回 404（message: '统计数据尚未生成，请触发刷新'），班级/年级不存在返回 404，同一维度并发刷新返回 409（message: '该维度已有正在执行的统计任务'），全量刷新频率超限返回 429（message: '全量刷新过于频繁，请 5 分钟后再试'），type 值非法返回 400（message: '参数错误' 并 details 指明 type 取值范围）。5xx 错误统一返回 500（message: '系统内部错误'），完整错误栈记录到服务日志。缓存操作（Redis）失败时降级为直接查询 DB，不阻塞正常业务流程。缓存键采用统一前缀 'stats:' 命名空间，便于管理和批量失效。统计数据变更后（刷新完成）需主动失效对应缓存：student 级别失效 'stats:student:{id}:*' 和关联的班级/年级/仪表盘缓存；class 级别失效 'stats:class:{id}:*' 和关联的年级/仪表盘缓存；grade 级别失效 'stats:grade:{id}:*' 和仪表盘缓存；type=all 时批量失效所有 stats: 前缀的缓存。消息队列投递失败时任务记录保留在 DB（status='pending'），通过定时任务（cron 每 5 分钟扫描超过 10 分钟仍为 pending 的任务）重新投递。异步 Worker 执行统计计算时遇到数据异常（如除零、空数据集）记录警告日志并返回零值而非中断流程。statistics_task 表中的任务记录保留最近 30 天，超过 30 天的由定时清理任务（每日凌晨 3:00 执行）物理删除。
