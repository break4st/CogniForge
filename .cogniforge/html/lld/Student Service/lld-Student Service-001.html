概述

模块: Student Service

基于 RESTful 架构的学生档案管理服务，对外提供学生信息的增删改查及搜索能力。采用分层设计：Controller 层处理 HTTP 请求与参数校验 → Service 层实现业务逻辑（学号去重、班级归属校验、搜索解析） → Repository 层封装数据库访问。数据库使用 MySQL/PostgreSQL，学生表作为核心持久化存储，学号字段建立唯一索引保证全局唯一。搜索功能通过数据库的 LIKE 模糊匹配实现（按学号或姓名），支持分页返回。与 Class Service 存在调用依赖：创建/更新学生时需验证 classId 对应的班级是否存在，删除学生时需通知 Class Service 更新班级人数缓存。

接口定义 (7)

学生列表查询

GET /api/students

分页查询学生列表，支持按关键词搜索学号或姓名、按班级筛选。条件之间为 AND 关系

学生详情查询

GET /api/students/:id

根据 ID 获取单个学生的完整信息，包含班级名称。返回 404 当学生不存在

创建学生

POST /api/students

新增一条学生档案记录。校验学号唯一性（学号重复返回 409）、班级 ID 有效性（调用 Class Service 校验，班级不存在返回 400）

更新学生

PUT /api/students/:id

更新指定学生的基本信息。学号变更时校验唯一性（排除自身）。classId 变更时校验新班级的有效性

删除学生

DELETE /api/students/:id

逻辑删除指定学生的档案记录（设置 deleted_at 时间戳），不物理删除。删除成功需通知 Class Service 刷新该班级的学生人数缓存

搜索学生

GET /api/students/search

精简版搜索接口，不返回分页元信息，适用于下拉选择器等组件快速查找。keyword 为空时返回空列表

批量查询学生

GET /api/students/batch

根据 ID 列表批量查询学生基本信息，用于被 Class Service / Statistics Service 内部调用获取学生数据

⚠️

错误处理

全局统一返回标准 JSON 格式：{ code: number, message: string, details?: any }。4xx 错误携带具体校验提示：学生不存在返回 404（message: '学生不存在'），学号重复返回 409（message: '学号已存在'），班级无效返回 400（message: '指定的班级不存在'），参数格式错误返回 400（message: '参数错误' 并 details 标明具体字段）。5xx 错误统一返回 500（message: '系统内部错误'），完整错误栈记录到服务日志。逻辑删除的记录在列表查询和详情查询中均被过滤（WHERE deleted_at IS NULL），若通过 ID 查询到已逻辑删除的记录也返回 404。批量操作（batch 接口）中，单个 ID 不存在不整体失败，而是在返回结果中标记该 ID 对应的记录为 null。
