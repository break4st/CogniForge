概述

模块: Student Service

学生信息管理核心服务，负责学生基础数据的增删改查。作为微服务架构中的领域服务之一，通过 REST 内部接口对外提供学生信息 CRUD 能力，消费者为 API Gateway。服务内部职责包括：1）学生基本信息的创建（含学号唯一性校验）、修改、删除；2）按条件（姓名、学号、班级）分页查询学生信息；3）学生-班级关联关系的维护（创建/更新时校验班级存在性，依赖 Class Service 的班级存在性校验接口）；4）学号 student_no 全局唯一性校验，防止重复创建。本服务不处理认证鉴权——该职责由 API Gateway 统一负责。数据存储采用关系型数据库，学生信息主表为 students，关联班级 ID（class_id）引用 Class Service 侧的班级数据（通过外键或应用层校验保证引用完整性）。

接口定义 (6)

学生管理内部接口（创建）

POST /internal/students

创建学生记录。接收学生基本信息，包含学号、姓名、联系方式及选填的班级 ID。核心校验规则：1）学号 student_no 必填且全局唯一，重复时返回 409 Conflict；2）如提供了 class_id，需调用 Class Service 接口 GET /internal/classes/{id}/exists 校验班级存在性，班级不存在时返回 422 Unprocessable Entity；3）name、contact_phone、contact_email 为必填字段，缺失时返回 422。创建成功返回 201 及完整学生信息（含自动生成的 id 和 created_at）。

参数类型描述
namestring学生姓名，必填
student_nostring学号，全局唯一，必填
contact_phonestring联系电话，必填
contact_emailstring联系邮箱，必填
class_idnumber (optional)所属班级 ID，选填，提供时需校验班级存在性

学生管理内部接口（更新）

PUT /internal/students/{id}

更新指定学生的信息。可修改字段：姓名、联系电话、联系邮箱、班级 ID。学号 student_no 不可修改（如需修改学号需删除重建）。核心校验规则：1）路径参数 id 对应的学生不存在时返回 404；2）如提供了 class_id，需调用 Class Service 接口 GET /internal/classes/{id}/exists 校验班级存在性；3）至少提供一个可修改字段，全空时返回 422。更新成功返回 200 及更新后的学生信息（含 updated_at 时间戳）。

参数类型描述
idnumber学生 ID，路径参数
namestring (optional)学生姓名，选填
contact_phonestring (optional)联系电话，选填
contact_emailstring (optional)联系邮箱，选填
class_idnumber (optional)所属班级 ID，选填，提供时需校验班级存在性

学生管理内部接口（删除）

DELETE /internal/students/{id}

删除指定学生记录。路径参数 id 对应的学生不存在时返回 404；删除成功返回 204 No Content，无响应体。注意：删除学生前无需确认关联数据（统计数据等由 Statistics Service 自行处理数据一致性）。

参数类型描述
idnumber学生 ID，路径参数

学生管理内部接口（查询列表）

GET /internal/students

按条件分页查询学生列表。支持按姓名（模糊匹配）、学号（精确匹配）、班级 ID 筛选。分页参数 page 默认 1，page_size 默认 20，最大 page_size 不超过 100。返回结果包含 total 总数、当前页码、每页条数及 items 数组。响应中不包含 class_name 字段（由 API Gateway 负责通过 Class Service 回填前端展示用的班级名称）。

参数类型描述
namestring (optional)按姓名筛选，模糊匹配
student_nostring (optional)按学号筛选，精确匹配
class_idnumber (optional)按班级筛选，精确匹配
pagenumber (optional)页码，默认 1
page_sizenumber (optional)每页条数，默认 20，最大 100

学生管理内部接口（详情）

GET /internal/students/{id}

查询指定学生的详细信息。返回结果包含学生全部字段（id、name、student_no、contact_phone、contact_email、class_id、created_at、updated_at）。学生不存在时返回 404。此接口不返回 class_name，由 API Gateway 根据 class_id 回填。

参数类型描述
idnumber学生 ID，路径参数

班级存在性校验（consumer）

GET /internal/classes/{id}/exists

Student Service 在创建或更新学生时，若请求中包含 class_id，需调用此接口校验目标班级是否存在。调用方式：HTTP GET 请求 Class Service。响应中 exists 为 true 时班级存在，为 false 时班级不存在，此时 Student Service 应返回 422 Unprocessable Entity 并提示班级不存在。此接口定义在 SAD 中，本处引用以说明调用依赖。

参数类型描述
idnumber班级 ID，路径参数
⚠️

错误处理

Student Service 按以下规则处理异常：1）学号重复——创建学生时 student_no 与已有记录冲突，返回 409 Conflict，响应体为 {"error": "conflict", "message": "学号已存在"}；2）班级不存在——创建/更新时 class_id 指向不存在的班级，返回 422 Unprocessable Entity，响应体为 {"error": "validation_error", "message": "班级不存在", "field": "class_id"}；3）必填字段缺失——创建时缺少 name/student_no/contact_phone/contact_email 中任一字段，返回 422，响应体中列出缺失字段；4）资源不存在——按 id 查询/更新/删除时记录不存在，返回 404 Not Found，响应体为 {"error": "not_found", "message": "学生不存在"}；5）分页参数越界——page_size 超过 100 时截断为 100，page 小于 1 时重置为 1，不返回错误；6）下游依赖超时——调用 Class Service 班级存在性校验接口超过 5 秒未响应时，当前操作失败，返回 502 Bad Gateway，响应体为 {"error": "upstream_error", "message": "班级服务不可用"}。所有操作记录结构化日志，包含请求路径、方法、耗时、操作人（由 API Gateway 在请求头传递的用户标识）和操作结果状态，日志级别：正常操作 INFO，业务校验失败 WARN，系统异常 ERROR。
