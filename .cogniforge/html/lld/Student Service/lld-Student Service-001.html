概述

模块: Student Service

负责学生领域核心业务，管理学生从入学到毕业全生命周期的信息维护，包括基本信息管理、学号唯一性校验、学生检索以及数据的导入导出。提供 7 个 REST API 作为 provider 供 API Gateway 调用；作为 consumer 依赖 Class Service 的班级查询接口与 Grade Service 的年级查询接口完成跨服务数据校验；在学生数据发生变更时向消息队列的 student.data.changed topic 发送事件通知，驱动 Statistics Service 异步更新统计结果。

接口定义 (12)

StudentInfoAPI

GET /api/v1/students

（Provider）分页查询学生列表，支持按姓名（模糊搜索）、学号（精确匹配）、年级 ID、班级 ID 等多条件组合筛选。命中缓存则直接返回缓存结果；未命中则查询数据库后将结果写入缓存。

StudentDetailAPI

GET /api/v1/students/{id}

（Provider）根据 ID 获取单个学生的完整详细信息。命中缓存则直接返回；未命中则查询数据库后回写缓存。

CreateStudentAPI

POST /api/v1/students

（Provider）创建新学生记录。调用前先校验学号唯一性（查询 student_no 索引），若不唯一则返回 409 Conflict；校验 grade_id 是否存在（调用 GradeService.GradeDetailAPI）以及 class_id 是否属于该 grade（调用 ClassService.ClassDetailAPI）且班级未超容量上限；校验通过后写入数据库，清除相关缓存条目，并发送 student.data.changed 事件到 MQ。入学日期由服务端自动设为当前日期。

UpdateStudentAPI

PUT /api/v1/students/{id}

（Provider）更新学生信息，支持部分字段更新（PATCH 语义）。若涉及 grade_id/class_id 变更，需校验新年级/班级是否存在且容量未超限；更新成功后清除相关缓存条目，并发送 student.data.changed 事件到 MQ。

DeleteStudentAPI

DELETE /api/v1/students/{id}

（Provider）根据 ID 删除学生记录。删除前校验学生是否存在；删除成功后清除缓存条目，并发送 student.data.changed 事件到 MQ。

StudentImportAPI

POST /api/v1/students/import

（Provider）批量导入学生信息，接收 CSV/Excel 文件。逐行解析并校验：学号唯一性、必填字段完整性、年级/班级存在性。全部校验完成后再执行批量写入（事务内逐行 insert，不因单行失败回滚全部），最终返回导入统计。

StudentExportAPI

GET /api/v1/students/export

（Provider）导出学生信息为 CSV/Excel 文件。支持按 grade_id 和 class_id 筛选导出范围，同步返回文件流。

StudentEventTopic

topic: student.data.changed

（Provider — 出站 MQ）当学生数据发生 created/updated/deleted 变更时，向消息队列的 student.data.changed topic 发送事件通知，供 Statistics Service 异步消费以更新统计结果。消息投递采用至少一次语义。

GradeDetailAPI

GET /api/v1/grades/{id}

（Consumer — Grade Service）根据 ID 获取年级详细信息，用于创建/更新学生时校验 grade_id 有效性

GradeInfoAPI

GET /api/v1/grades

（Consumer — Grade Service）分页查询年级列表，支持按学年和学段过滤

ClassDetailAPI

GET /api/v1/classes/{id}

（Consumer — Class Service）根据 ID 获取班级详细信息，用于创建/更新学生时校验 class_id 有效性以及班级容量是否已达上限

ClassInfoAPI

GET /api/v1/classes

（Consumer — Class Service）分页查询班级列表，支持按年级过滤

⚠️

错误处理

Student Service 统一返回 JSON 错误体 {"code": "错误码", "message": "错误描述"}。1）学号重复时 CreateStudentAPI 返回 409 Conflict，错误码 'STUDENT_NO_DUPLICATE'。2）学生不存在时 StudentDetailAPI / UpdateStudentAPI / DeleteStudentAPI 返回 404 Not Found，错误码 'STUDENT_NOT_FOUND'。3）请求参数校验失败（如必填字段缺失、birth_date 格式错误）返回 400 Bad Request，错误码 'INVALID_PARAMETER'。4）引用的年级或班级不存在（via Grade Service / Class Service）返回 422 Unprocessable Entity，错误码 'REFERENCE_NOT_FOUND'，message 中指明具体引用类型和 ID。5）班级人数已达容量上限（创建或移动学生时）返回 422 Unprocessable Entity，错误码 'CLASS_CAPACITY_EXCEEDED'。6）导入文件格式不支持或超过 10MB 限制返回 400 Bad Request，错误码 'IMPORT_FILE_INVALID'。7）批量导入过程不因单行错误回滚整个事务，逐行记录错误到 errors 数组返回。8）调用下游服务（Grade/Class Service）超时阈值为 5 秒，超时或连接失败返回 503 Service Unavailable，错误码 'DEPENDENCY_TIMEOUT'。9）数据库操作异常返回 500 Internal Server Error，错误码 'DATABASE_ERROR'。
