概述

Web控制台
🖥️ 前端
基于React的浏览器端单页应用，提供项目、环境、部署全流程的可视化操作界面。用户通过Web控制台完成项目管理、环境配置、SSH密钥管理、一键部署、部署进度实时查看和版本回溯等操作。前端通过HTTP/REST与API网关通信，通过WebSocket接收部署状态实时推送。采用JWT Bearer Token进行身份认证，根据用户角色（admin/operator/developer/viewer）控制界面功能和路由访问权限。
依赖: API网关项目管理服务环境管理服务部署编排服务密钥管理服务文件存储
ReactAnt DesignWebSocketJWT + RBAC

组件树 (1)

App/

应用根组件，初始化全局 Provider、路由配置和 Error Boundary

行为
  • mount 时加载 AuthProvider 检查本地存储中是否存在有效的 JWT token
  • token 有效时自动跳转至 /projects，无效时跳转至 /login
  • 全局 axios 响应拦截器在 401 时清除 token 并跳转登录页
  • 使用 React.lazy 和 Suspense 按页面拆分代码，实现路由级懒加载
边界情况
  • ⚠️ JWT token 已过期但 refresh_token 仍有效时自动静默刷新 token 后重试原请求
  • ⚠️ 全局 Error Boundary 捕获未预期的渲染异常，展示降级 UI 而非白屏
  • ⚠️ 网络离线时展示离线提示，在线恢复后不自动刷新页面
AuthProvidercontext/AuthProvider

全局认证上下文 Provider，管理 JWT 令牌的存储、刷新、解析和用户会话状态

Events
@onAuthStateChange(auth_state)@onLogout(void)
State
auth_state: auth_stateloading: boolean
行为
  • mount 时从 localStorage 读取 access_token 和 refresh_token
  • access_token 存在时解析 JWT payload 恢复 user_info
  • 提供 login(username, password) 方法调用 POST /api/v1/auth/login
  • 登录成功后存储 token 到 localStorage，更新 auth_state
  • 提供 logout() 方法清除 token 并跳转 /login
  • axios 请求拦截器自动在 Authorization header 附加 Bearer token
  • axios 响应拦截器捕获 401 后尝试用 refresh_token 调用 POST /api/v1/auth/refresh 静默续期
  • refresh_token 也过期时清除所有 token 跳转 /login
边界情况
  • ⚠️ 多点登录：同一账号在其他设备登录不感知，由服务端 token 过期机制保证
  • ⚠️ token 刷新并发安全：多个请求同时 401 时只发起一次 refresh 请求，其他请求排队等待新 token
  • ⚠️ localStorage 不可用时（隐私模式）：降级为内存存储，页面刷新后需重新登录
Routerrouter/AppRouter

应用路由配置，基于 react-router-dom v6，根据认证状态控制路由访问

行为
  • 未认证用户访问受保护路由时自动重定向到 /login
  • 登录成功后自动重定向到 /projects
  • 路由切换时自动滚动到页面顶部
边界情况
  • ⚠️ 不存在的路由路径展示 404 Not Found 页面
  • ⚠️ 无权限访问的路由（根据角色判断）展示 403 Forbidden 页面

缓存策略

采用按需缓存 + 手动失效策略：1) 项目列表缓存（project_list_cache）在创建/编辑/删除项目后失效并刷新；2) 环境列表和部署历史按项目ID缓存，切换项目时清除对应缓存；3) 密钥列表在创建/更新/吊销密钥后失效刷新；4) WebSocket 状态实时更新不同步到全局 Store，仅在 DeployExecutePage 和 DeployDetailPage 页面级状态中维护；5) 所有缓存均使用 React Query（@tanstack/react-query）的 staleTime 控制，列表数据默认 staleTime=30秒，详情数据默认 staleTime=60秒。页面离开时不清除缓存（支持前进/后退快速返回），但跨天访问自动失效。

交互流程 (6)

用户登录流程

用户通过用户名密码登录系统，获取 JWT token 后进入主界面

1
用户打开 Web 控制台，未认证状态下自动跳转至 /login 登录页
2
用户在登录表单中输入用户名和密码，点击「登录」按钮
3
前端调用 POST /api/v1/auth/login 发送认证请求
4
登录成功后 API 返回 access_token、refresh_token 和过期时间
5
前端将 token 存储在 localStorage，解析 JWT payload 获取用户信息
6
AuthProvider 更新认证状态，路由自动跳转至 /projects 项目列表页
7
用户进入主界面，侧边栏加载项目列表，顶部导航栏显示用户信息
8
用户关闭浏览器后再打开，AuthProvider 从 localStorage 恢复 token，校验有效性后进入主界面
一键部署流程

用户选择项目和版本，执行一键部署并实时查看部署进度

1
用户在侧边栏项目选择器中切换到目标项目
2
从项目详情页点击「执行部署」进入 /projects/:projectId/deploys/execute 部署执行页
3
页面 mount 时并行加载环境列表（GET /api/v1/environments）和文件版本列表（GET /api/v1/files/versions）
4
用户从环境列表中选择一个 ONLINE 状态的部署环境
5
用户从版本列表中选择要部署的目标版本
6
点击「开始部署」按钮，弹出确认对话框展示部署摘要
7
确认后调用 POST /api/v1/deploys 发起部署请求
8
API 返回 202 Accepted 及 deploy_id
9
前端立即建立 WebSocket 连接 ws://host/api/v1/deploys/{deploy_id}/status
10
DeployProgressPanel 展示整体进度条和当前步骤状态
11
WebSocket 推送各步骤状态：文件传输 → 创建目录 → 生成脚本 → 执行命令
12
用户实时看到每个步骤的状态变更和日志输出
13
部署完成后 WebSocket 推送最终状态（SUCCESS/FAILED），连接自动关闭
14
页面展示最终结果横幅：成功时展示绿色成功通知及耗时；失败时展示红色失败通知及错误详情
15
用户点击「查看详情」跳转部署详情页查看步骤时间线和完整日志
版本回滚流程

用户从部署历史中选择一个历史版本，发起回滚部署

1
用户进入项目部署历史页 /projects/:projectId/deploys
2
页面加载部署历史列表（GET /api/v1/deploys/history）
3
用户找到目标 SUCCESS 状态的部署记录，点击操作列的「回滚」按钮
4
弹出 Popconfirm 确认框，展示回滚版本号和环境名称
5
用户确认后，前端根据该部署记录的 version 和 file_id 调用 POST /api/v1/deploys 创建新部署
6
API 返回新部署的 deploy_id 和初始状态
7
跳转至新的部署详情页 /projects/:projectId/deploys/:newDeployId
8
自动连接 WebSocket 查看回滚部署的实时进度

错误处理

处理策略

前端错误处理分四层：1) 网络层——axios/fetch 拦截器统一捕获 HTTP 错误状态码，401 自动跳转登录页并清除 token，403 展示无权限提示，429 展示限流提示并显示 Retry-After 倒计时，5xx 展示服务不可用提示；2) 业务层——API 返回的 code/error/detail 结构由统一错误解析器解析，根据 error_code 映射到中文本地化错误消息；3) 表单层——Ant Design Form 组件校验规则捕获前端参数校验错误，实时展示字段级别的错误提示；4) 运行时层——React Error Boundary 包裹各页面组件，捕获未预期的渲染异常，展示友好降级界面并提供错误报告入口。所有错误消息使用 Ant Design message/notification 组件展示，支持自动消失和手动关闭。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
401
未认证或会话过期
JWT token 缺失、无效或已过期。全局 axios 响应拦截器检测到 401 时自动清除本地存储的 token、跳转 /login 页面，并展示「登录会话已过期，请重新登录」提示
403
权限不足
用户角色不满足接口要求的 RBAC 角色。统一展示「您没有执行此操作的权限，请联系管理员」通知，并隐藏对应的操作按钮
404
资源不存在
查询的项目、环境、密钥、部署记录或文件在系统中不存在。展示对应资源的「未找到」提示，列表页保持原有内容不自动跳转
409
操作冲突
并发部署冲突、名称重复、密钥已吊销等业务冲突。展示具体冲突原因提示，引导用户检查当前状态后重试
429
请求过于频繁
突破 API 网关限流阈值。展示「操作过于频繁，请稍后再试」提示，并显示建议等待时间
500
服务端错误
后端服务异常。展示「服务暂时不可用，请稍后重试」提示，并附带错误追踪 ID（如有）供排查
502
服务不可达
后端服务连接失败或超时。展示「后端服务暂时不可达，请检查网络或联系运维」提示
WS_DISCONNECT

部署实时状态 WebSocket 连接意外断开。自动重连最多 3 次，重连间隔 2s/5s/10s 递增，重连失败后展示「实时状态连接已断开，请刷新页面重试」提示，并显示最后一次收到的状态
NETWORK_ERROR
