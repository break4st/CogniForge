概述

Key Management Service
密钥管理服务，负责SSH密钥对的导入、存储和管理，确保密钥信息安全。提供SSH密钥对的导入、查询以及内部服务间的私钥解密获取能力。对导入的私钥进行加密存储，密钥列表接口仅暴露元数据（名称、指纹、类型），不返回私钥内容。内部接口提供给Deployment Orchestrator在部署流程中获取解密后的SSH私钥。所有操作通过Audit Service记录审计日志。
依赖: Primary DatabaseAudit Service
PythonFastAPIPostgreSQL

数据模型 (1)

引用模型 1

🔗 ssh_keys引用

↳ 引用自: lld-Primary Database-001 / ssh_keys

SSH密钥表。存储导入的SSH密钥对信息，包括密钥元数据（名称、类型、指纹）和加密后的私钥内容。private_key_encrypted字段使用服务层加密后在存储层持久化，确保数据库层面的密钥数据安全。public_key以明文存储用于展示和指纹计算。type字段枚举RSA、ECDSA、Ed25519三种算法类型，由导入时指定。通过created_by字段记录密钥导入操作人，用于审计追溯。

字段
字段名类型描述
id *uuid密钥唯一标识（主键），服务层自动生成UUID v4
name *varchar(255)密钥名称，用户在导入时指定的可读标识
public_key *textSSH公钥内容（OpenSSH格式明文存储）
private_key_encrypted *text加密后的SSH私钥内容，服务层使用AES-256-GCM加密后持久化
type *varchar(20)密钥算法类型枚举：RSA、ECDSA、Ed25519
fingerprint *varchar(64)SSH公钥指纹（SHA256），导入时由服务根据公钥内容计算
created_by *varchar(255)密钥导入操作人标识，从认证上下文中获取
created_at *timestamp记录创建时间，默认为当前UTC时间
updated_at *timestamp最后更新时间，密钥信息变更时自动更新

接口定义 (3)

POST/api/keys导入SSH密钥
导入SSH密钥对。校验请求参数（name、public_key、private_key、type必填）。校验name不重复。校验public_key是否为合法的OpenSSH格式公钥。校验type是否在允许的枚举范围（RSA、ECDSA、Ed25519）内。校验通过后计算公钥的SHA256指纹，对private_key使用AES-256-GCM进行加密，将密钥元数据和加密后的私钥持久化到ssh_keys表。通过Audit Service记录"key.import"审计日志。返回201及密钥元数据，不返回私钥内容。
参数类型描述
namestring密钥名称，在项目中应唯一标识
public_keystringSSH公钥内容（OpenSSH authorized_keys格式）
private_keystringSSH私钥内容，传输过程中使用HTTPS加密，存储前由服务层加密
typeenum(RSA, ECDSA, Ed25519)密钥算法类型，仅支持RSA、ECDSA、Ed25519三种
Response 201

GET/api/keys查询SSH密钥列表
查询SSH密钥列表（不含私钥内容）。支持分页查询，返回密钥元数据列表（id、name、type、fingerprint、created_at）。按created_at降序排列，最新导入的密钥在前。列表接口不返回私钥内容，确保密钥信息安全。通过page和page_size参数控制分页，返回items数组和total总数。

GET/internal/keys/{id}/private获取SSH私钥（内部）
Deployment Orchestrator获取解密后的SSH私钥，仅内部服务间调用。根据路径参数id在ssh_keys表查询密钥记录，对private_key_encrypted使用AES-256-GCM解密后返回私钥明文。通过Audit Service记录"key.access"审计日志，记录访问时间、操作人和目标密钥ID。仅允许内部网络调用，拒绝外部请求。

错误处理

处理策略

统一错误处理，所有接口返回标准JSON错误格式。请求参数校验在Controller层通过FastAPI/Pydantic模型校验拦截，业务逻辑异常（密钥名称冲突、密钥不存在）在Service层显式抛出，私钥加解密异常由全局异常处理器捕获并记录日志后返回通用错误信息。错误响应不包含密钥内容或加解密密钥等敏感信息。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
400
参数校验错误
请求参数校验失败。包括必填字段缺失（name、public_key、private_key、type）、type值不在枚举范围（RSA、ECDSA、Ed25519）、公钥格式不合法（非OpenSSH格式）、page/page_size参数为负数或page_size超过100。在Controller层通过FastAPI/Pydantic请求模型自动校验，校验不通过直接返回400及具体错误字段说明。
403
内部接口访问拒绝
非内部网络请求尝试访问/internal/前缀接口时触发。由内部网络中间件检测请求来源IP和网络标识，非内部网络请求直接拒绝返回403，不暴露内部接口存在信息。
404
资源不存在
根据密钥ID在ssh_keys表查询时未找到对应记录。Service层在查询后判断结果，结果为空时转换为404响应，detail字段包含请求的密钥ID。
409
资源冲突
导入密钥时，name字段在ssh_keys表中已存在同名记录。Service层在校验阶段查询name唯一性，发现重复时返回409及冲突提示，建议用户使用不同的密钥名称。
500
服务器内部错误
服务运行时发生未捕获异常，包括私钥AES-256-GCM加密/解密失败（密钥或算法配置错误）、数据库连接/写入/查询异常、公钥指纹计算异常等。由全局异常处理器统一捕获，记录完整异常堆栈到应用日志，响应中仅返回通用"服务器内部错误"信息，不暴露密钥内容或加解密密钥等敏感信息。
