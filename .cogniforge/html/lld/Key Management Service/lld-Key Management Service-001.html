概述

Key Management Service
负责 SSH 密钥的安全存储、管理和生命周期控制。提供 SSH 私钥的加密存储与解密、密钥上传与删除、密钥与环境关联管理等核心功能，并为 SSH Execution Service 提供密钥解密内部接口。所有私钥内容在存储前使用 AES-256 加密，内存中使用后及时清除。
依赖: API GatewayPrimary DatabaseSSH Execution ServiceAudit Service
PythonFastAPIPostgreSQL 15

数据模型 (2)

引用模型 1

🔗 keys引用

↳ 引用自: lld-Primary Database-001 / keys

SSH 密钥表，存储密钥元数据和加密后的私钥内容。私钥在写入前使用 AES-256-CBC 加密，密钥指纹在写入时自动计算。支持可选密码短语的加密存储。

密钥加密配置，定义 AES 加密算法参数和主密钥来源。配置加载后常驻内存，用于私钥的加密和解密操作。

接口定义 (4)

POST/api/keysUploadKey
上传 SSH 私钥。接收 PEM 格式的私钥内容和可选密码短语，验证私钥格式合法性，计算密钥指纹，使用 AES-256-CBC 加密私钥内容后持久化到数据库。返回密钥 ID、名称、指纹和创建时间。
Response 201

错误处理

Key Management Service 对各类异常进行统一处理：(1) 参数校验异常 — 请求体 JSON 解析失败、必填字段缺失、密钥名称重复、私钥非 PEM 格式返回 400 Bad Request，附带具体校验错误详情；(2) 资源不存在 — 密钥 ID 在数据库中不存在时返回 404 Not Found；(3) 业务冲突 — 密钥已被环境绑定引用时返回 409 Conflict，提示用户先解除环境关联后再删除；(4) 私钥解析失败 — 私钥内容损坏或密码短语错误时返回 422 Unprocessable Entity；(5) 加密解密异常 — AES 加密解密操作失败（主密钥不可用、密文损坏等）记录完整错误栈并返回 500 Internal Server Error，确保私钥明文不写入日志；(6) 数据库异常 — 数据库连接失败或写入冲突时记录错误上下文，返回 500 Internal Server Error。所有错误响应体统一格式为: { code: integer, error: string, detail: string }。密钥明文在内存中使用后通过 byte 数组覆写方式及时清除，防止敏感信息残留。
