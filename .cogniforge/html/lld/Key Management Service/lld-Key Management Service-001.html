概述

Key Management Service
密钥管理微服务，负责SSH密钥的上传、安全存储、配置管理和连通性测试。提供密钥的AES-256-GCM加密存储、密钥与环境的关联绑定、SSH连接连通性测试、密钥删除和轮换以及密钥文件权限管理能力。
依赖: Primary Database
Python 3.11+FastAPIMySQL 8.0Paramiko
🗄️

接口定义 (2)

POST/api/environments/{env_id}/keysSSH Key Upload API
为指定环境上传SSH密钥。接收密钥类型和私钥文本内容，校验密钥格式合法性（PEM/OpenSSH格式），计算密钥指纹，使用AES-256-GCM加密密钥内容后存储密钥元数据到数据库，返回密钥ID、类型、指纹和创建时间。
参数类型描述
env_idinteger环境ID（路径参数）
key_typeenum密钥类型：rsa|ed25519
key_contentstringSSH私钥文本内容（PEM或OpenSSH格式）
passphrasestring密钥口令，可选
Response 201
字段类型
idinteger
env_idinteger
key_typestring
fingerprintstring
created_atdatetime

⚠️

错误处理

1）参数校验错误（400）：密钥类型不在[rsa,ed25519]范围内、密钥内容非合法PEM/OpenSSH格式、口令格式不合法时返回400，响应体包含具体校验失败原因。2）资源不存在（404）：env_id引用的环境在environments表中不存在时返回404；该环境未配置SSH密钥时同样返回404。3）资源冲突（409）：尝试为已有密钥的环境上传新密钥时返回409 Conflict，提示先删除现有密钥。4）SSH连接失败（502）：目标主机不可达（DNS解析失败、连接超时）、SSH认证失败（密钥不匹配、口令错误）、传输层错误等场景返回502，响应体包含连接失败的具体原因描述但不暴露密钥材料等敏感信息。5）加密/解密错误（500）：AES-256-GCM加密或解密操作失败时记录错误日志，不泄露密钥材料和明文内容。6）数据库错误：数据库连接失败或查询超时（默认5秒超时阈值），记录错误日志后返回500，不暴露数据库内部细节。7）内部错误（500）：所有未捕获异常统一返回500，响应体包含请求ID以便链路追踪。
