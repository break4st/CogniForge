概述

模块: Web UI

基于现代前端框架（如 Vue 3 / React）构建的单页应用（SPA），通过 API Gateway 与后端微服务通信。面向教务管理员、班主任、教师、校长及家长等不同角色提供差异化视图，包含学生管理、班级管理、年级管理、统计看板等核心功能模块。所有业务接口请求均经过 API Gateway 统一路由与鉴权，前端不直接访问后端微服务。

接口定义 (17)

AuthVerifyAPI

POST /api/v1/auth/login

用户登录认证，提交用户名与密码，获取 JWT Token 和角色信息

StudentInfoAPI

GET /api/v1/students

分页查询学生列表，支持按姓名、学号、年级、班级等多条件组合筛选

StudentDetailAPI

GET /api/v1/students/{id}

获取单个学生的完整详细信息

CreateStudentAPI

POST /api/v1/students

创建新学生记录，学号必须唯一

UpdateStudentAPI

PUT /api/v1/students/{id}

更新学生信息，支持部分字段更新

DeleteStudentAPI

DELETE /api/v1/students/{id}

根据 ID 删除学生记录

StudentImportAPI

POST /api/v1/students/import

批量导入学生信息，支持 CSV/Excel 文件上传

StudentExportAPI

GET /api/v1/students/export

导出学生信息为 CSV/Excel 文件

ClassInfoAPI

GET /api/v1/classes

分页查询班级列表，支持按年级过滤

ClassDetailAPI

GET /api/v1/classes/{id}

获取班级详细信息，包括班主任和学生人数

CreateClassAPI

POST /api/v1/classes

创建新班级

ClassStudentsAPI

GET /api/v1/classes/{id}/students

查询指定班级的学生名单

GradeInfoAPI

GET /api/v1/grades

分页查询年级列表，支持按学年和学段过滤

GradeDetailAPI

GET /api/v1/grades/{id}

获取年级详细信息

CreateGradeAPI

POST /api/v1/grades

创建新年级

StatisticsAPI

GET /api/v1/statistics/overview

获取统计概览数据，支持按学生/班级/年级维度查看

StatisticsExportAPI

GET /api/v1/statistics/export

导出统计报表，支持 CSV/PDF 格式

⚠️

错误处理

前端统一通过 HTTP 拦截器处理异常响应：4xx 类错误根据状态码和角色跳转登录页或提示权限不足；5xx 类错误展示全局错误提示并记录日志。请求超时阈值为 15 秒，超时后提示用户重试。表单提交时启用前端字段校验，如学号格式、必填项检查等，校验未通过不发起请求
