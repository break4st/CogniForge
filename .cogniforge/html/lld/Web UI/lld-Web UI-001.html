概述

模块: Web UI

基于 Vue.js 3 + Vite 的单页应用，采用 Composition API + <script setup> 模式开发。页面布局采用左侧导航栏 + 右侧内容区的经典管理后台结构。状态管理使用 Pinia，路由使用 Vue Router 4，HTTP 通信使用 Axios。图表展示使用 ECharts。项目以 views（页面级组件）→ components（可复用 UI 组件）→ api（接口封装层）→ stores（状态管理）→ router（路由配置）的目录结构组织代码。

错误处理

HTTP 请求异常统一由 Axios 响应拦截器捕获，按 status code 分类处理：4xx 错误在页面顶部以黄色警告条展示后端返回的错误消息（如学号重复、资源不存在），5xx 错误展示红色错误提示并附带'系统繁忙，请稍后重试'文案。网络断开时展示全页遮罩层提示'网络连接已断开'。表单校验在前端做第一道防线（必填项、格式校验），提交后即使后端返回 400 也继续展示后端的具体校验提示，避免前后端校验不一致时用户困惑。所有列表页加载中展示骨架屏，查询失败时列表区域展示空状态插画+重试按钮。
