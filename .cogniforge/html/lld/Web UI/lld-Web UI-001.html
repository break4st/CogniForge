概述

模块: Web UI

Web UI 是基于 SPA 架构的前端应用，面向管理员、老师、学生三类角色提供差异化视图与操作能力。所有业务请求均通过 API Gateway 统一接入，前端不直接访问后端微服务。应用包含六个主要功能模块：登录认证、学生管理、班级管理、年级管理、统计看板。页面路由基于角色进行权限控制，管理员拥有全部操作权限，老师拥有查看和数据录入权限（不含删除），学生仅拥有个人数据查看权限。前端框架建议采用 Vue 3 或 React，通过 HTTP 客户端（如 Axios）与 API Gateway 通信，请求时在 Authorization Header 携带 JWT Token 进行鉴权。

用户登录认证

POST /api/auth/login

用户登录认证，提交用户名密码和角色，获取 JWT Token 和用户信息。前端将 token 存储于 localStorage/sessionStorage，后续请求在 Authorization Header 中携带 Bearer token。

参数类型描述

passwordstring密码
rolestring角色: admin|teacher|student

错误处理

前端采用统一 HTTP 拦截器集中处理 API 异常：401 响应时清除本地 Token 并跳转至登录页；403 响应时提示权限不足；404 响应时显示资源不存在提示；422/400 响应时将后端校验错误映射到表单字段级错误提示；500 及以上响应时展示全局错误提示并记录日志。表单提交前进行前端字段格式校验（如学号长度、邮箱格式、必填项检查等），校验未通过时不发起请求。列表查询接口请求超时阈值设为 15 秒，超时后提示用户网络异常并允许重试。所有删除操作需先弹确认对话框，用户确认后才发送 DELETE 请求。
