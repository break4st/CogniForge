概述

Web Console
单页应用前端，提供项目、环境、密钥管理和部署操作的可视化界面。基于 React 18 + Ant Design 5 构建，通过 Pinia 管理全局状态，通过 API Gateway 与后端服务通信，使用 WebSocket 实时接收部署日志推送。
依赖: API GatewayDeployment Orchestrator
React 18Ant Design 5WebSocket (FastAPI WebSocket)
🗄️

错误处理

Web Console 前端采用统一的错误处理策略：（1）API 请求失败：通过 Axios 拦截器捕获 HTTP 错误状态码，根据状态码分类处理——4xx 错误在页面顶部展示 Ant Design 警告提示（Alert），5xx 错误展示全局异常提示并记录日志；（2）WebSocket 异常：断线时自动重连（指数退避策略，最多重试 5 次），重连期间展示「连接中断，正在重连…」提示条；连接最终失败时展示错误页并提供手动刷新按钮；（3）表单验证：使用 Ant Design Form 内置校验规则，在提交前对必填项、格式（版本号、主机地址、端口号等）进行客户端校验，校验不通过时聚焦到第一个错误字段；（4）加载与空状态：列表页使用 Skeleton 骨架屏展示加载中，空数据时展示 Ant Design Empty 空状态组件与引导提示；（5）并发请求管理：页面卸载时通过 AbortController 取消未完成的 API 请求，避免内存泄漏和状态污染。
