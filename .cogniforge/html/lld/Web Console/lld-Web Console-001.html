概述

Web Console
🖥️ 前端
基于 React 18 的单页应用，提供用户操作界面。采用 Ant Design 5.x 作为 UI 组件库，React Query + Context API 管理状态，通过 REST API 经由 API Gateway 与后端服务交互。涵盖项目管理、环境配置、一键部署、部署监控和审计日志查看等核心功能。
依赖: API Gateway
React 18Ant Design 5.xReact Query + Context APIServer-Sent Events (SSE)

State

行为
  • mount 时从 localStorage 恢复 token 并校验用户身份

错误处理

处理策略

全局 Axios 拦截器统一捕获 HTTP 错误状态码，按分类展示 Ant Design notification；表单校验使用 Ant Design Form 内置 rules；网络异常展示友好提示并提供重试按钮。所有后端返回的错误遵循统一格式 {code, error, detail}。

字段类型
