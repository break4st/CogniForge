概述

模块: Web Console
基于Web的管理控制台，提供项目、环境、部署等功能的操作界面
依赖: API Gateway
Vue 3Element Plus

⚠️

错误处理

全局 HTTP 请求拦截器统一处理 API 错误响应，401 跳转登录页，其余错误通过 Element Plus ElMessage 组件展示提示消息。WebSocket 连接中断时自动重连，重连间隔指数退避（1s/2s/4s/8s，上限30s），断连期间日志暂存于 deploymentLogStore 缓冲区，重连后自动续传缺失日志。表单提交前进行前端校验（必填项、格式合法性），校验不通过禁用提交按钮并展示字段级错误提示。路由守卫检查登录状态，未登录时重定向至登录页。所有列表页面展示加载骨架屏（ElSkeleton）以提升加载体验。
