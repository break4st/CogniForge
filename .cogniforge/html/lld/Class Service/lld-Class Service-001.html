概述

模块: Class Service

负责班级领域业务，管理班级的新建、调整与解散，维护班级-年级层级关系，支持班主任指派与班级学生名单查询。提供 4 个 REST API 作为 provider 供 API Gateway 和 Student Service 调用；作为 consumer 依赖 Grade Service 的年级查询接口完成年级存在性校验，依赖 Student Service 的学生信息接口获取班级学生名单。provider 接口严格遵循 SAD 定义的契约签名。

接口定义 (7)

ClassInfoAPI

GET /api/v1/classes

（Provider）分页查询班级列表，支持按年级过滤。返回列表中的每条记录包含 id、name、grade_id、head_teacher、student_count、capacity 字段。student_count 通过查询 Student Service 的 StudentInfoAPI（filter by class_id）获取各班级实时学生人数。命中缓存则直接返回；未命中则查询数据库后回写缓存。缓存 key 格式：class:list:{grade_id}:{page}:{page_size}。

ClassDetailAPI

GET /api/v1/classes/{id}

（Provider）根据 ID 获取班级详细信息。student_count 通过查询 Student Service 的 StudentInfoAPI（filter by class_id）获取当前在籍人数。命中缓存则直接返回；未命中则查询数据库后回写缓存。缓存 key 格式：class:detail:{id}。

CreateClassAPI

POST /api/v1/classes

（Provider）创建新班级。先校验 grade_id 存在性（调用 GradeService.GradeDetailAPI），若年级不存在则拒绝并返回 422；再校验同年级内班级名称是否重复（查询 class 表 (grade_id, name) 唯一索引），若重复返回 409；校验通过后写入数据库，清除班级列表缓存。

ClassStudentsAPI

GET /api/v1/classes/{id}/students

（Provider）查询指定班级的学生名单。先校验班级是否存在（查 class 表），不存在则返回 404。存在则调用 StudentService.StudentInfoAPI 并传入 class_id 过滤条件，获取该班级全部在籍学生列表，将其作为 students 数组返回。返回的学生对象包含学生完整档案信息（id、name、student_no、gender、birth_date、phone、address、grade_id、class_id、enrollment_date）。

StudentDetailAPI

GET /api/v1/students/{id}

（Consumer — Student Service）根据 ID 获取单个学生的完整详细信息。Class Service 在 ClassStudentsAPI 中通过该接口获取班级内单名学生的详细信息（当需要精确单条查询时使用）。

GradeDetailAPI

GET /api/v1/grades/{id}

（Consumer — Grade Service）根据 ID 获取年级详细信息，用于 CreateClassAPI 创建班级时校验 grade_id 的有效性。

GradeInfoAPI

GET /api/v1/grades

（Consumer — Grade Service）分页查询年级列表，支持按学年和学段过滤。Class Service 在需要按年级维度获取班级统计信息时使用。

⚠️

错误处理

Class Service 统一返回 JSON 错误体 {"code": "错误码", "message": "错误描述"}。1) 班级不存在时 ClassDetailAPI / ClassStudentsAPI 返回 404 Not Found，错误码 'CLASS_NOT_FOUND'。2) 创建班级时同年级内班级名称重复返回 409 Conflict，错误码 'CLASS_NAME_DUPLICATE'。3) 引用的年级不存在（via GradeService.GradeDetailAPI）返回 422 Unprocessable Entity，错误码 'GRADE_NOT_FOUND'。4) 请求参数校验失败（如 name/grade_id 缺失、page/page_size 格式错误）返回 400 Bad Request，错误码 'INVALID_PARAMETER'。5) 调用下游服务（Student Service / Grade Service）超时阈值为 5 秒，超时或连接失败返回 503 Service Unavailable，错误码 'DEPENDENCY_TIMEOUT'。6) 数据库操作异常返回 500 Internal Server Error，错误码 'DATABASE_ERROR'。
