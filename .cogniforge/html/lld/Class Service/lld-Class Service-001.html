概述

模块: Class Service

基于 RESTful 架构的班级信息管理服务，对外提供班级的增删改查、班级成员管理及班级-年级归属关系维护能力。采用分层设计：Controller 层处理 HTTP 请求与参数校验 → Service 层实现业务逻辑（班级名称去重、班级人数上限校验、学生归属关系维护） → Repository 层封装数据库访问。数据库使用 MySQL/PostgreSQL，核心表为 class（班级信息）和 class_student（班级-学生归属关系），class 表通过 grade_id 外键关联 grade 表维护班级-年级层级，class_student 表维护多对多的学生归属关系（一对多语义：一个学生在同一时间只应属于一个班级，由业务层保证）。班级成员查询需关联 student 表获取学生基本信息，并联动缓存层（Redis）缓存成员列表和班级人数，降低关联查询压力。与 Student Service 存在调用依赖：删除班级时需校验班级下是否仍有学生（防止数据孤儿）；新增/移除班级成员时需校验学生 ID 有效性（调用 Student Service）。

接口定义 (10)

班级列表查询

GET /api/classes

分页查询班级列表，支持按年级筛选和关键词搜索班级名称。条件之间为 AND 关系

班级详情查询

GET /api/classes/:id

根据 ID 获取单个班级的详细信息，包含年级名称和当前学生人数。返回 404 当班级不存在

创建班级

POST /api/classes

新增一条班级记录。校验名称在同年级下的唯一性（重复返回 409）、gradeId 有效性（调用 Grade Service 校验，年级不存在返回 400）

更新班级

PUT /api/classes/:id

更新指定班级的基本信息。名称变更时校验同年级下唯一性（排除自身）。gradeId 变更时校验新年级有效性。maxStudents 调低后若低于当前在班人数则拒绝更新

删除班级

DELETE /api/classes/:id

逻辑删除指定班级（设置 deleted_at 时间戳），不物理删除。删除前校验班级下是否仍有学生（class_student 中 deleted_at IS NULL 的记录），若有学生则拒绝删除返回 409

班级成员列表查询

GET /api/classes/:id/students

分页查询指定班级的成员列表，需关联 student 表获取学生基本信息（姓名、学号、性别）。优先从缓存读取，缓存未命中则查 DB 并回填缓存

添加班级成员

POST /api/classes/:id/students

将一个学生分配到指定班级。校验学生 ID 有效性（调用 Student Service，不存在返回 400），校验该学生是否已在其他班级（同一学生在 class_student 中只能有一条未删除记录，如果已有则先移出旧班级再加入新班级），校验班级人数是否已达上限（拒绝返回 409）。操作成功后清除班级成员列表缓存

移除班级成员

DELETE /api/classes/:id/students/:studentId

将指定学生从班级中移除（逻辑删除 class_student 中对应的记录，设置 deleted_at）。校验该学生是否确实在当前班级中（不存在返回 404）。操作成功后清除班级成员列表缓存

搜索班级

GET /api/classes/search

精简版搜索接口，不返回分页元信息，适用于下拉选择器等组件快速查找。keyword 为空时返回空列表

获取班级人数统计

GET /api/classes/statistics/headcount

按班级维度统计各班级当前在班人数（按年级分组可供前端展示）。用于学习统计模块和 Web UI 仪表盘展示。优先返回缓存数据

⚠️

错误处理

全局统一返回标准 JSON 格式：{ code: number, message: string, details?: any }。4xx 错误携带具体校验提示：班级不存在返回 404（message: '班级不存在'），班级名称在同年级下重复返回 409（message: '该年级下已存在同名班级'），年级无效返回 400（message: '指定的年级不存在'），学生不存在返回 400（message: '指定的学生不存在'），班级人数已达上限返回 409（message: '班级人数已达上限，无法添加新成员'），班级下仍有学生时拒绝删除返回 409（message: '班级下仍有学生，请先移除所有学生后再删除'），参数格式错误返回 400（message: '参数错误' 并 details 标明具体字段）。5xx 错误统一返回 500（message: '系统内部错误'），完整错误栈记录到服务日志。逻辑删除的记录在列表查询和详情查询中均被过滤（WHERE deleted_at IS NULL）。class_student 关系表采用逻辑删除，同一学生加入新班级前自动逻辑删除旧归属记录，保证一个学生同时只属于一个班级的业务约束。缓存操作（Redis）失败时降级为直接查询数据库，不阻塞正常业务流程。
