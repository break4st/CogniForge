概述

模块: Class Service

班级信息管理服务，负责班级的创建维护及学生分配管理。作为微服务架构中的领域服务之一，通过 REST 内部接口对外提供班级信息 CRUD 及学生名单查询能力，消费者为 API Gateway 和 Student Service。服务内部职责包括：1）班级的创建、编辑和删除；2）按条件（年级、名称）分页查询班级列表，列表项中 student_count 通过统计关联学生数实时计算；3）班级下学生名单的分页查询（直接查询共享数据库的 students 表，按 class_id 筛选）；4）班级-年级关联关系的维护（创建/更新时设置 grade_id 需调用 Grade Service 接口 GET /internal/grades/{id}/exists 校验年级存在性）；5）班级存在性校验（供 Student Service 在分配学生时调用）。本服务不处理认证鉴权——该职责由 API Gateway 统一负责。数据存储采用关系型数据库，班级信息主表为 classes，关联年级 ID（grade_id）引用 Grade Service 侧的年级数据（通过应用层校验保证引用完整性）。班级下学生名单通过查询共享的 students 表获得，按 class_id 过滤。

接口定义 (8)

班级管理内部接口（创建）

POST /internal/classes

创建班级记录。接收班级名称、可选年级 ID 和可选描述。核心校验规则：1）name 为必填字段，缺失时返回 422；2）如提供了 grade_id，需调用 Grade Service 接口 GET /internal/grades/{id}/exists 校验年级存在性，年级不存在时返回 422 Unprocessable Entity。创建成功返回 201 及完整班级信息（含自动生成的 id 和 created_at）。

参数类型描述
namestring班级名称，必填
grade_idnumber (optional)所属年级 ID，选填，提供时需校验年级存在性
descriptionstring (optional)班级描述，选填

班级管理内部接口（更新）

PUT /internal/classes/{id}

更新指定班级的信息。可修改字段：名称、年级 ID、描述。核心校验规则：1）路径参数 id 对应的班级不存在时返回 404；2）如提供了 grade_id，需调用 Grade Service 接口 GET /internal/grades/{id}/exists 校验年级存在性，年级不存在时返回 422；3）至少提供一个可修改字段，全空时返回 422。更新成功返回 200 及更新后的班级信息（含 updated_at 时间戳）。

参数类型描述
idnumber班级 ID，路径参数
namestring (optional)班级名称，选填
grade_idnumber (optional)所属年级 ID，选填，提供时需校验年级存在性
descriptionstring (optional)班级描述，选填

班级管理内部接口（删除）

DELETE /internal/classes/{id}

删除指定班级记录。路径参数 id 对应的班级不存在时返回 404；删除成功返回 204 No Content，无响应体。注意：删除班级时，关联该班级的学生不会自动删除——class_id 仅置空逻辑由 Student Service 自行处理，本服务只负责删除班级记录本身。

参数类型描述
idnumber班级 ID，路径参数

班级管理内部接口（列表）

GET /internal/classes

按条件分页查询班级列表。支持按年级 ID（精确匹配）和班级名称（模糊匹配）筛选。分页参数 page 默认 1，page_size 默认 20，最大 page_size 不超过 100。返回结果中 student_count 通过 COUNT 聚合 students 表中 class_id 等于当前班级 ID 的记录数实时计算。响应中包含 total 总数、当前页码、每页条数及 items 数组。

参数类型描述
grade_idnumber (optional)按年级筛选，精确匹配
namestring (optional)按名称模糊搜索
pagenumber (optional)页码，默认 1
page_sizenumber (optional)每页条数，默认 20，最大 100

班级管理内部接口（详情）

GET /internal/classes/{id}

查询指定班级的详细信息。返回结果包含班级全部字段（id、name、grade_id、student_count、description、created_at、updated_at），其中 student_count 通过 COUNT 聚合 students 表中 class_id 等于当前班级 ID 的记录数实时计算。班级不存在时返回 404。

参数类型描述
idnumber班级 ID，路径参数

班级管理内部接口（班级学生名单）

GET /internal/classes/{id}/students

查询指定班级下的学生名单。通过查询共享数据库的 students 表，按 class_id 过滤出属于该班级的学生记录，分页返回。返回字段包含学生的 id、name、student_no、contact_phone、contact_email。注意：此接口只返回基本信息，不包含班级名称等冗余字段（由 API Gateway 负责组装）。班级不存在时返回 404。分页参数 page 默认 1，page_size 默认 20，最大 100。

参数类型描述
idnumber班级 ID，路径参数
pagenumber (optional)页码，默认 1
page_sizenumber (optional)每页条数，默认 20，最大 100

班级存在性校验

GET /internal/classes/{id}/exists

校验指定班级是否存在。Student Service 在创建或更新学生时，若请求中包含 class_id，需调用此接口校验目标班级是否存在。本接口返回班级存在状态（exists 布尔值）以及班级的基本信息（id、name）。注意：即使班级被逻辑删除（如有），也应按实际数据库状态返回，不存在则 exists 为 false。

参数类型描述
idnumber班级 ID，路径参数

年级存在性校验（consumer）

GET /internal/grades/{id}/exists

Class Service 在创建或更新班级时，若请求中包含 grade_id，需调用此接口校验目标年级是否存在。调用方式：HTTP GET 请求 Grade Service。响应中 exists 为 true 时年级存在，为 false 时年级不存在，此时 Class Service 应返回 422 Unprocessable Entity 并提示年级不存在。此接口定义在 SAD 中，本处引用以说明调用依赖。

参数类型描述
idnumber年级 ID，路径参数
⚠️

错误处理

Class Service 按以下规则处理异常：1）班级不存在——按 id 查询/更新/删除时记录不存在，返回 404 Not Found，响应体为 {"error": "not_found", "message": "班级不存在"}；2）年级不存在——创建/更新时 grade_id 指向不存在的年级，返回 422 Unprocessable Entity，响应体为 {"error": "validation_error", "message": "年级不存在", "field": "grade_id"}；3）必填字段缺失——创建时缺少 name 字段，返回 422，响应体为 {"error": "validation_error", "message": "班级名称不能为空", "field": "name"}；4）更新时无有效字段——所有字段均为空，返回 422，响应体为 {"error": "validation_error", "message": "至少需要提供一个待更新字段"}；5）分页参数越界——page_size 超过 100 时截断为 100，page 小于 1 时重置为 1，不返回错误；6）下游依赖超时——调用 Grade Service 年级存在性校验接口超过 5 秒未响应时，当前操作失败，返回 502 Bad Gateway，响应体为 {"error": "upstream_error", "message": "年级服务不可用"}。所有操作记录结构化日志，包含请求路径、方法、耗时、操作人（由 API Gateway 在请求头传递的用户标识）和操作结果状态，日志级别：正常操作 INFO，业务校验失败 WARN，系统异常 ERROR。
