概述

模块: Grade Service

年级信息管理服务，负责年级的划分及与班级的层级关联。作为微服务架构中的领域服务之一，通过 REST 内部接口对外提供年级信息 CRUD 及年级-班级结构查询能力，消费者为 API Gateway 和 Class Service。服务内部职责包括：1）年级信息的创建和编辑（年级名称 name 为必填字段，description 可选）；2）年级列表的分页查询，列表项中 class_count 通过统计关联班级数实时计算；3）年级下班级结构的分页查询（直接查询共享数据库的 classes 表，按 grade_id 筛选）；4）年级存在性校验（供 Class Service 在关联班级到年级时调用）。本服务不处理认证鉴权——该职责由 API Gateway 统一负责。数据存储采用关系型数据库，年级信息主表为 grades。年级-班级层级关联通过 classes 表的 grade_id 字段实现，本服务可跨服务查询共享数据库中的 classes 表以获得年级下的班级列表和统计。本服务不依赖其他微服务的接口，所有操作均为自包含的数据查询和修改。

接口定义 (5)

年级管理内部接口（创建）

POST /internal/grades

创建年级记录。接收年级名称和可选描述。核心校验规则：1）name 为必填字段，缺失时返回 422；2）name 需全局唯一，重复时返回 409 Conflict。创建成功返回 201 及完整年级信息（含自动生成的 id、description 默认空字符串、created_at）。

参数类型描述
namestring年级名称，必填，全局唯一
descriptionstring (optional)年级描述，选填

年级管理内部接口（更新）

PUT /internal/grades/{id}

更新指定年级的信息。可修改字段：名称、描述。核心校验规则：1）路径参数 id 对应的年级不存在时返回 404；2）如更新 name，需校验新名称不与其他年级重复，重复时返回 409；3）至少提供一个可修改字段，全空时返回 422。更新成功返回 200 及更新后的年级信息（含 updated_at 时间戳）。

参数类型描述
idnumber年级 ID，路径参数
namestring (optional)年级名称，选填，更新时需校验全局唯一
descriptionstring (optional)年级描述，选填

年级管理内部接口（列表）

GET /internal/grades

分页查询年级列表。支持分页参数 page（默认 1）和 page_size（默认 20，最大 100）。返回结果中 class_count 通过 COUNT 聚合 classes 表中 grade_id 等于当前年级 ID 的记录数实时计算。响应中包含 total 总数、当前页码、每页条数及 items 数组。

参数类型描述
pagenumber (optional)页码，默认 1
page_sizenumber (optional)每页条数，默认 20，最大 100

年级管理内部接口（年级班级结构）

GET /internal/grades/{id}/classes

查询指定年级下的班级结构。路径参数 id 对应的年级不存在时返回 404。通过查询共享数据库的 classes 表按 grade_id 过滤出属于该年级的班级列表，返回字段包含 class_id、class_name、student_count（通过 COUNT 聚合 students 表中 class_id 匹配的记录数实时计算）、description。

参数类型描述
idnumber年级 ID，路径参数

年级存在性校验

GET /internal/grades/{id}/exists

校验指定年级是否存在。Class Service 在创建或更新班级时，若请求中包含 grade_id，需调用此接口校验目标年级是否存在。本接口返回年级存在状态（exists 布尔值）以及年级的基本信息（id、name）。年级不存在时 exists 为 false，id 和 name 返回 null。

参数类型描述
idnumber年级 ID，路径参数
⚠️

错误处理

Grade Service 按以下规则处理异常：1）年级不存在——按 id 查询/更新时记录不存在，返回 404 Not Found，响应体为 {"error": "not_found", "message": "年级不存在"}；2）名称重复——创建或更新时 name 与其他年级重复，返回 409 Conflict，响应体为 {"error": "conflict", "message": "年级名称已存在", "field": "name"}；3）必填字段缺失——创建时缺少 name 字段，返回 422 Unprocessable Entity，响应体为 {"error": "validation_error", "message": "年级名称不能为空", "field": "name"}；4）更新时无有效字段——所有字段均为空，返回 422，响应体为 {"error": "validation_error", "message": "至少需要提供一个待更新字段"}；5）分页参数越界——page_size 超过 100 时截断为 100，page 小于 1 时重置为 1，不返回错误；6）年级下无班级——GET /internal/grades/{id}/classes 查询时 classes 数组为空列表，不属于异常，正常返回 200 及空数组。所有操作记录结构化日志，包含请求路径、方法、耗时和操作结果状态，日志级别：正常操作 INFO，业务校验失败 WARN，系统异常 ERROR。
