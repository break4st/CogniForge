概述

模块: student-service

学生管理服务是学生管理系统的基础核心模块，负责学生基本信息的全生命周期管理。本服务提供学生信息的增删改查、批量导入导出、多维度检索筛选等功能，保障学生数据的唯一性与完整性，并支持数据变更的历史追溯。本服务遵循分层架构设计，向上通过 RESTful API 为前端和网关层提供统一接口，向下通过数据持久层与关系型数据库交互，并通过缓存层加速高频读取。

接口定义 (9)

CreateStudent

POST /api/v1/students

创建学生记录。校验学号和身份证号的唯一性，校验关联的年级和班级存在。

UpdateStudent

PUT /api/v1/students/{id}

更新学生记录。使用乐观锁（version 字段）防止并发写覆盖。

DeleteStudent

DELETE /api/v1/students/{id}

逻辑删除学生记录（标记 status=TRANSFERRED/DROPPED，不做物理删除），保留历史数据完整性。

GetStudent

GET /api/v1/students/{id}

根据 ID 查询单个学生详细信息，优先查缓存。

GetStudentByNo

GET /api/v1/students/by-no/{student_no}

根据学号查询学生信息，用于学号唯一性校验和快速检索。

SearchStudents

GET /api/v1/students

多维度分页检索学生信息。支持关键词模糊搜索、组合条件筛选、排序和分页。缓存命中的分页结果，缓存键包含完整查询条件。

BatchImportStudents

POST /api/v1/students/import

批量导入学生信息。支持 CSV 和 Excel 格式。采用两阶段处理：先全量校验再批量写入。使用分布式锁防止并发导入。生成导入结果报告。

ExportStudents

GET /api/v1/students/export

按筛选条件导出学生信息为 CSV 或 Excel 文件。大数据量时异步生成并提供下载链接。

GetStudentHistory

GET /api/v1/students/{id}/history

查询学生信息变更历史记录，用于数据追溯和审计。

错误处理

本模块采用统一的错误处理策略，所有异常返回标准错误响应体 { code: string, message: string, details: object }。 1. 参数校验错误 (400 BAD_REQUEST)：请求参数缺失、格式错误或超出长度限制时返回，包含具体字段级别的错误详情。 2. 业务唯一性冲突 (409 CONFLICT)：学号或身份证号与已有记录重复时返回，提示具体冲突字段。 3. 并发冲突 (409 CONFLICT)：乐观锁版本号不匹配时返回，提示客户端刷新数据后重试。 4. 资源不存在 (404 NOT_FOUND)：指定 ID 的学生记录不存在时返回。 5. 关联引用错误 (422 UNPROCESSABLE_ENTITY)：引用的年级或班级 ID 不存在时返回。 6. 导入格式错误 (400 BAD_REQUEST)：上传文件格式不支持、文件内容解析失败时返回。 7. 导入部分失败 (200 OK with partial_failure flag)：批量导入中部分行校验失败时返回成功导入数、失败数及详细错误列表。 8. 缓存降级（静默处理）：缓存服务不可用时自动降级直查数据库，不中断业务流程。 9. 内部错误 (500 INTERNAL_SERVER_ERROR)：未预期的系统异常，记录审计日志并返回通用错误信息。
