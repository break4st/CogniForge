概述

File Storage
存储用户上传的可执行文件和部署产物，为部署任务提供文件下载/传输路径，管理文件版本，存储部署生成的脚本等中间产物。后端采用本地文件系统或对象存储（MinIO），通过 FileRecord 元数据实现文件生命周期管理。
本地文件系统 / 对象存储 (MinIO)
🗄️

数据模型 (2)

数据结构 1

📦 FileRecord自有

文件元数据记录。每个上传到文件存储的文件对应一条记录，记录文件的基本信息、存储路径和关联项目。元数据可存储在本地 SQLite 或 MinIO 对象标签/元数据字段中，不依赖外部数据库。

字段
字段名类型描述
file_id *string文件唯一标识（UUID v4）
file_name *string原始文件名（包含扩展名）
project_id *string文件关联的项目 ID
size *integer文件大小（字节）
content_typestring文件 MIME 类型，由文件扩展名或 Magic Number 检测
storage_path *string文件在存储后端中的相对路径，格式：files/{file_id}/{file_name}
checksumstring文件 SHA-256 校验和（十六进制），上传完成后计算并记录，下载时用于完整性验证
uploaded_at *datetime文件上传完成时间（ISO 8601 格式）
配置定义 1

⚙️ StorageConfig自有

文件存储后端配置。支持本地文件系统和 MinIO 对象存储两种后端，通过 backend_type 切换。应用启动时加载配置并初始化对应存储驱动。

字段
字段名类型描述
backend_type *string存储后端类型：local（本地文件系统）或 minio（对象存储）
root_path *string存储根路径（本地模式为绝对路径，MinIO 模式为 bucket 名称）
max_file_size_mb *integer单文件大小上限（MB），默认 500，超过返回 413
allowed_extensionsarray<string>允许上传的文件扩展名列表（如 ["exe", "sh", "tar.gz"]），空表示不限制
minio_endpointstringMinIO 服务端点（仅 backend_type=minio 时需要），格式：host:port
minio_access_keystringMinIO 访问密钥（仅 backend_type=minio 时需要）
minio_secret_keystringMinIO 秘密密钥（仅 backend_type=minio 时需要），应用内加密存储
minio_use_sslbooleanMinIO 是否使用 SSL/TLS 连接，默认 false

错误处理

文件存储模块采用防御式校验和降级策略：(1) 文件合法性校验 — 上传请求在写入存储前执行三层校验：① 文件是否为空（size=0 直接拒绝）；② 文件大小是否超过 max_file_size_mb 限制（超限返回 413）；③ 文件扩展名是否在 allowed_extensions 白名单中（配置为空则跳过此校验）。校验不通过立即拒绝，不产生脏数据。(2) 存储后端故障处理 — 本地文件系统模式：目录不存在时自动递归创建（os.makedirs exist_ok=True），磁盘写入失败（IOError/OSError）统一返回 507。MinIO 模式：客户端连接超时设定为 5s，超时或连接拒绝时返回 500。两种后端均支持启动时健康检查（写入探针文件验证 I/O 可用性），检查失败则应用拒绝启动。(3) 文件完整性 — 文件上传完成后后台计算 SHA-256 校验和，记录到 FileRecord.checksum。DownloadFile 接口可接受可选参数 ?verify=checksum，查询时返回校验和由客户端自行验证，避免服务端重复计算的开销。(4) 资源清理 — 上传过程中写入存储失败（如写入 50% 时报错），已写入的部分文件由后台协程根据超时未完成标记清理。资源泄漏防护：上传文件写入临时路径（files/.tmp/{uuid}），FileRecord 创建完成并成功后原子重命名至正式路径。上传失败或超时（默认 5 分钟）的临时文件由定时清理任务（每小时执行）批量删除。(5) 删除操作 — DeleteFile 接口幂等：文件已不存在时仍返回 200（result: true），元数据存储删除失败时返回 500 并记录审计日志。(6) 并发安全 — 文件通过 file_id（UUID）唯一标识，天然避免名称冲突。同一项目下不同用户同时上传同名文件时各自生成独立 file_id，互不影响。文件删除和下载的并发由存储后端保证（MinIO 对象版本 / 本地文件系统通过原子重命名和硬链接计数避免部分读取）。(7) 磁盘空间监控 — 后台定时（每 5 分钟）检查存储根目录所在分区的剩余空间，低于阈值（默认可用空间 < 1GB）时触发告警并拒绝新的上传请求，返回 507。
