概述

Environment Manager
⚙️ 业务服务
管理某个项目下的部署环境配置，负责环境的增删改查、密钥加密存储与连通性测试调度。调用 Security Module 处理密钥，通过 SSH Service 进行连接测试。
依赖: Security ModuleSSH ServicePrimary Database
TypeScriptElectron 主进程Electron ipcMain / contextBridgeSQLite (via better-sqlite3)Node.js crypto (AES-256-GCM) (间接依赖)主密码派生密钥 (间接依赖)
基于: PRD prd-current v1 · SAD sad-001 v1
📐 模块边界
范围内: 环境的 CRUD 操作（增删改查） 环境连通性测试调度 调用 Security Module 对私钥加解密 调用 SSH Service 进行连接测试 环境列表查询及连通状态展示 环境配置的输入校验与业务规则
范围外: UI 渲染逻辑 SSH 协议实现 加密算法实现 审计日志存储 部署执行流程 历史记录与回滚 文件上传逻辑
拥有组件: CMP-003

属性
属性名类型描述

服务接口 (1)

🔧 EnvironmentService 5 方法
addEnvironment
(dto: AddEnvironmentDTO, userId: string) -> EnvironmentResponseDTO
校验并添加新环境，加密私钥后存储，返回环境信息
前置条件
userId 非空，dto 通过输入校验（名称必填、主机必填、端口范围 1-65535、标签必为 test/gray/production 之一），同一用户下环境名称唯一
后置条件
环境配置被持久化，若提供私钥则加密存储，返回新创建环境的完整信息（不含解密私钥）
ValidationException→ 400输入校验失败BusinessRuleViolationException→ 409同一用户下环境名称已存在
editEnvironment
(dto: EditEnvironmentDTO, userId: string) -> EnvironmentResponseDTO
校验并更新已有环境配置，处理密钥轮转，返回更新后的环境信息
前置条件
userId 非空，dto 包含环境 ID 且存在，至少修改一个字段，若有端口则范围 1-65535，若有标签则必为合法值，新名称不得与同一用户下其他环境冲突
后置条件
数据库中的环境记录被更新，若提供新私钥则重新加密存储并擦除旧私钥，返回更新后的环境信息（不含解密私钥）
ValidationException→ 400输入校验失败或缺少环境 IDNotFoundException→ 404环境 ID 不存在BusinessRuleViolationException→ 409修改后的名称与同一用户下其他环境冲突
deleteEnvironment
(dto: DeleteEnvironmentDTO, userId: string) -> void
校验并删除环境配置，确保无活跃部署后移除记录
前置条件
userId 非空，dto 包含环境 ID 且存在，该环境下没有活跃的部署
后置条件
对应的环境记录连同加密私钥一同从数据库删除
ValidationException→ 400缺少环境 IDNotFoundException→ 404环境 ID 不存在BusinessRuleViolationException→ 409该环境存在活跃的部署
listEnvironments
(projectId: string, userId: string) -> EnvironmentResponseDTO[]
查询项目下所有环境并组装响应，最新连通状态来自缓存或默认 unknown
前置条件
projectId 和 userId 非空
后置条件
返回指定项目下所有环境的列表，每个环境包含基本信息及最新的连通状态，私钥字段置空或脱敏
testConnection
(dto: TestConnectionDTO, userId: string) -> TestConnectionResultDTO
解密私钥并调度 SSH 连接测试，更新状态，返回测试结果
前置条件
userId 非空，dto 包含环境 ID 且环境存在
后置条件
调用 Security Module 解密私钥（若有），通过 SSH Service 执行连接测试，得到成功或失败的结果，更新缓存中的连通状态，返回测试结果，使用后立即从内存擦除私钥
NotFoundException→ 404环境 ID 不存在CryptoOperationException→ 500私钥解密失败SSHConnectionException→ 502SSH 连接测试过程异常
数据访问依赖
findByNameAndCreatedBy(userId: string, name: string) -> EnvironmentRecord?
existsActiveDeployment(environmentId: string) -> boolean
save(record: EnvironmentRecord) -> EnvironmentRecord
findByProjectId(projectId: string) -> EnvironmentRecord[]

不变量
  • !同一项目下，环境名称必须唯一（不区分大小写）
  • !主机地址必须是有效的IPv4地址或域名
  • !端口号必须在1~65535之间
  • !私钥内容不能为空，且由Security Module加密后才能存入数据库
  • !环境标签只能是test、gray或production之一
  • !每个项目至少保留一个生产环境，不可删除最后一个标记为production的环境
状态机
🎯 EnvironmentEntity
正常使用连通性测试中已删除
→用户发起连通性测试by 用户
→测试完成by 系统
🚫 状态一旦变为'已删除'，不可逆转到其他状态
⚡ 同一个环境只能有一个活跃的连通性测试，测试期间不能删除或编辑
跨服务规则
调用Security Module加密私钥时，必须传递明文私钥和环境ID；解密时需传递加密后的私钥和环境ID，解密后私钥仅用于SSH连接测试，使用后立即从内存中安全擦除
SSH连接测试完成后，必须断开连接并清除所有会话密钥
删除环境时，需先调用Security Module清除相关加密密钥和审计日志引用

编排流程

环境连通性测试流程

用户发起连通性测试，系统解密私钥并通过SSH Service测试连通性，更新状态并返回结果

1
接收测试请求 (30s 超时)
接收TestConnectionDTO，校验环境ID
失败处理: 返回400错误
2
获取环境配置 (10s 超时)
从数据库加载EnvironmentRecord
失败处理: 返回404错误
3
解密私钥 (30s 超时)
调用Security Module解密encrypted_private_key
失败处理: 返回500错误

错误处理

处理策略

所有 API 调用均返回统一错误响应体，包含数字错误码、简短错误消息和详细错误说明。客户端应根据错误码进行分类处理，敏感信息不应在 detail 中暴露。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
4xx
客户端错误
由无效输入、缺失字段、违反业务规则或资源不存在等客户端侧问题触发。返回详细校验错误信息，帮助用户纠正请求。
5xx
服务端错误
由数据库操作失败、加密解密异常、SSH 连接测试失败或外部服务调用失败等服务器内部问题触发。返回通用错误消息，避免暴露内部实现细节。
