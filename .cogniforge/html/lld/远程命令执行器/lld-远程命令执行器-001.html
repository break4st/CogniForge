概述

远程命令执行器
⚙️ 业务服务
通过SSH在远程服务器上执行命令，完成目录操作和脚本执行。作为执行层核心组件，接收部署编排服务下发的执行指令，在已建立的SSH会话上完成创建部署目录、解压文件、设置权限、执行启动脚本和进程监控等操作，并收集命令执行结果和错误输出返回给上层调用方。自身不管理数据库表，所有状态由上层服务负责持久化。
依赖: SSH连接池
GoGingolang.org/x/crypto/ssh

业务规则

不变量
  • !所有远程命令执行必须设置大于0的超时时间，禁止无超时执行以防止命令永久挂起导致SSH会话泄漏
  • !命令执行结果必须包含退出码（exit code），上层基于退出码0/非0判断命令成败
  • !部署目录路径必须按版本号隔离（如 /app/releases/v1.2.3/），禁止多个版本共享同一物理目录
  • !关键操作（目录创建、文件解压、权限设置、脚本执行）失败时必须返回完整的stderr和退出码供上游决策
  • !同一SSH会话同一时间只能执行一条命令，禁止并发复用以防止输出交叉污染
  • !所有命令输出必须限制捕获大小（每通道最多10MB），防止OOM
状态机
🎯 CommandExecution
PENDINGRUNNINGSUCCESSFAILEDTIMEOUT
→SSH会话分配完毕，命令开始执行by RemoteCommandExecutor
→命令执行完毕，退出码为0by SSH远程Shell
→命令执行完毕，退出码非0by SSH远程Shell
→命令执行时间超过timeout_seconds，进程被终止by RemoteCommandExecutor
🚫 命令从 RUNNING 转换为 SUCCESS/FAILED/TIMEOUT 后不可逆转回 RUNNING 或 PENDING
⚡ 同一SSH会话不支持并发命令执行，每个会话一次只能执行一条命令。多命令并发需通过SSH连接池分配多个独立会话。命令执行内部不涉及共享内存状态，无需加锁。
跨服务规则
依赖SSH连接池提供活跃的SSH会话对象，远程命令执行器不负责连接的生命周期管理（创建、维护、关闭）
执行结果的 stdout/stderr 必须完整返回给部署编排服务，编排服务根据退出码和输出内容决定下一步动作（继续部署/中止/回滚）
部署目录路径命名规范由部署编排服务传递，远程命令执行器不自行生成版本目录名或版本号
脚本执行后启动的后台守护进程由部署编排服务通过定时调用 CheckProcessStatus 确认进程存活，远程命令执行器不自行发起重试或告警
文件传输由文件传输引擎独立完成，远程命令执行器不参与SCP/SFTP传输过程，仅操作已传输到远程服务器的文件

错误处理

处理策略

所有远程命令执行统一采用超时控制机制，防止命令长时间挂起导致SSH会话泄漏。命令执行结果始终包含退出码和完整的 stdout/stderr，由上层调用方（部署编排服务）根据业务语义判断成败。SSH会话异常（连接断开、会话关闭）统一转换为 SessionInvalid 错误，触发上层重试获取新会话。命令超时后主动终止远程进程（SIGTERM/SIGKILL），释放会话资源。

统一错误响应体
字段类型
codestring（错误码，如 EC500）
errorstring（错误分类标识，如 SESSION_INVALID）
detailstring（详细错误描述，包含命令退出码和stderr内容）
EC-SESSION_INVALID
SSH会话异常
SSH连接不可用、会话已关闭或认证失败。触发条件：会话超时断开、连接被远程服务器关闭、会话标识不存在。处理方式：上报部署编排服务，编排服务调用SSH连接池重新建立连接后重试。
EC-TIMEOUT
命令执行超时
命令在指定的超时时间内未完成执行。触发条件：启动脚本卡死、远程服务器负载过高、命令陷入无限循环、健康检查服务器无响应。处理方式：向远程进程发送 SIGTERM（等待5s），若仍未退出则发送 SIGKILL；返回已捕获的部分输出和超时标识。
EC-NON_ZERO_EXIT
命令退出码非零
命令执行完毕但退出码不为0。触发条件：目录创建失败（路径无效）、权限设置错误（chmod 非法模式）、脚本执行异常、解压失败（格式不支持）。处理方式：返回完整的 stderr 输出和退出码，由部署编排服务根据步骤类型决定是否中止部署流程。
EC-REMOTE_IO
远程文件系统错误
远程服务器上发生文件系统相关错误。触发条件：磁盘空间不足（df -h 显示使用率100%）、目标路径存在文件冲突、权限拒绝（Permission denied）、文件不存在（No such file or directory）。处理方式：捕获系统错误消息，格式化后返回给调用方，编排服务据此判断是否需要中止部署。
EC-INVALID_PARAM
参数校验失败
调用参数不合法。触发条件：路径为空字符串、超时值 <= 0、命令为空白字符串、包含潜在注入字符（如 ;、&&、| 在非预期位置）。处理方式：拒绝执行并返回参数校验错误，不上报SSH操作，避免资源浪费。
