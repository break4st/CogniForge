概述

Dashboard
🖥️ 前端
作为系统的全局仪表盘页面，Dashboard 负责从 ProjectService 获取所有项目的最新概览信息，并以卡片形式呈现。用户可快速了解每个项目的当前部署状态，并通过搜索和排序功能快速定位感兴趣的项目，点击卡片即可进入项目详情或部署操作界面。
依赖: ProjectService
React 18Ant Design
基于: PRD prd-current v1 · SAD sad-001 v1
📐 模块边界
范围内: 展示全局项目卡片列表，每个卡片包含项目名称、描述、最近部署状态与时间 支持按名称模糊搜索和按时间/名称排序 卡片点击后导航至对应项目的详情页或部署管理页
范围外: 项目的增删改操作 部署任务的执行与监控 环境/密钥/脚本的管理 部署历史详情展示
消费契约: CTR-001
🧩

组件树 (1)

DashboardPage/dashboard

仪表盘页面容器，负责数据获取、状态管理以及搜索/排序参数的 URL 同步。

State
projects: ProjectCard[]loading: booleanerror: string | nullsearch: stringsort: string
行为
  • mount 时从 URL search params 读取 search 和 sort，若无则使用默认 sort='time'
  • search 或 sort 变化时，通过 useEffect 触发 API 请求，并更新 URL search params
  • API 请求成功后更新 projects 状态，失败则设置 error 并显示错误提示
  • 提供重试函数 retry，点击后重新执行当前 search/sort 的请求
边界情况
  • ⚠️ projects 为空且非 loading 且无 error：显示 Empty 组件，文案“暂无项目”
  • ⚠️ 网络错误：在页面上方显示 Alert，提供重试按钮
  • ⚠️ 快速输入搜索词：使用 300ms debounce 防止频繁请求
SearchSortBar

搜索框和排序下拉框的组合控件。

Props
search: string *sort: string *onSearchChange: (value: string) => void *onSortChange: (value: string) => void *
Events
@onSearchChange(string)@onSortChange(string)
行为
  • 渲染 Ant Design Input.Search，onChange 经过 debounce 300ms 后调用 onSearchChange
  • 渲染 Select 组件，选项为 '按名称排序' 和 '最近部署时间'，onChange 调用 onSortChange
边界情况
  • ⚠️ 用户清空搜索框时，立即触发 onSearchChange('')
  • ⚠️ 排序下拉框高亮当前选中项
ProjectCardGrid

项目卡片的栅格布局容器。

Props
projects: ProjectCard[] *
行为
  • 使用 Ant Design Row/Col 响应式栅格，遍历 projects 渲染 ProjectCard 组件
  • projects 为空时由父组件控制显示 Empty，本组件只做列表渲染
边界情况
  • ⚠️ 列表长度极大（>100）时，可改用虚拟列表或分页优化性能（本期不实现）
ProjectCard

单个项目卡片，展示名称、描述、部署状态和时间，点击可跳转。

Props
project: ProjectCard *onClick: (projectId: number) => void *
Events
@onClick(number)
行为
  • 渲染 Ant Design Card，标题为 project.name，描述为 project.description
  • 卡片底部使用 Tag 展示部署状态（颜色随状态变化）和部署时间（格式化为可读文本）
  • 整个卡片可点击，触发 onClick(project.id) 进行路由跳转
边界情况
  • ⚠️ last_deploy_time 为空或无效：显示“从未部署”
  • ⚠️ last_deploy_status 未知值：显示默认灰色 Tag，文案“未知状态”
  • ⚠️ 卡片宽度自适应，设置 max-width 避免在小屏幕上过宽

交互流程 (4)

首次加载仪表盘

用户进入仪表盘后，加载并展示所有项目卡片。

1
步骤1: 用户访问 /dashboard 路径，DashboardPage 组件挂载
2
步骤2: 从 URL query 读取 search 和 sort，若不存在则使用默认值 sort='time'
3
步骤3: 显示全屏加载 Spin
4
步骤4: 调用 GET /api/projects?search=&sort= API 获取项目列表
5
步骤5: 请求成功，更新 projects 状态并隐藏加载态，渲染卡片网格
6
步骤6: 请求失败，显示错误 Alert 和重试按钮
搜索项目

用户在搜索框输入关键词，实时过滤项目卡片。

1
步骤1: 用户在 SearchSortBar 的 Input.Search 中输入文本
2
步骤2: 经过 300ms debounce 后，触发 onSearchChange，更新 DashboardPage 的 search 状态
3
步骤3: useEffect 检测到 search 变化，更新 URL query 参数并重新请求 API
4
步骤4: API 返回过滤后的 projects，刷新视图；若无匹配结果，显示 Empty
切换排序方式

用户选择按名称或按时间排序项目。

1
步骤1: 用户在 SortSelect 中切换排序选项
2
步骤2: onSortChange 回调触发，更新 DashboardPage 的 sort 状态
3
步骤3: 同样触发 URL 更新和 API 重新请求，渲染排序后的结果
点击项目卡片跳转

用户点击某个项目卡片，导航到该项目详情或部署页面。

1
步骤1: 用户点击某个 ProjectCard 的任意区域
2
步骤2: 触发 onClick(project.id)，DashboardPage 内部使用 react-router 的 navigate 跳转到 `/projects/${id}` 或相应部署页面

编排流程

仪表盘数据加载流程

页面挂载或搜索/排序参数变化时，请求项目列表数据并更新视图。

1
触发请求
组件挂载或 search/sort 值变化（经过 debounce 后）
失败处理: 无
2
显示加载态 (10s 超时)
设置 loading=true，渲染 Spin 组件覆盖卡片区域
失败处理: 超时后触发重试逻辑
3
调用 API (10s 超时)
发送 GET /api/projects?search=&sort= 请求
失败处理: catch 异常，进入错误处理步骤
4
成功处理
将响应数据映射为 DM-001 数组，更新 projects 状态，loading=false
失败处理: 无
5
失败处理
根据错误类型显示对应 Alert 或 message，提供重试按钮，loading=false
失败处理: 显示“重试失败，请联系管理员”
重试策略: 最多 0 次，间隔 0s
可重试错误: 无
不可重试错误: 无

错误处理

处理策略

统一使用 try-catch 捕获 API 调用异常，根据错误类型在页面顶部显示 Alert 或使用 message 全局提示，并提供重试按钮。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
NETWORK_ERROR
网络错误
请求无法发送到服务器（如断网），提示检查网络连接，显示重试按钮
SERVER_ERROR
服务器错误
状态码 5xx，提示“服务器内部错误，请稍后重试”，可手动重试
CLIENT_ERROR
客户端错误
状态码 4xx（如 401），由全局拦截器统一处理，跳转登录页
