概述

Deploy Engine
⚙️ 业务服务
部署执行引擎，消费 RabbitMQ 中的部署任务消息，通过 SSH 连接远程服务器执行文件上传、解压、脚本生成、符号链接更新等步骤，并实时推送日志。
依赖: Business ServiceAPI GatewayMySQLRabbitMQ
Python 3.11FastAPIRabbitMQ 3.12MySQL 8.0AsyncSSH
基于: PRD prd-current v1 · SAD sad-001 v1
📐 模块边界
范围内: 从 RabbitMQ 消费部署任务消息 通过 SFTP/SCP 传输部署文件到远程服务器 远程执行 Shell 命令（创建目录、解压、生成脚本、赋予权限） 原子更新 current 符号链接 实时捕获命令输出并通过 WebSocket 推送日志 部署失败时执行回滚操作 更新部署记录状态
范围外: 用户认证与鉴权 部署记录创建、文件上传、任务入队 WebSocket 的网关代理实现 前端界面展示
拥有组件: CMP-005
实现契约: CTR-007

领域对象 (6)

📄 DeploymentOrchestratorservice

部署流程编排器，负责执行整个部署流水线：连接建立、文件上传、远程命令执行、符号链接更新、回滚等

📄 SSHServiceservice

SSH 服务，封装 AsyncSSH 连接、文件上传、远程命令执行、输出捕获，支持自动重连

📄 DeploymentRepositoryrepository

部署记录持久化层，封装对 Deployment 表的 CRUD 操作

📄 WebSocketServiceservice

日志推送服务，封装向指定 task_id 的 WebSocket 连接发送结构化日志消息

📌 CommandResult值对象

命令执行结果值对象，包含退出码、标准输出、标准错误

📄 RollbackHandlerservice

回滚处理器，在部署失败时负责将符号链接回切到上一个版本，或执行自定义回滚脚本

服务接口 (1)

🔧 DeployService 2 方法
consume_deploy_message
consume_deploy_message(message: DeployTaskMessage) -> None
处理从 RabbitMQ 消费的部署任务消息，执行完整部署流程
前置条件
消息格式有效，且部署记录存在
后置条件
部署流水线完成（成功或失败），部署记录状态更新，日志已推送
cancel_deployment
cancel_deployment(task_id: str) -> bool
取消一个正在运行的部署任务
前置条件
部署任务正在运行中 (status=RUNNING)
后置条件
部署任务被标记为取消，远程执行清理操作（如删除临时文件），状态置为 CANCELLED
不变量
  • !更新 current 符号链接时，必须确保其原子性，避免出现中间状态导致服务不可用
  • !服务器上的部署目录必须遵循约定的目录结构，以保证回滚和共享文件正确

错误处理

处理策略

每个部署步骤失败时需记录详细错误日志，更新部署状态为 FAILED，并触发回滚流程；若回滚失败，进入 ROLLING_BACK 状态并告警
