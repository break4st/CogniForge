SSH连接池服务
⚙️ 业务服务

服务接口 (1)

🔧 SshConnectionPoolService 6 方法
execute_command
(request: ExecuteCommandRequest) -> CommandResult
在指定远程服务器上顺序执行一组命令，从连接池中获取或新建SSH连接，执行完毕后归还连接
前置条件
request.host、port、login_user、key_id、commands均非空且合法（host非空字符串、port在1-65535范围、commands至少1条不超过50条）；密钥管理服务必须正常运行可调用
后置条件
返回CommandResult包含完整的stdout和stderr文本及exit_code；使用完成后连接归还到池中（state从active变为idle）或异常时释放并从池中移除
SshAuthenticationError→ 401密钥管理服务返回解密失败，或Paramiko认证时远程服务器拒绝私钥SshConnectionTimeout→ 502TCP连接建立超过connection_timeout_seconds未成功SshHostUnreachable→ 502远程服务器网络不可达、DNS解析失败或端口未开放PoolExhaustedException→ 503连接池中所有连接均被占用且已达max_pool_size上限，新请求等待超过内部acquire_timeoutCommandExecutionTimeout→ 504远程命令执行超过channel.settimeout设定的超时时间SshChannelError→ 500在已建立的连接上调用open_session()创建Channel失败
test_connection
(request: TestConnectionRequest) -> TestConnectionResponse
建立临时SSH连接测试到目标远程服务器的连通性，验证密钥认证成功后立即关闭连接
前置条件
request.host、port、login_user、key_id均非空且合法
后置条件
返回TestConnectionResponse包含success标志和延迟指标；测试连接建立完毕后立即关闭，不加入连接池
SshAuthenticationError→ 401密钥解密失败或远程服务器拒绝私钥认证SshConnectionTimeout→ 502TCP连接建立超时SshHostUnreachable→ 502远程服务器不可达或端口未开放
release_connection
(host: str, port: int, login_user: str) -> bool
主动关闭并移除指定远程服务器的SSH连接，调用Paramiko transport.close()后清理池中记录
前置条件
host、port、login_user均非空；存在对应此三元组的活跃或空闲连接
后置条件
对应SshConnection被强制关闭并从池中移除，返回true；若不存返回false
ConnectionCloseError→ 500Paramiko transport.close()抛出异常（如已关闭的连接）
get_pool_metrics
() -> ConnectionMetrics
获取连接池当前运行状态的监控指标快照，用于健康检查和运维仪表盘
前置条件
无
后置条件
返回当前时刻连接池的快照指标（active、idle、total、pending、total_errors），不修改池状态
acquire_connection
(host: str, port: int, login_user: str, key_id: uuid) -> SshConnection
从池中获取或新建一个SSH连接，供内部文件传输等服务复用同一连接。返回的连接由调用方管理归还
前置条件
host、port、login_user、key_id均非空；该三元组在池中不存在或已有连接可用
后置条件
返回一个state为idle的SshConnection（池中已有或新建）；返回前验证transport.is_active()确保通道健康
SshAuthenticationError→ 401新建连接时密钥解密或认证失败SshConnectionTimeout→ 502新建连接建立超时SshHostUnreachable→ 502新建连接时目标不可达PoolExhaustedException→ 503池中无可用空闲连接且已达max_pool_size上限
cleanup_idle_connections
() -> int
周期性清理任务，由定时调度触发，遍历池中所有空闲连接移除超时连接以释放系统资源
前置条件
无
后置条件
所有（当前时间 - last_used_at）> idle_timeout_seconds 的空闲连接被关闭并从池中移除；返回被清理的连接数量
ConnectionCloseError→ 500关闭某个空闲连接时Paramiko抛出异常

本服务无数据库直接依赖，所有连接参数通过REST API入参传递
调用密钥管理服务 POST /api/keys/{id}/decrypt 获取SSH私钥明文（路径参数id为key_id）

业务规则

不变量
  • !同一 (host, port, login_user) 三元组在连接池中最多只能有一个空闲连接，避免对同一服务器建立冗余TCP连接
  • !池中总连接数（active + idle）始终不超过 max_pool_size
  • !空闲连接数始终不超过 max_idle_connections，超出部分必须在归还时被主动关闭
  • !空闲超过 idle_timeout_seconds 的连接必须被自动关闭并从池中移除
  • !连接分配前必须通过 transport.is_active() 验证通道活性，不活跃的连接必须先关闭再重建
  • !从密钥管理服务获取的私钥明文仅用于当前SSH连接认证，认证完成后立即将字节数组覆盖清零
  • !ConnectionState 状态转换必须严格遵循状态机定义，不允许非法跳跃
状态机
🎯 SshConnection
idleactivereconnectingclosederror
→新建SSH连接（connect）成功by 连接池管理器
→错误重试后新建连接成功by 连接池管理器
→从池中分配连接用于命令执行或通道创建by SshConnectionPoolService
→命令执行完成，释放通道后归还连接by SshConnectionPoolService
→健康检测发现transport断开（网络闪断）by 健康检查器
→重连成功，transport重新建立by 连接池管理器
→重试max_retry_attempts次后仍失败by 连接池管理器
→空闲超时关闭或主动调用release_connectionby 清理任务或外部调用
→手动清理异常连接by 连接池管理器
→命令执行中发生不可恢复异常（如SSH断开）by SshConnectionPoolService
🚫 状态进入closed或error后必须由连接池管理器创建全新连接才能回到idle，不可从closed/error直接转为active🚫 active到error的转换不可逆，异常连接不能直接恢复为active
⚡ 连接池内部使用threading.Lock保护connections列表的读写，分配和归还操作互斥。单个SshConnection的state变更通过连接对象级锁同步，防止同一连接被并发分配给多个请求
跨服务规则
调用密钥管理服务 POST /api/keys/{id}/decrypt 获取私钥明文后，必须在SSH认证完成（connect或auth）后立即将明文字节数组填充为零并销毁，禁止将私钥明文写入日志、缓存或持久化到任何存储
密钥管理服务调用失败（HTTP 4xx/5xx或网络超时）时，SSH连接池服务向上返回401并不再对该key_id重试，避免频繁无效请求导致密钥管理服务过载
文件传输服务必须通过acquire_connection获取已有SshConnection，在其transport上打开SCP/SFTP通道，不得绕过连接池直接建立SSH连接
当密钥管理服务不可用时，所有依赖SSH连接池的接口（execute、test）统一返回503，并记录内部健康检查告警

错误处理

处理策略

所有SSH操作异常统一捕获并按分类映射为HTTP状态码返回。认证类异常返回401，网络类异常返回502，资源耗尽返回503，超时类异常返回504。使用Paramiko异常层次进行归类映射，私钥内容等敏感信息不出现在错误消息中。连接池内部异常不影响已分配给其他请求的连接。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
400
参数校验错误
请求参数缺失或格式错误，如host为空、port超出范围(1-65535)、commands为空列表或超过最大条数限制

密钥解密失败（密钥管理服务返回错误）、私钥格式不正确、远程服务器拒绝认证。触发时立即释放该连接并从池中移除
502
SSH连接失败
远程服务器不可达、端口未开放、DNS解析失败、TCP握手超时。自动重试max_retry_attempts次后仍失败才向调用方返回

远程命令在Paramiko channel.settimeout设定的时间内未完成执行，将关闭该channel
500
