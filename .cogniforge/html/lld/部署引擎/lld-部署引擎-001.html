概述

部署引擎
⚙️ 业务服务
部署引擎负责解析部署请求，协调环境管理、密钥管理、SSH客户端等模块，执行文件上传、脚本生成、符号链接更新等部署步骤，并实时推送部署进度。
依赖: 环境管理模块（获取环境及关联密钥信息）密钥管理模块（获取解密后的SSH私钥）SSH客户端模块（建立连接、上传文件、执行远程命令）本地数据库（保存部署记录）
Node.js (主进程)Electronssh2SQLite
基于: PRD prd-001 v1 · SAD sad-001 v1
📐 模块边界
范围内: 接收部署请求（envId, localFilePath, remoteDeployPath） 通过环境管理模块获取环境详情及关联密钥 通过密钥管理模块获取解密私钥 建立SFTP连接并上传文件至远程新建版本目录 生成启动脚本 更新current符号链接 部署过程中实时推送进度事件 部署失败清理不完整文件 部署成功后保存部署记录
范围外: 环境配置的增删改查（由环境管理模块负责） 密钥的导入、加密存储和检索（由密钥管理模块负责） 历史记录的查询与回滚（由历史管理模块负责） SSH底层连接管理（由SSH客户端模块负责） 数据库表的定义与维护（由本地数据库负责）
拥有组件: CMP-005
实现契约: CTR-005
消费契约: CTR-007 CTR-008

服务接口 (1)

🔧 DeployEngineService 3 方法
startDeploy
(deployRequest: DeployRequest) -> Observable<DeployProgress>
启动部署的主流程。返回一个可观察对象，实时推送部署进度。
前置条件
传入的 deployRequest 必须包含有效的 envId, localFilePath, remoteDeployPath；环境及关联密钥必须存在且可用。
后置条件
部署成功：文件已上传至远程新版本目录，启动脚本已生成，current 符号链接已更新，部署记录已持久化；部署失败：远程已部分创建的文件和目录被清理，部署记录标记为失败。进度事件流正常结束。
EnvironmentNotFoundException→ 404根据 envId 无法找到对应的环境KeyRetrievalException→ 500无法获取关联密钥或私钥解密失败ConnectionFailedException→ 502SSH 连接建立失败FileUploadFailedException→ 500文件上传过程中出错RemoteExecutionException→ 500远程命令执行失败
cancelDeploy
(deployId: string) -> void
取消正在进行的部署（保留，暂不实现）。
前置条件
部署正在进行中，存在对应的部署ID。
后置条件
部署流程被标记为取消，正在进行的操作将被中断或回滚，进度事件流发送取消状态。
DeployNotFoundException→ 404未找到进行中的部署
onProgress
(event: DeployProgress) -> void
用于推送部署进度事件的内部方法，通过调用 IPC 模块实现。
前置条件
部署流程已启动，存在有效的 IPC 通道。
后置条件
进度事件通过 IPC 发送到 GUI 渲染进程。
数据访问依赖
findEnvironmentById(envId: string) -> EnvironmentInfo?
findKeyMaterialById(keyId: string) -> SSHKeyMaterial?
saveDeployRecord(record: DeployRecord) -> void
updateDeployRecordStatus(deployId: string, status: string) -> void
不变量
  • !部署前必须验证本地文件存在，否则拒绝部署
  • !远程部署路径必须以 '/' 开头且不为根目录 '/'
  • !同一环境同一时间只能有一个部署任务在执行
  • !版本目录名必须唯一，格式为 'v_YYYYMMDD_HHmmss_SSS' 避免冲突
  • !current符号链接必须始终指向一个已成功部署的版本目录
  • !部署过程中任何一步失败都应清理已创建的远程版本目录（如果有）
  • !部署记录必须在部署结束（成功或失败）后立即持久化到数据库

🎯 Deployment
PENDINGPREPARINGCONNECTINGUPLOADINGGENERATING_SCRIPTUPDATING_SYMLINKRECORDINGSUCCEEDEDFAILEDCANCELLED
→startDeploy()调用by 用户
→环境信息与密钥获取成功by 系统
→环境或密钥获取失败by 系统
→SSH连接建立成功by 系统
→SSH连接失败by 系统
→文件上传全部完成by 系统
→文件上传过程中出错by 系统
→启动脚本生成并上传成功by 系统
→脚本生成或上传失败by 系统
→符号链接更新成功by 系统
→符号链接更新失败，且无法回滚by 系统
→部署记录保存成功by 系统
→部署记录保存失败by 系统
🚫 一旦状态变为FAILED或SUCCEEDED，不能回退到其他状态🚫 进入UPLOADING后不能回退到PREPARING或CONNECTING🚫 取消操作仅在PENDING、PREPARING或CONNECTING状态下可能执行（暂不实现接口，规则预留）
⚡ 通过环境级别的互斥锁保证同一环境同一时刻只有一个活动部署；若新请求到达时已有部署处于非终态（FAILED/SUCCEEDED），则拒绝新请求并返回错误。
跨服务规则
部署引擎必须通过环境管理模块（CTR-007）获取环境详情，不得直接访问环境数据库
解密后的私钥必须通过密钥管理模块（CTR-008）获取，部署引擎不得缓存或存储私钥
SSH连接配置（DO-007）由部署引擎组装，但连接建立与命令执行必须通过SSH客户端模块进行
部署进度事件（DO-002）必须通过IPC主动推送到GUI（IF-003），频率至少在每个状态变更时推送
部署记录持久化使用本地数据库，但表结构由本地数据库模块维护，部署引擎仅通过数据访问层操作

编排流程

部署执行主流程

部署引擎的主流程，按顺序执行环境准备、密钥获取、连接建立、文件上传、脚本生成、符号链接更新及记录持久化。

1
验证请求参数 (5s 超时)
检查 envId, localFilePath, remoteDeployPath 的存在性和有效性
失败处理: 返回参数错误，部署终止
2
获取环境信息 (10s 超时)
调用环境管理模块获取环境详情及关联的密钥ID
失败处理: 返回环境不存在错误，部署终止
3
获取SSH密钥 (10s 超时)
调用密钥管理模块获取解密后的私钥
失败处理: 返回密钥获取失败错误，部署终止
4
建立SSH连接 (15s 超时)
使用环境信息和私钥建立SFTP连接
失败处理: 返回连接失败错误，部署终止
5
创建远程版本目录 (10s 超时)
在远程部署路径下创建基于时间戳的版本目录
失败处理: 返回远程文件操作失败错误，部署终止
6
上传文件 (300s 超时)
将本地文件递归上传到远程版本目录
失败处理: 清理已创建的版本目录，返回上传失败错误，部署终止
7
生成启动脚本 (10s 超时)
在版本目录中生成标准启动脚本
失败处理: 清理已上传的内容，返回远程执行失败错误，部署终止
8
更新符号链接 (10s 超时)
将 current 符号链接指向新版本目录
失败处理: 返回符号链接更新失败错误，部署终止（不清理，避免影响现有版本）
9
保存部署记录 (5s 超时)
将部署结果写入数据库
失败处理: 记录日志但不影响部署成功状态（最终一致性）
重试策略: 最多 3 次，间隔 30s
可重试错误: NETWORK_ERROR, TIMEOUT
不可重试错误: AUTH_ERROR, CONFIG_ERROR

启动部署流程，接收环境ID、本地文件路径、远程部署路径等参数，异步执行部署，并实时推送进度。

取消正在进行的部署（暂未实现，保留）。

字段类型

通过 Electron IPC 向渲染进程推送部署进度事件，包含当前步骤、总体百分比、消息等。

错误处理

处理策略

所有部署错误统一通过 try-catch 捕获，转换为标准错误响应体（DeployError），包含业务错误码与详细信息，并通过进度事件推送错误状态。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
4xx
参数错误
缺少必要参数（envId, localFilePath, remoteDeployPath）或格式无效，返回错误码 4001。
4xx
环境不存在
通过环境管理模块查询环境信息时，若环境不存在或已删除，返回错误码 4002。
4xx
密钥获取失败
关联密钥不存在或密钥管理模块无法解密，返回错误码 4003。
4xx
本地文件不存在
指定的 localFilePath 在本地文件系统中不存在，返回错误码 4004。
5xx
SFTP连接或认证失败
SSH客户端无法建立连接或认证失败（主机不可达、端口错误、密钥不匹配等），返回错误码 5001。
5xx
远程文件操作失败
上传文件、创建目录、更新符号链接等远程操作失败，或远程磁盘空间不足，返回错误码 5002。
5xx
部署过程异常中断
部署过程中发生未预期错误（如网络中断、进程崩溃），已上传内容将被清理，返回错误码 5003。
5xx
进度推送失败
向GUI推送进度事件时IPC通道异常，不影响部署主流程，但会记录日志，返回错误码 5004。
