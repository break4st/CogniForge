概述

Web前端
🖥️ 前端
用户交互界面，提供项目管理和一键部署的操作入口。基于 Vue 3 + Element Plus 构建单页应用，通过 REST API 和 WebSocket 与后端交互，实现项目全生命周期管理、环境配置、一键部署和实时状态监控。
依赖: API网关
Vue 3Element PlusVite
🧩

组件树 (1)

AppLayout/

应用主布局组件。采用左右结构：左侧为固定侧边栏（项目切换 + 导航菜单），右侧为页头 + 内容区（路由视图），所有页面共享此布局

State
sidebarCollapsed: boolean
行为
  • onMounted 时检查本地存储的认证 Token，若不存在则重定向至登录页
  • 监听路由变化自动更新侧边栏的菜单激活项
  • 响应式布局：视口宽度 < 768px 时自动折叠侧边栏
边界情况
  • ⚠️ 页面首次加载时显示全局骨架屏，避免白屏闪烁
  • ⚠️ 路由切换时保持侧边栏和页头状态不变
  • ⚠️ Token 校验异步完成后才渲染子路由，避免未认证闪现内部页面

错误处理

处理策略

统一通过 Axios 拦截器捕获 HTTP 错误，按状态码分类处理：401 跳转登录页、403/404 展示友好提示组件、5xx 展示服务不可用通知。业务错误从响应体解析 code + error + detail 并通过 ElMessage 展示。WebSocket 断开时自动重连（最多 5 次，间隔指数退避），重连失败降级为轮询。所有接口调用在组件内维护 loading 和 error 状态，供给模板条件渲染错误/重试 UI。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
400
参数校验错误
表单提交时参数不合法（名称空、长度超限、格式错误等），由前端表单校验或后端返回的校验错误触发，前端高亮对应字段并展示错误消息
401
未认证
用户 Token 过期或未提供，Axios 响应拦截器检测到 401 后清除本地 Token 并跳转登录页
403
权限不足
当前用户无权操作指定资源，展示 ElAlert 提示无权限并禁用相关操作按钮
404
