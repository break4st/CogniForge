概述

环境配置服务
⚙️ 业务服务
管理每套部署环境的连接参数、目标服务器信息和关联密钥，提供环境CRUD操作、环境类型管理（测试/灰度/正式）、服务器目标配置、环境与密钥关联管理、连通性验证能力。本服务是部署流程的前置条件模块，为部署编排服务提供环境配置基础数据。
依赖: PostgreSQL数据库密钥存储服务
GoGinPostgreSQL 15golang.org/x/crypto/ssh

业务规则

不变量
  • !同一项目下环境名称必须唯一（逻辑唯一：不包含已软删除的记录）
  • !环境类型 env_type 必须为预定义的枚举值之一: test（测试）、gray（灰度）、production（正式）
  • !SSH 端口号必须在 1-65535 有效范围内，默认值为 22
  • !环境连通性 status 必须为 EnvironmentStatus 枚举值之一: unknown、reachable、unreachable
  • !软删除的环境不可被查询、更新和连通性验证操作访问
  • !环境必须关联有效的 project_id，外键约束由数据库保证
状态机
🎯 Environment.status
unknownreachableunreachable
→连通性验证成功by 系统（SSH连接测试）
→连通性验证失败by 系统（SSH连接测试）
→连通性重验证失败by 系统（SSH连接测试）
→连通性重验证成功by 系统（SSH连接测试）
🚫 所有状态转换均为可逆的：reachable 和 unreachable 之间可互相转换，unknown 可转换为任一方。不存在不可逆的状态转换。
⚡ 同一环境同一时刻只允许执行一个连通性验证任务。通过分布式锁（Redis SETNX）实现，锁超时 60s，防止并发 SSH 连接导致服务器压力过大。
跨服务规则
删除环境前需通过部署编排服务查询该环境是否存在关联的部署记录，存在关联时拒绝删除并返回 409
创建/更新环境时如果指定了 key_id，必须调用密钥存储服务（GET /api/v1/keys/{id}）校验该密钥存在且有效
连通性验证时，必须调用密钥存储服务获取解密后的 SSH 私钥内容，不得在本服务中存储或缓存明文凭证
环境配置的创建、更新、删除操作完成后，应向审计日志服务发送操作记录事件（通过消息队列异步投递）
连通性验证结果（reachable/unreachable）需回写数据库，状态变更可被部署编排服务读取用于部署前的环境健康检查

错误处理

处理策略

采用分层错误处理：API 层负责参数校验和 HTTP 状态码映射，服务层抛出业务语义异常，数据访问层将数据库错误转换为持久化异常。SSH 连接错误由连接池捕获并转换为结构化响应，超时和网络错误区分对待。

统一错误响应体
字段类型
codeinteger
errorstring
detailstring
400
请求参数错误
必填字段缺失、env_type 不在合法枚举值范围内、端口号超出有效范围(1-65535)等输入校验失败，响应 detail 中给出具体字段错误信息
404
资源不存在
指定的 environment_id 或 project_id 在数据库中不存在或已被软删除，由服务层 NotFoundError 映射
409
资源冲突
同一项目下环境名称重复、环境存在关联部署记录无法删除等业务约束冲突，由服务层业务异常映射
502
外部服务调用失败
调用密钥存储服务获取解密凭证时连接失败、超时或返回异常响应，使用指数退避重试1次，仍失败则向上层抛出
504
SSH连接超时
环境连通性验证时 SSH 连接超时，超时阈值 15s，超时后记录日志并将环境 status 更新为 unreachable
