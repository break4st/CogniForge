概述

一键发 (OneDeploy) 是一款跨项目的一键式自动化部署工具，用于将本地打包的可执行文件快速部署到多套远程服务器环境。系统支持用户创建和管理多个项目，每个项目可配置测试、灰度、生产等多套独立环境，并通过加密的SSH密钥或密码安全连接。部署时自动在远程服务器创建版本文件夹、上传文件并执行自定义脚本，同时提供版本历史追溯与一键回滚能力，显著提升多项目并行部署的效率与可靠性。

功能需求 (7)

REQ-001 项目管理draft高 v1

用户可以创建、编辑、归档和切换多个项目，每个项目拥有独立的名称和远程根目录，作为组织所有部署活动的基本单元。
验收条件
  • 创建项目：填写名称和远程根目录后点击保存，项目出现在项目列表中
  • 编辑项目：修改名称或根目录后保存，信息即时更新
  • 归档项目：归档后项目不在主列表显示，但可在归档列表找回并恢复
  • 切换项目：点击切换当前项目，界面中的环境列表、部署历史等数据实时刷新为对应项目内容

REQ-002 多环境配置draft高 v1

在项目下可添加多套部署环境（如测试线、灰度线、正式线），为每个环境配置独立的服务器IP/域名、SSH端口、远程工作目录等，并支持连接测试。
依赖: REQ-001
验收条件
  • 添加环境：填写环境名称、服务器地址、端口（默认22）、远程工作目录（留空则继承项目根目录）后保存，环境出现在列表
  • 编辑与删除：修改或删除环境信息，列表即时更新
  • 环境隔离：不同项目下的环境列表互不影响
  • 连接测试：点击测试按钮，系统尝试SSH连接并反馈成功或失败原因

REQ-003 安全密钥管理draft高 v1

支持SSH密码、SSH密钥对（文本或文件导入）、跳板机代理三种连接方式，所有密钥信息本地加密存储，通过主密码解锁。
依赖: REQ-002
验收条件
  • 密钥方式选择：新建/编辑环境时可从密码、密钥文件、密钥文本、跳板机模式中选择
  • 加密存储：配置完密钥后，关闭应用再打开，需输入主密码才能解密并列出环境
  • 主密码设置：首次使用时引导设置主密码，主密码不在磁盘明文存储
  • 连接测试：使用当前密钥配置进行SSH连接测试，显示详细错误信息

REQ-004 一键自动化部署draft高 v1

选择本地可执行文件，一键部署到指定项目目标环境。流程包括：连接远程服务器、创建版本文件夹（名称含版本号和时间戳）、上传文件、生成并执行部署脚本。
依赖: REQ-002, REQ-003
验收条件
  • 文件选择与部署触发：用户浏览本地文件，点击“部署”后开始流程
  • 版本文件夹创建：远程目标路径下创建类似 v1.0.0_202605241500 的文件夹
  • 文件上传：本地可执行文件成功上传至该版本文件夹
  • 脚本执行与日志：用户可在部署窗口中实时看到远程命令的标准输出/错误输出，最终显示部署成功或失败
  • 部署记录：部署结束后自动保存一条历史记录

REQ-005 部署脚本模板draft中 v1

支持为每个环境自定义部署脚本模板，包含占位符（如{APP_NAME}、{VERSION_DIR}等），部署时动态替换生成最终脚本并顺序执行。
依赖: REQ-004
验收条件
  • 模板编辑：在环境配置界面提供脚本模板编辑区，支持多步骤脚本
  • 占位符替换：部署时模板中所有占位符被正确替换为实际值
  • 执行顺序：模板中定义的脚本步骤按顺序执行
  • 内置默认模板：系统提供一份通用默认模板，用户可在此基础上修改

REQ-006 部署历史与一键回滚draft中 v1

记录每次部署的详细信息，提供按项目/环境筛选的部署历史列表，并支持从历史记录中一键回滚到任意版本。
依赖: REQ-004
验收条件
  • 历史记录条目：包含项目名、环境名、部署时间、版本号、本地文件路径、远程目录、执行结果、日志快照
  • 筛选与搜索：可按项目、环境、时间范围筛选历史，支持关键字搜索
  • 一键回滚：点击某次成功部署记录中的“回滚”按钮，系统执行预定义回滚操作（如切换current软链接或重新部署该版本），回滚后可执行额外命令

REQ-007 多项目快速切换与收藏draft低 v1

提供便捷的项目切换器，支持将常用项目收藏置顶，切换后整个界面上下文（环境、历史）即时更新。

  • 收藏功能：项目列表中有星标按钮，收藏的项目始终排在前列
  • 上下文完整性：切换项目后，环境列表、部署历史、脚本模板等所有关联数据立刻刷新为新项目数据
