概述

本产品旨在解决开发团队手动部署可执行文件到远程服务器时过程繁琐、易出错的问题。用户可在系统中维护多套远程部署环境（如测试线、灰度线、正式线），通过SSH密钥或密码安全认证，将打包好的可执行文件自动上传至目标服务器，并自动在远程创建带版本号的发布目录，同时生成启停脚本，实现一键部署。系统还支持多项目管理，每个项目拥有独立的部署环境配置，开发、测试、运维人员可在不同项目间灵活切换，高效并行管理多个产品的发布流程。

功能需求 (8)

REQ-001 远程服务器配置管理draft高 v1

提供界面或配置项，允许用户新增、修改、删除远程服务器信息，包括服务器IP/域名、SSH端口、认证方式（密钥文件或密码）、连接用户。系统需支持测试连接功能以验证配置的正确性。
验收条件
  • 用户可以添加一台新服务器，填写IP、端口、用户名、并上传私钥文件或输入密码
  • 系统提供“测试连接”按钮，点击后根据当前配置尝试SSH连接，并返回成功或失败的具体原因
  • 用户可编辑已有服务器配置，修改后重新测试连接
  • 已添加的服务器列表正确显示所有服务器，支持搜索和删除（需二次确认）

REQ-002 部署环境配置draft高 v1

支持用户创建多套自定义部署环境（如测试、灰度、正式），每套环境可绑定一台目标服务器，并配置部署路径基目录、环境变量、自定义命令模板（如安装依赖、重启服务）。环境配置归属于某个项目，支持复制环境以快速创建相似配置。
依赖: REQ-001
验收条件
  • 用户在当前项目下可新建环境，输入环境名称、选择关联服务器、填写远程部署路径（基础目录）
  • 环境配置中包含“版本文件夹模板”字段（默认：{project}_{version}_{datetime}），用于生成唯一目录名
  • 提供脚本模板编辑器，可自定义部署前/后执行的 shell 脚本（提供常用变量如{deploy_path}）
  • 支持环境顺序调整、禁用、删除，环境列表清晰展示关联服务器、最后部署时间等信息

REQ-003 一键自动化部署draft高 v1

选择一个目标环境后，上传打包好的可执行文件（如 .zip, .tar.gz），系统将通过SSH连接至目标服务器，在指定基础路径下创建版本文件夹，上传并解压文件，然后根据配置的脚本模板生成启动、停止、重启等脚本，并自动赋予可执行权限。整个过程提供实时日志反馈，并在部署完成或失败后给出明确结果。
依赖: REQ-001, REQ-002
验收条件
  • 用户在环境详情页点击“部署”，选择本地打包文件或从构建系统（如 Jenkins 产出）获取文件路径
  • 输入部署版本号（支持手动输入或自动生成递增版本号）及可选的备注信息
  • 点击“开始部署”后，界面实时显示 SSH 连接、创建目录、上传文件、解压、生成脚本等步骤的进度日志
  • 远程服务器上最终生成类似 /opt/app/test_v1.2.0_202503011430 的目录，内含应用文件及 start.sh, stop.sh 等脚本
  • 部署完成后生成一条部署记录，记录部署人、时间、版本、环境等信息

REQ-004 版本文件夹与脚本自动生成draft高 v1

部署时在远程服务器上创建规范的版本文件夹，命名规则可配置，并自动生成具有执行权限的启动、停止、重启、状态检查等辅助脚本，脚本内容根据环境配置中的模板填充，支持变量替换，确保应用可被统一管理。
依赖: REQ-002
验收条件
  • 远程版本文件夹名称使用用户定义的模板动态生成，至少包含项目标识、版本号和时间戳，确保不同版本不冲突
  • 生成的 start.sh 脚本中包含了启动应用的具体命令，该命令来自环境配置的“启动命令”字段
  • 生成的 stop.sh 脚本能安全停止应用（如查找 PID 文件或进程名），具备超时强制终止能力
  • 所有生成的脚本权限自动设为 755，且包含 shebang 头

REQ-005 多项目管理draft中 v1

系统支持创建多个项目，每个项目拥有独立的服务器列表、部署环境配置、部署历史和成员权限（可选）。用户可随时在不同项目之间切换，项目数据完全隔离，确保多线开发时部署配置互不干扰。
验收条件
  • 系统首页显示项目列表，支持创建新项目，填写项目名称、描述
  • 点击某个项目进入后，仅展示属于该项目的服务器、环境、部署记录，与其他项目隔离
  • 项目切换导航清晰，当前项目标识始终可见
  • 支持删除项目（需确认）并级联删除其下所有配置及历史，或提供归档功能

REQ-006 安全连接与密钥管理draft高 v1

所有与远程服务器的连接均使用 SSH 加密协议，支持的认证方式包括 SSH 私钥和密码。用户上传的私钥文件应加密存储于数据库或安全文件系统，界面显示时脱敏处理，密码同样加密存储。支持在服务器配置中管理多把密钥，并可标记默认密钥。
依赖: REQ-001
验收条件
  • 添加服务器时，选择“密钥认证”可上传私钥文件，系统不予明文展示
  • 密钥文件在后台以加密形式存储（如 AES-256），使用时解密
  • 密码认证时，密码字段以密文存储，编辑时回显为占位符，需重新输入才可修改
  • 对于同一服务器可关联多个密钥/密码，部署时可选择本次使用的认证方式

REQ-007 部署历史与日志查询draft中 v1

记录每一次部署的详细信息，包括项目、环境、版本、操作人、开始/结束时间、执行状态（成功/失败）、日志文件链接。支持按时间、环境、状态筛选，并可查看某次部署的详细输出日志。
依赖: REQ-003
验收条件
  • 每次部署完成后自动生成一条历史记录，字段完整
  • 提供历史列表界面，支持按项目内多条件组合筛选，支持分页
  • 点击某条历史记录可展开部署期间的完整实时日志（或下载日志文件）
  • 部署失败时，日志中高亮显示错误信息，并支持一键重试（使用相同参数重新发起部署）
