概述

本产品旨在实现将打包好的可执行文件一键部署到指定远程服务器，支持自定义多套环境（测试、灰度、正式等），通过密钥认证安全连接，部署时自动创建版本文件夹并生成执行脚本。同时支持用户创建和管理多个项目，每个项目拥有独立的部署环境配置，可在项目间灵活切换，满足多项目并行管理需求。

功能需求 (10)

REQ-001 项目生命周期管理draft高 v1

用户能够创建、编辑、删除项目，每个项目拥有唯一名称和描述信息。项目是承载部署环境的容器，所有环境配置归属在具体项目下。
验收条件
  • 用户可以点击“新建项目”填写项目名称和描述，点击保存后项目出现在项目列表中
  • 项目名称支持编辑，编辑后不影响已关联的环境配置
  • 删除项目时会提示确认，并一同删除该项目下所有环境和部署历史

REQ-002 多环境配置管理draft高 v1

在每个项目内，用户可以新建、编辑、删除多个部署环境（如测试线、灰度线、正式线等）。每个环境需配置服务器地址（IP/域名）、SSH端口、登录用户名、远程部署根目录、认证方式（密钥或密码）以及可选的备注信息。
依赖: REQ-001
验收条件
  • 在项目详情页，用户可添加新环境，选择环境类型标签（可自定义）
  • 环境配置信息保存后可再次编辑，修改后连接测试需重新验证
  • 环境支持拖动排序，方便常用环境靠前展示
  • 每个项目至少需要存在一个环境，但无环境时不阻止项目删除

REQ-003 SSH密钥安全存储draft高 v1

支持用户生成新的SSH密钥对或导入已有的私钥文件。私钥在本地存储时必须经过加密，不允许以明文形式保存。密钥可绑定到环境配置中用于认证。
依赖: REQ-002
验收条件
  • 提供生成密钥按钮，生成后用加密方式保存私钥，公钥可导出
  • 导入私钥时支持密码保护的私钥，提示用户输入私钥密码
  • 配置环境时可选已保存的密钥，保存后密钥文件以AES-256加密存储在本地数据库
  • 环境使用密钥连接时，调用解密后的私钥，连接过程不落地明文文件

REQ-004 版本部署执行draft高 v1

用户选择目标项目和环境后，指定本地可执行文件或压缩包路径，输入版本号（或自动使用时间戳），点击部署按钮触发自动化部署流程。系统将文件上传至远程服务器指定目录，创建版本文件夹，生成脚本并可选择立即启动服务。
依赖: REQ-002, REQ-003
验收条件
  • 部署界面提供文件选择器，支持拖拽文件指定部署包
  • 可输入自定义版本号（如v1.3.2），不输入时系统自动生成“YYYY-MM-DD-HHmmss”格式版本
  • 点击部署后，前端显示进度条，实时展示上传进度和远程执行状态
  • 部署完成后在目标服务器上出现新版本文件夹，如 `/deploy/versions/v1.3.2_2026...`
  • 若部署过程出错（网络断开、权限不足等），界面给出明确错误提示，并停止后续操作

REQ-005 远程目录与脚本生成draft高 v1

部署时，系统在远程服务器上基于“远程部署根目录 + versions/”下创建以版本号命名的子目录，将上传的文件解压或直接放入该目录，并根据环境配置中的模板生成启动脚本（start.sh）、停止脚本（stop.sh）等，并赋予可执行权限。可在环境配置中自定义脚本模板。
依赖: REQ-002, REQ-004
验收条件
  • 版本文件夹命名规则为 {自定义版本号}_{时间戳}，保证唯一
  • 默认启动脚本包含设置环境变量、执行可执行文件的命令，停止脚本包含kill进程或调用应用停止接口的命令
  • 用户可在环境编辑区自定义启动/停止脚本内容，支持变量占位符（如 {{APP_PATH}}、{{PORT}}）
  • 脚本生成后，系统自动执行 `chmod +x` 确保脚本可执行
  • 若环境配置勾选了“部署后立即启动”，则在部署完成后执行 start.sh，并将输出返回前端

REQ-006 部署历史与日志管理draft中 v1

系统记录每次部署的元数据（项目、环境、版本、操作时间、操作用户、状态、日志链接），提供查看界面，支持按时间、项目筛选，并可以针对历史成功版本一键回滚（重新执行该版本的启动脚本或切换符号链接）。
依赖: REQ-004
验收条件
  • 在部署历史页面，能够列出所有部署记录，分页显示，支持按项目和状态筛选
  • 每条记录可展开查看完整日志输出
  • 对状态为“成功”的历史记录，提供“回滚”按钮，点击后将该版本的 start.sh 重新执行一次，并生成一条新的回滚部署记录
  • 回滚操作可配置是否需要人工确认

REQ-007 项目与环境快速切换draft中 v1

提供全局的项目选择器，用户可在任意界面顶部或侧边栏切换当前工作项目，切换后所有环境列表、部署表单都更新为对应项目的数据。支持搜索或多级分组。

  • 支持输入关键字快速筛选项目

REQ-008 连接测试与诊断draft高 v1

在环境配置页面提供“测试连接”按钮，系统尝试使用配置的密钥和端口连接目标服务器，验证连通性、认证是否成功以及目标部署路径是否存在或有创建权限，并反馈详细结果。
依赖: REQ-002, REQ-003
验收条件
  • 点击测试连接后，显示进度和最终结果：成功或失败原因（如网络不通、密钥被拒绝、路径权限不足等）
  • 测试通过后界面给予明确的成功提示

REQ-009 部署前校验draft中 v1

在真正执行远程操作前，对本地文件是否存在、远程磁盘空闲空间是否足够、版本号是否与已有文件夹冲突等进行检查，并提前告知用户，避免部署失败。
依赖: REQ-004
验收条件
  • 点击部署后先进行校验，校验不通过时给出警告并阻止部署，同时列出具体原因
  • 校验项目至少包含：本地文件存在性、远程磁盘空间（通过df命令）预估、版本文件夹名称唯一性
  • 用户可忽略某些非致命警告（如空间不足但勉强可压）继续部署，需二次确认

REQ-010 配置文件导入导出draft低 v1

支持将全部项目、环境、密钥配置导出为加密的备份文件，也支持导入，便于迁移工具到其他电脑或分享同组配置。
依赖: REQ-001, REQ-002, REQ-003
验收条件
  • 提供导出按钮，生成一个加密的压缩包，内含所有非敏感配置（密钥仍加密）
  • 导入时要求输入导出时设置的密码解密，并校验完整性
  • 导入后不会覆盖现有同名项目，提供合并或重命名选项
