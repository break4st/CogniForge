系统概述

系统定位

本系统采用本地桌面应用架构，提供一键式可执行文件远程自动化部署功能。用户可通过桌面UI管理多项目、多环境，安全存储SSH密钥，并自动完成文件上传、脚本生成等部署步骤。

架构设计

桌面应用分层架构
采用 Electron 桌面应用架构，分离渲染进程（UI）与主进程（业务逻辑）。渲染进程负责用户交互，主进程处理核心逻辑、SSH连接、文件操作和本地数据持久化。设计分层包括表现层、业务逻辑层和数据层，模块化设计确保可维护性。

组件设计 (10)

表现层 1

🖥️ Desktop UI

frontend

Electron 渲染进程，提供用户交互界面，支持拖拽文件、进度展示、项目与环境管理、部署历史查看等。

  • 展示UI
  • 接收用户操作
  • 通过IPC发送指令到主进程
  • 实时展示部署进度
业务逻辑层 8

⚡ Main Process

infrastructure

Electron 主进程，作为应用入口，管理窗口创建，并提供IPC通道处理渲染进程请求，协调各业务模块。

  • 窗口管理
  • IPC通信协调
  • 加载各业务模块

⚙️ SSH Client

service

封装SSH连接与操作，支持密钥认证，用于连接远程服务器执行命令和文件传输。

  • 建立SSH连接
  • 执行远程命令
  • 上传文件(SFTP)
  • 测试连通性

⚙️ Project Manager

service

管理项目实体的增删改查，提供当前项目上下文。

  • 创建/编辑/删除项目
  • 项目列表查询
  • 切换当前项目

⚙️ Environment Manager

service

管理项目下的部署环境配置，包括服务器信息、密钥关联，并提供连通性测试。

  • 增删改查环境配置
  • 关联密钥
  • 连通性测试
  • 环境排序

⚙️ Deploy Executor

service

执行部署流程，按步骤协调SSH连接、文件上传、脚本生成、权限设置等。

  • 执行部署步骤
  • 进度反馈
  • 失败中断与错误处理
  • 部署完成摘要生成

⚙️ File Manager

service

处理本地文件读取和远程脚本模板生成，生成start.sh等脚本。

  • 读取可执行文件
  • 生成启动/停止/重启脚本
  • 计算文件哈希以校验完整性

⚙️ Key Manager

service

负责SSH私钥的加密存储、加载、验证与缓存，确保密钥安全。

  • 加密存储私钥
  • 解密密钥到内存
  • 验证密钥格式
  • 绑定密钥到环境

⚙️ Log Manager

service

记录部署操作日志，提供查询和导出功能。

  • 记录部署日志
  • 日志查询与筛选
  • 导出日志为TXT/CSV
数据层 1

🗄️ Local DB

database

基于SQLite的本地数据库，存储项目、环境、密钥元数据、部署历史等结构化数据。

  • 持久化存储
  • 查询与事务支持

数据流

1
一键部署流程
用户在Desktop UI选择项目、环境和文件→UI通过IPC发送部署请求到Main Process→Main Process调用Deploy Executor→Deploy Executor使用SSH Client连接远程服务器→SSH Client建立SSH连接→Deploy Executor在远程创建版本文件夹→File Manager读取本地文件并通过SSH Client上传→上传过程中通过IPC向UI报告进度→File Manager生成启动、停止、重启脚本并上传→SSH Client执行chmod设置脚本可执行权限→Deploy Executor记录部署日志到Log Manager→Log Manager写入Local DB→Deploy Executor返回结果给Main Process→Main Process通过IPC通知UI完成
2
环境连通性测试流程
用户在Desktop UI点击测试按钮→UI发送测试请求到Main Process→Main Process调用Environment Manager→Environment Manager获取环境配置及关联的密钥→Environment Manager调用SSH Client尝试连接→SSH Client建立连接并返回结果→Environment Manager返回结果给Main Process→Main Process通过IPC通知UI显示测试结果
