系统概述

系统定位

DeployForge 是一款面向开发者的轻量级跨平台桌面工具（基于 Electron），用于本地管理多个项目并一键部署到远程服务器。系统提供直观的图形界面，允许用户配置多套环境（测试、灰度、生产），并进行安全的 SSH 连接、文件上传、版本化目录管理、启动脚本生成、部署历史追溯及回滚等操作。所有敏感数据在本地加密存储，部署过程提供实时进度反馈。

架构设计

分层架构 + 微内核（Electron 桌面应用）
整体分为表现层、通信层、核心服务层和存储层。表现层使用 React 构建，通过 Electron IPC 与主进程通信；核心服务层包含项目管理、环境管理、部署编排、SSH 客户端、脚本模板、历史版本、加密等服务；存储层使用 SQLite 和本地文件系统。

数据流

1
一键部署流程
用户在前端选择项目和环境，拖拽文件并点击部署→前端发送 IPC 'deploy:start' 到主进程→部署编排引擎调用环境管理服务获取解密后的 SSH 配置→部署编排引擎通过 SSH 客户端连接远程服务器→在远程基础路径下创建版本目录（如 20260524_1642）→通过 SFTP 上传本地文件至版本目录，并实时推送进度到前端→调用脚本模板服务渲染 start.sh 和 stop.sh→上传脚本文件并赋予执行权限→若启用自动启动，远程执行 start.sh 并获取 PID→部署编排引擎将结果（成功/失败、版本号、远程路径）记录到历史版本服务→向前端返回最终部署状态和日志
2
版本回滚流程
用户在前端历史记录中选择某个版本，点击回滚→前端发送 IPC 'history:rollback' 到主进程→历史版本服务根据历史记录 ID 获取部署详情和环境配置→通过 SSH 客户端连接远程服务器→修改 current 软链接：rm -f current && ln -s {版本目录} current→可选：执行新 current 目录下的 start.sh 重启服务→历史版本服务更新数据库中的 is_current 标记→向前端返回回滚结果
