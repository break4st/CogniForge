系统概述

系统定位

实现将打包好的可执行文件自动化部署到指定远程服务器的功能。支持用户自定义多套部署环境（如测试线、灰度线、正式线等），每套环境可通过SSH密钥配置安全连接，部署时自动在远程服务器上创建版本文件夹并生成执行脚本，实现一键式自动化部署。用户可创建和管理多个项目，每个项目拥有独立的部署环境配置，支持在项目间灵活切换，满足多项目并行管理的需求。

  • 上传和管理SSH密钥
  • 执行一键自动化部署
  • 查看部署进度和结果
  • 在项目间切换管理

  • 管理远程服务器访问权限

架构设计

前后端分离的模块化架构
系统采用前后端分离的模块化架构，前端提供Web UI交互界面，后端按业务领域划分为项目管理、环境管理、部署执行、密钥管理等核心服务模块。通过消息队列实现异步部署任务调度，结合加密存储保障密钥安全，支持多环境多服务器的自动化部署流程。

组件设计 (9)

Web UI

frontend

基于Web的图形用户界面，提供项目管理、环境配置、部署操作和状态查看等功能

  • 项目列表展示与搜索筛选
  • 部署环境配置表单
  • 部署操作入口与进度展示
  • SSH密钥上传管理界面
  • 部署历史与日志查看

API Gateway

gateway

统一API网关，负责请求路由、认证鉴权、限流和日志记录

  • 请求路由转发
  • 用户身份认证
  • 接口访问控制
  • 请求日志记录
  • 限流保护

Project Service

service

项目管理服务，负责项目的CRUD操作和项目间切换

  • 项目创建、编辑、删除
  • 项目列表查询与关键字搜索
  • 项目切换管理
  • 项目与环境的关联管理

Environment Service

service

环境管理服务，负责部署环境的配置管理和连通性测试

  • 环境创建、编辑、删除
  • 环境类型标签管理
  • 服务器地址、端口、用户名等连接信息配置
  • 连通性测试

Key Management Service

service

密钥管理服务，负责SSH密钥的安全存储和管理

  • SSH密钥上传与存储
  • 密钥内容加密解密
  • 密钥与环境的关联管理
  • 密钥更换与轮转

Deployment Service

service

部署执行服务，负责自动化部署流程的编排和执行

  • 部署任务创建与调度
  • 可执行文件上传到远程服务器
  • 远程版本目录创建
  • 启动/停止/重启执行脚本生成
  • 部署状态跟踪与反馈

Message Queue

mq

消息队列，负责异步部署任务分发和状态变更通知

  • 部署任务异步分发
  • 部署状态变更通知推送
  • 失败任务重试机制

Relational Database

db

关系型数据库，存储项目、环境、密钥、部署记录等全部结构化数据

  • 项目数据持久化
  • 环境配置数据存储
  • 密钥元数据存储
  • 部署历史记录存储

Cache

cache

缓存服务，缓存项目列表、环境配置等热点数据，提升系统响应速度

  • 缓存项目列表数据
  • 缓存环境配置信息
  • 缓存用户会话信息

拓扑结构

系统采用四层拓扑结构：接入层提供Web UI和API统一入口，服务层包含全部核心业务服务，中间件层通过消息队列实现异步通信解耦，数据层负责持久化存储和热点缓存。

数据流

1
一键部署流程
用户在Web UI选择项目、环境和版本号，上传可执行文件→API Gateway接收请求并转发至Deployment Service→Deployment Service创建部署任务并返回task_id→Deployment Service将任务发送到Message Queue异步执行→Deployment Service从队列消费任务，通过SSH连接到远程服务器→在远程服务器按版本号创建独立部署目录→上传可执行文件到远程服务器→生成启动/停止/重启等执行脚本→通过Message Queue发送部署状态变更事件→Web UI实时更新部署进度和结果
2
环境配置流程
用户填写环境配置表单（服务器地址、端口、用户名等）→关联已上传的SSH密钥→Environment Service测试远程服务器连通性→配置信息保存到Relational Database→结果返回前端确认
3
密钥管理流程
用户在Web UI上传SSH密钥或选择更换密钥→API Gateway转发请求至Key Management Service→Key Management Service对密钥私钥内容进行加密存储→密钥元数据（非私钥原文）保存到Relational Database→加密后的密钥与对应环境关联→操作结果返回前端确认
