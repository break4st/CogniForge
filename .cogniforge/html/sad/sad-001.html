系统概述

系统定位

面向开发者和运维人员的轻量级持续部署桌面工具，支持多项目管理、多环境配置、密钥加密、一键自动化部署、版本历史与回滚。客户端本地运行，通过 SSH/SFTP 与远程服务器交互。

架构设计

本地优先的分层桌面架构
系统分为表现层、应用服务层和基础设施层。表现层负责 UI 交互，通过 IPC 通道调用主进程服务；应用服务层封装业务逻辑，协调基础设施能力；基础设施层提供加密、存储、SSH 连接等底层支持。层间通过清晰接口通信，确保模块化和可测试性。

数据流

1
部署流程
用户在 DeployPanel 选择环境和文件，触发部署→IPC Bridge 调用 DeploymentService.deploy()→DeploymentService 从 EnvironmentService 获取解密后的环境配置→若配置了部署前脚本，通过 SshClient 执行并获取输出（实时推送日志）→生成时间戳版本目录名，通过 SFTP 创建目录并上传文件→根据脚本模板生成 start.sh，通过 SshClient 创建文件并赋予执行权限→若配置了部署后脚本，执行之并推送输出→根据配置决定更新 current 软链接→部署完成，返回结果给 UI
2
版本回滚流程
用户在 VersionHistoryView 选择历史版本，确认回滚→IPC Bridge 调用 VersionHistoryService.rollback()→VersionHistoryService 获取环境解密配置，通过 SshClient 连接服务器→执行 ln -snf <版本目录> current→返回成功，刷新历史列表
3
主密码验证流程
应用启动时检查本地是否存在密码哈希→若不存在，弹出设置界面，用户输入两次密码→MasterPasswordService 派生密钥，存储哈希→若已存在，弹出输入界面→MasterPasswordService 派生输入密码并与存储哈希比对→正确则缓存密钥，允许使用加密功能
