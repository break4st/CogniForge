系统概述

系统定位

本系统采用前后端分离的微服务架构，支持多项目自动化部署。前端为单页应用，通过API网关访问后端微服务。后端按业务边界拆分为项目、环境、SSH密钥、部署、历史等服务，部署任务通过消息队列异步执行，确保高可用和可扩展性。

架构设计

微服务架构
系统分为接入层、网关层、服务层、数据层。服务层包含多个独立微服务，通过RESTful API和消息队列进行通信。部署任务采用异步处理，提升响应速度和可靠性。

数据流

1
一键部署流程
1. 用户在前端选择项目、环境，上传文件，点击部署→2. 前端调用 API 网关 POST /api/deployments→3. API 网关转发至 deployment-service→4. deployment-service 校验：调用 project-service 确认项目存在，调用 environment-service 获取环境详情，调用 ssh-key-service 测试远程连接→5. 校验通过后，deployment-service 在数据库中创建“等待中”的部署记录，并将任务消息发送至 RabbitMQ→6. deployment-executor 消费消息，从 environment-service 获取环境信息，从 ssh-key-service 获取解密后的内存私钥→7. deployment-executor 建立 SSH 连接，上传文件，创建版本文件夹，生成启动脚本→8. deployment-executor 实时推送进度到前端 WebSocket，并更新部署记录状态和日志→9. 用户通过 history-service 查看历史记录和日志，失败时可触发重试
