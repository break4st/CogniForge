系统概述

系统定位

AutoDeploy 自动化部署平台旨在实现将打包好的可执行文件自动化部署到指定远程服务器的功能。平台采用前后端分离的B/S架构，支持用户自定义多套部署环境（如测试线、灰度线、正式线等），通过SSH安全连接实现一键式自动化部署，并支持多项目并行管理。

架构设计

分层架构 + 服务化设计
系统采用经典的分层架构，表现层通过API网关与后端服务通信，服务层各服务职责单一、相互协作以完成部署编排，数据统一由关系型数据库持久化存储。API网关作为统一入口负责鉴权路由，服务层内部通过REST接口或消息队列异步通信，实现解耦与可扩展性。

frontend

用户交互界面，提供项目管理、环境管理、部署操作的可视化操作界面

  • 提供环境配置界面
  • 提供部署操作界面

  • 审计日志查询界面
网关层 1

🔀 API Gateway

系统统一API入口，负责请求路由、认证鉴权、请求限流

  • 请求路由分发
  • 用户身份认证
  • 接口权限校验
  • 请求限流与防护
服务层 7

⚙️ Project Management Service

service

项目管理服务，负责项目的创建、编辑、删除和查询，实现多项目数据隔离

  • 项目CRUD操作
  • 项目环境关联管理
  • 项目列表查询与搜索
  • 项目间数据隔离

⚙️ Environment Management Service

service

环境管理服务，负责部署环境的配置和管理，支持多套环境独立配置

  • 环境CRUD操作
  • 服务器连接信息配置
  • 环境标签和备注管理
  • 连接测试验证

⚙️ Deployment Orchestrator

service

核心部署编排服务，协调文件传输、目录创建、脚本生成等部署流程，管理部署状态

  • 部署流程编排
  • 文件传输调度
  • 版本目录自动创建
  • 执行脚本自动生成
  • 部署状态跟踪和日志记录

⚙️ SSH Execution Service

service

SSH远程执行服务，负责与远程服务器建立安全连接并执行命令和文件传输

  • SSH连接管理
  • 远程命令执行
  • 文件传输(SFTP/SCP)
  • 连接超时与重试管理
  • 连接测试

⚙️ Key Management Service

service

密钥管理服务，负责SSH密钥对的导入、存储和管理，确保密钥信息安全

  • SSH密钥对生成
  • 密钥导入和导出
  • 密钥加密存储
  • 密钥与环境的关联管理

⚙️ Audit Service

service

审计日志服务，记录所有部署操作和环境变更操作，提供可追溯的审计能力

  • 部署操作日志记录
  • 环境配置变更记录
  • 审计日志查询
  • 操作时间线追溯

⚙️ File Storage

service

文件存储服务，管理上传的部署包文件，支持版本化和归档

  • 部署文件上传
  • 部署文件版本管理
  • 文件归档与清理
持久化层 1

📦 Primary Database

db

系统主数据库PostgreSQL，持久化存储项目、环境、部署记录等核心业务数据

  • 项目数据存储
  • 环境配置存储
  • 部署记录存储
  • 审计日志存储
  • 用户数据存储
  • SSH密钥元数据存储

数据流

1
一键部署流程
用户通过Web Console选择项目、目标环境和部署文件→Web Console调用 Deployment API (POST /api/deployments) 发起部署请求→Deployment Orchestrator 接收请求并记录部署开始日志到 Audit Service→Deployment Orchestrator 向 Environment Management Service 获取目标环境连接配置→Deployment Orchestrator 向 Key Management Service 获取关联的SSH私钥→Deployment Orchestrator 向 File Storage 获取部署文件内容→Deployment Orchestrator 调用 SSH Execution Service 的 File Transfer 接口将部署文件上传到远程服务器→SSH Execution Service 在远程服务器创建带版本标识的部署目录→SSH Execution Service 将上传的文件放置到版本目录→Deployment Orchestrator 调用 SSH Execution Service 的 Execute 接口在远程服务器生成并执行启动脚本→SSH Execution Service 返回执行结果和日志→Deployment Orchestrator 将部署结果和日志持久化到 Primary Database→Deployment Orchestrator 更新部署状态并通过 Audit Service 记录完成事件→Web Console 实时轮询 Deployment API 获取部署状态和日志并展示给用户
2
环境配置流程
运维工程师通过Web Console进入环境管理页面→填写环境名称、服务器地址、端口、认证方式等信息→选择认证方式（密码或密钥），如选择密钥认证则关联已导入的SSH密钥→Web Console调用 Environment API (POST /api/environments) 创建环境配置→Environment Management Service 将环境配置持久化到 Primary Database→配置完成后运维工程师可发起连接测试→Environment Management Service 调用 SSH Execution Service 的内部接口进行连接测试→连接测试结果返回并展示在Web Console
3
项目管理流程
技术经理通过Web Console进入项目管理页面→创建新项目，填写项目名称和描述→Web Console调用 Project API (POST /api/projects) 创建项目→Project Management Service 将项目信息持久化到 Primary Database→在项目下创建部署环境并关联SSH密钥→项目创建完成后可在项目间快速切换→不同项目的环境和部署数据完全隔离
4
SSH密钥管理流程
运维工程师通过Web Console进入密钥管理页面→选择导入已有SSH密钥对，填写密钥名称并上传公钥和私钥→Web Console调用 Key Management API (POST /api/keys) 导入密钥→Key Management Service 对私钥进行加密后持久化到 Primary Database→密钥导入成功后可在环境配置中选择关联该密钥→密钥列表仅展示元数据（名称、指纹、类型），不暴露私钥内容
