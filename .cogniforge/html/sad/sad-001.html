系统概述

系统定位

CogniForge 是一个基于 Electron 的桌面应用，帮助开发者将本地打包文件一键部署到远程服务器。系统支持多项目管理、独立环境配置、安全凭据存储、实时日志回传、版本回滚等功能。采用分层架构，前端 React + TypeScript，后端 Node.js 集成在 Electron 主进程，本地使用 SQLite，通过 SSH 协议与远程服务器交互。

架构设计

分层 + 前后端分离（Electron 主进程与渲染进程）
渲染进程负责 UI 展示和用户交互，通过 Electron IPC 调用主进程的服务模块。主进程中的服务层包括项目服务、环境服务、部署服务、安全服务、SSH 服务等，通过数据访问层操作本地 SQLite 数据库。远程通信完全基于 SSH 协议。整体分为表示层、服务层、数据层和基础设施层。

数据流

1
一键部署流程
用户选择项目、环境、本地文件、版本标签→前端调用 deployment.start IPC→DeploymentService 从 EnvironmentService 获取解密凭据→DeploymentService 调用 SSHService 建立连接→执行远程命令创建 releases/<version> 目录→SFTP 上传文件并校验 MD5→生成并上传管理脚本 (start/stop/restart)→若配置前置脚本则执行→更新 current 软链接指向新版本→若配置后置脚本则执行→整个过程通过 LoggerService 推送实时日志→记录部署结果到数据库→成功则返回部署记录 ID；失败则清理远程文件并抛出错误
2
回滚流程
用户在部署历史页面选择一条记录并确认回滚→调用 deployment.rollback IPC→RollbackService 查询原部署记录，获取环境和版本信息→验证远程服务器上该版本目录是否存在→更新 current 软链接指向该版本目录→尝试执行该版本目录下的 start.sh→记录回滚操作（新部署记录或状态更新）
3
主密码设置/验证流程
首次启动或修改主密码时，前端弹出设置界面→通过 IPC 调用 masterPassword.set/change→SecurityService 使用 PBKDF2 派生密钥，存储哈希→修改主密码时，用旧密码解密所有敏感数据，再用新密码重新加密→启动验证时，读取哈希并验证输入的密码
