系统概述

系统定位

CogniDeploy 是一套面向开发与运维团队的自动化部署平台，统一管理多套部署环境、通过 SSH 安全连接远程服务器、一键将本地可执行文件部署并生成版本目录与启动脚本，同时提供完整的部署历史追踪。系统支持多项目独立管理，且对环境配置、私钥进行加密保存，保障安全性。

架构设计

模块化单体 + 前后端分离
采用一个内部松耦合的单体后端（逻辑上划分为多个领域服务模块），配合清晰的前后端分离模式。后端各模块通过内部 API 交互，但对外暴露统一 RESTful API。部署执行采用 Celery 异步任务队列以保证非阻塞。

高安全：私钥 AES-256 加密存储，传输过程仅内存处理实时反馈：部署进度通过 SSE 推送至前端多项目隔离：环境绑定与部署操作完全隔离可追溯：全量部署历史记录，支持过滤易用性：一键部署，清晰进度与错误提示可扩展：环境、项目、部署服务各自解耦

数据流

1
一键部署流程
前端用户选择项目、环境、本地文件，点击部署→前端发送 POST /api/projects/{id}/deploy 携带参数→DeploymentOrchestrator 校验文件、获取环境配置、生成部署摘要→返回 deployment_id 并提交 Celery 异步任务→Celery Worker 解密私钥 → 建立 SSH 连接 → 创建远程目录 → 上传文件 → 生成启动脚本→ProgressNotifier 通过 SSE 向前端实时推送进度→任务完成或失败后，将结果和日志写入 DeploymentHistory→前端 SSE 监听，动态更新进度条与状态
2
环境创建与连通性测试
前端环境表单填写信息，提交创建请求→EnvironmentService 接收，调用 KeyManager 加密私钥→自动触发 ConnectivityTester 执行 TCP/SSH/写权限测试→测试通过才允许保存环境记录→测试失败则返回详细错误，阻止保存
3
项目多环境绑定
用户在项目管理页面选择一个项目→从全局环境池中选择环境进行绑定→后端 ProjectService 更新绑定关系表→前端切换项目时，部署面板仅显示该项目绑定的环境
