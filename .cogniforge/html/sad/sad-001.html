系统概述

系统定位

本系统为面向开发与运维人员的本地桌面应用，基于 Electron 构建，支持多项目、多环境的自动化一键部署。用户通过 React 界面集中管理项目、环境、脚本模板与部署历史，通过 SSH/SFTP 将本地产物上传至远程服务器并自动生成启动脚本。

👤
部署操作员
  • 管理项目
  • 管理环境
  • 执行一键部署
  • 查看部署历史与日志
  • 管理脚本模板
🏗️

架构设计

本地前后端分离的分层架构
采用 Electron 主进程与渲染进程分离的模式。主进程运行 Express 服务提供本地 REST API，处理业务逻辑与远程连接；渲染进程使用 React + Ant Design 构建用户界面。系统分为表示层、应用服务层、数据访问层和基础设施层。
