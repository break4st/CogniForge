系统概述

系统定位

CogniDeploy 是一款本地单用户自动化部署工具，采用前后端分离的分层架构。前端提供多项目管理、环境配置、一键部署及历史回溯等交互；后端通过 RESTful API 提供业务服务，并利用 SSH/SFTP 协议与远程服务器交互，所有敏感凭证使用 AES-256 加密存储。系统运行在本地，数据库使用 SQLite，整体强调安全性、易用性和部署过程的可视化。

架构设计

分层架构 + 前后端分离
系统划分为表现层、接入层、服务层、数据层和基础设施层。表现层为 React 单页应用，通过本地 HTTP/WebSocket 与接入层（FastAPI 网关）通信；服务层封装所有业务逻辑，依赖基础设施层实现 SSH 连接与加密；数据层采用 SQLite 持久化信息。各层职责清晰，便于维护和扩展。
