系统概述

系统定位

DeployFlow 是一款基于分层架构的轻量级自动化部署工具，采用前后端分离设计：React 前端提供直观的操作界面，Flask 后端处理核心业务逻辑并通过 REST API 与前端通信。系统使用 SQLite 本地存储项目、环境、历史等数据，通过 paramiko 库实现安全的 SSH 密钥认证与远程操作，支持多项目隔离、版本化部署、脚本定制及一键回滚。

👤
用户
  • 创建、编辑、删除项目
  • 为项目配置测试/灰度/正式等多套环境
  • 进行 SSH 连接测试
  • 执行一键部署与查看实时进度
  • 自定义启动/停止脚本
  • 查看部署历史并执行回滚
  • 切换当前活动项目
🏗️

架构设计

分层架构（表现层-服务层-基础设施层-数据层）
系统采用清晰分层解耦：表现层基于 React SPA，通过 HTTPS REST 调用服务层；服务层由 Flask 核心应用实现，封装项目管理、环境配置、部署执行、历史记录等业务模块；基础设施层提供 SSH 连接池与 SFTP 传输能力；数据层使用 SQLite 数据库，通过 SQLAlchemy ORM 访问。各层间职责明确，便于独立开发和维护。

轻量级单体应用，易于部署和分发前后端分离，UI 可独立迭代多项目完全隔离，数据独立管理基于 SSH 密钥的安全无密码自动化运维版本目录以时间戳或自定义标签命名，支持多版本共存与快速回滚内置脚本模板与变量替换，适应不同环境需求

数据流

1
一键部署流程
用户在前端选择项目与环境，上传文件压缩包→前端通过 POST /api/deployments 提交部署请求→Flask API 接收请求，校验参数，创建部署记录状态置为 'queued'→部署执行引擎异步领取任务，更新状态为 'deploying'→引擎通过 SSH 连接模块建立 SFTP 连接，上传文件包并实时报告进度→引擎在远程创建版本目录（如 `/deploy_root/20260524_194030`），执行解压→引擎调用脚本模板管理器生成 start.sh / stop.sh 并上传到版本目录→引擎根据 auto_start 配置决定是否远程执行 start.sh→引擎将部署结果（成功/失败信息、远程路径等）写入部署历史记录→前端通过轮询或 WebSocket 获取进度更新，直至状态变为 'success' 或 'failed'
2
项目切换数据刷新流程
用户在前端项目列表点击目标项目→前端存储当前选中项目ID→前端调用 GET /api/projects/{project_id}/environments 获取环境列表→前端调用 GET /api/deployments?project_id=... 获取该项目的部署历史→页面渲染环境标签与历史记录表格，内容随项目切换即时更新
