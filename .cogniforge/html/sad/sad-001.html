系统概述

系统定位

本系统为一站式自动化部署平台，实现对打包好的可执行文件向远程服务器的自动化部署。系统采用 B/S 架构，提供 Web 控制台操作界面，后端通过 SSH 协议与目标服务器交互。支持多项目、多环境（测试线/灰度线/正式线）的灵活管理，每个环境独立配置 SSH 密钥认证，部署时自动创建版本目录并生成执行脚本，实现一键式部署。

架构设计

分层单体架构 + 前后端分离
系统采用前后端分离的分层架构。前端为 SPA 单页应用，通过 REST API 与后端通信。后端采用分层结构：接入层（API 控制器）→ 业务服务层 → 基础设施层。业务服务层内部按领域划分为项目管理、环境管理、部署引擎、密钥管理四大核心模块。基础设施层封装 SSH 连接池、文件存储和审计日志等通用能力。这种分层方式在保持较小部署单元的同时，确保各领域逻辑的清晰边界和可测试性。

组件设计 (11)

表现层 1

🖥️ Web控制台

frontend

浏览器端 SPA 应用，提供项目、环境、部署管理的可视化操作界面

  • 项目列表展示与切换
  • 部署环境配置表单
  • SSH 密钥上传/粘贴配置
  • 部署操作触发与进度展示
  • 部署日志实时查看
接入层 2

🔀 API网关

gateway

REST API 统一入口，负责请求路由、认证鉴权、请求校验和响应封装

  • 请求路由分发到对应业务服务
  • 统一身份认证与会话管理
  • 请求参数校验与错误格式化
  • 跨域处理和限流

🔀 认证中间件

gateway

嵌入在 API 网关中的认证拦截模块，验证用户的登录会话和操作权限

  • 用户会话 Token 校验
  • 请求身份解析和注入上下文
  • 基于角色的操作鉴权
  • 未授权请求拦截
业务服务层 4

⚙️ 项目管理服务

service

管理项目生命周期，维护项目及其关联的环境和部署记录

  • 项目的创建、编辑、删除
  • 项目列表查询和当前项目切换
  • 项目-环境关联关系维护
  • 项目部署历史记录查询

⚙️ 环境管理服务

service

管理部署环境的配置，包括服务器地址、端口、认证方式等

  • 环境的创建、编辑、删除
  • 环境连接参数配置（地址、端口）
  • 环境与密钥的绑定关系管理
  • 环境连通性测试

⚙️ 密钥管理服务

service

安全存储和管理 SSH 密钥，提供密钥的上传、绑定和验证功能

  • SSH 密钥的安全存储（加密后落库）
  • 密钥与环境的绑定管理
  • 密钥有效性验证
  • 部署时提供解密后的密钥会话

⚙️ 部署引擎服务

service

核心部署执行单元，负责在远程服务器上创建目录、传输文件、生成脚本和执行部署

  • 接收部署请求并解析部署参数
  • 在远程服务器创建版本化目录结构
  • 上传可执行文件包到远程服务器
  • 生成启动/停止/重启执行脚本
  • 实时回传部署进度和日志
  • 处理部署失败的回滚逻辑
基础设施层 4

⚙️ SSH连接池

service

管理到远程服务器的 SSH 连接，提供连接复用和生命周期管理

  • SSH 连接的创建、复用和销毁
  • 连接健康检测和自动重连
  • 连接超时管理
  • 并发连接数控制

⚙️ 文件存储服务

service

存储用户上传的可执行文件包，支持版本化管理和按需下载

  • 可执行文件包的上传和存储
  • 文件版本化管理
  • 部署时按需提供文件下载
  • 存储空间配额管理

⚙️ 审计日志服务

service

记录系统中所有关键操作的审计日志，确保操作可追溯

  • 记录项目的创建/修改/删除操作
  • 记录环境配置变更和密钥操作
  • 记录每次部署的全流程日志
  • 日志的持久化存储和查询

🗄️ 数据库

database

关系型数据库，存储项目、环境、密钥、部署记录和审计日志等持久化数据

  • 项目数据的持久化存储
  • 环境配置数据存储
  • 加密后的密钥信息存储
  • 部署记录和审计日志存储
  • 数据完整性约束和事务支持

数据流

1
创建项目
用户在 Web 控制台填写项目名称和标识→Web 控制台调用 POST /api/v1/projects 发送请求→API 网关校验身份后路由到项目管理服务→项目管理服务校验项目参数，写入数据库→返回创建成功的项目信息给 Web 控制台→审计日志服务记录项目创建操作
2
配置环境与密钥
用户在 Web 控制台选择项目，进入环境管理页面→用户填写环境名称（如测试线）、服务器地址和端口→Web 控制台调用 POST /api/v1/projects/:pid/environments→环境管理服务校验并存储环境配置→用户选择 SSH 密钥认证方式，上传或粘贴私钥内容→Web 控制台调用 POST /api/v1/environments/:eid/keys→密钥管理服务加密存储密钥，并与环境绑定→用户点击'测试连接'按钮验证配置→环境管理服务调用 SSH 连接池发送测试请求→SSH 连接池使用密钥建立连接并返回连接成功/失败结果→审计日志服务记录环境和密钥配置操作
3
一键部署
用户在 Web 控制台选择项目、目标环境和待部署的可执行文件包→用户填写版本号，点击'部署'按钮→Web 控制台调用 POST /api/v1/deploy 创建部署任务→部署引擎服务接收部署请求，返回任务 ID→部署引擎向文件存储服务请求获取文件包→部署引擎通过 SSH 连接池连接到目标服务器→在远程服务器上创建版本化目录（如 /opt/app/releases/v1.0.0/）→上传可执行文件包到版本目录→自动生成 start.sh、stop.sh、restart.sh 执行脚本→执行启动脚本完成部署→实时回传部署进度和日志到 Web 控制台→Web 控制台轮询 GET /api/v1/deploy/:taskId/status 展示进度→部署成功或失败后更新任务状态→审计日志服务记录完整部署过程
4
项目切换
用户在 Web 控制台的项目列表中选择目标项目→前端切换当前上下文，展示选中项目的仪表盘→自动加载该项目的环境列表和部署历史→用户可在新项目下执行环境配置和部署操作→所有后续 API 请求携带当前项目 ID 上下文
