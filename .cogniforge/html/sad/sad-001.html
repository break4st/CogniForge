系统概述

系统定位

CogniForge 是一款基于 Electron 的桌面应用程序，面向开发运维人员，提供多项目独立管理、安全 SSH 连接、一键部署、历史回溯等功能。系统采用模块化单体架构，通过主进程与渲染进程分离实现 UI 与业务逻辑的解耦，利用本地 SQLite 数据库存储配置与历史，并对敏感密钥实施 AES-256 加密。整体架构围绕项目管理、环境配置、部署执行和安全控制四大核心域构建，支持可扩展的部署流程和灵活的环境管理。

👤
操作员（开发/运维/测试/安全/产品经理）
  • 创建、查看、编辑、删除项目
  • 管理所有环境的配置与密钥
  • 执行一键部署
  • 测试连接
  • 查看部署历史并执行回滚
  • 查阅审计日志

架构设计

模块化单体（Electron 桌面应用）
系统采用 Electron 框架构建跨平台桌面应用，前端使用 React + TypeScript 实现丰富的用户界面，后端逻辑运行于 Electron 主进程，通过 IPC 通信与渲染进程交互。主要划分为表现层、业务逻辑层、基础服务层和数据持久层。表现层负责 UI 交互与快捷键响应；业务逻辑层包含项目管理、环境管理、部署引擎等核心模块；基础服务层封装 SSH/SFTP 通信、密钥加解密及审计日志；数据持久层采用 SQLite 本地数据库。各层之间通过定义好的服务接口解耦，确保单一职责和可测试性。

数据流

1
一键部署流程
用户在 UI 拖拽文件并选择环境，点击部署→UI 通过 IPC 调用 Deployment Engine (startDeploy)→Deployment Engine 检查环境连通性（通过 Environment Manager）→调用 Security Module 解密目标环境的私钥→使用 SSH Service 建立连接并执行 SFTP 上传文件、创建版本文件夹→SSH Service 返回每个步骤的结果，Deployment Engine 推送进度事件到 UI→文件传输完成后，Deployment Engine 调用 SSH Service 执行 shell 命令生成 deploy.sh 脚本并赋予可执行权限→部署成功后，Deployment Engine 调用 History & Rollback Service 保存记录→UI 接收最终成功事件并通知用户
2
环境连通性测试
用户在 UI 点击“测试连接”→UI 调用 Environment Manager 的 testConnection IPC→Environment Manager 获取该环境的加密私钥，调用 Security Module 解密→调用 SSH Service 尝试连接并执行简单命令（如 echo ok）→SSH Service 返回成功/失败，Environment Manager 通过 IPC 将结果返回 UI 展示
3
部署回滚
用户在历史页面选择某条历史记录，点击“回滚”→UI 调用 History & Rollback Service 的 rollback IPC→Service 根据历史记录找到远程 version 文件夹路径和 deploy.sh→通过 Security Module 解密对应环境的私钥→调用 SSH Service 执行回滚命令（执行 deploy.sh）→执行成功后将此次回滚记录为新的特殊历史条目

架构决策 (3)

1
AD-001: 选择 Electron 而非原生桌面框架

决策: 选用 Electron 结合 React + Ant Design，提供一致的 UI 体验。

原因:

2
AD-002: 密钥加密存储于本地 SQLite

决策: 使用 AES-256-GCM 加密私钥后存入 SQLite，加密密钥由用户主密码或系统密钥环派生，解密仅在内存中进行。

原因:

3
AD-003: 部署流程幂等性与原子性

决策: 部署引擎采用步骤化设计，每一步失败可重试，且所有部署操作先上传至临时目录，最后原子性重命名至目标版本文件夹。
