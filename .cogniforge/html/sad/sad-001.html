系统概述

系统定位

自动化部署系统是一个基于 Web 的可视化部署平台，支持用户管理多项目、多环境（测试线、灰度线、正式线），通过 SSH 密钥安全连接到远程服务器，实现一键式自动化部署。系统采用前后端分离的微服务架构，将项目管理、环境配置、部署执行等核心能力解耦为独立服务，确保可扩展性与可维护性。

架构设计

微服务架构（前后端分离）
系统采用前后端分离的微服务架构，前端为单页应用（SPA），后端按业务领域拆分为独立微服务。各服务通过 REST API 通信，异步任务通过消息队列解耦。数据存储采用关系型数据库为主、对象存储为辅的混合存储策略。

前后端分离，独立部署和扩展服务无状态设计，支持水平扩展异步任务处理，部署操作不阻塞用户SSH连接池复用，提升远程执行效率统一认证鉴权，保障系统安全完整审计日志，操作可追溯

数据流

1
项目创建流程
用户填写项目信息并提交→API网关验证JWT并路由到项目管理服务→项目管理服务校验并创建记录到数据库→返回创建结果，前端刷新项目列表
2
环境配置流程
用户选择项目并添加部署环境→环境管理服务接收配置并安全存储SSH密钥→用户发起连接测试请求→SSH执行服务验证连接配置→返回测试结果，更新状态
3
一键部署流程
用户选择项目、环境和文件，点击部署→API网关发送请求到部署编排服务→部署编排服务创建部署任务并推送到消息队列→文件管理服务传输文件到SSH执行服务→SSH执行服务在远程创建版本文件夹 (/data/deploy/{project}/{env}/{version}/)→上传可执行文件并生成执行脚本→授予执行权限并运行部署脚本→通过WebSocket实时展示部署日志和结果
4
部署回滚流程
用户在历史中选择版本发起回滚→部署编排服务查询目标版本记录→从文件存储获取历史文件并传输→执行回滚脚本完成版本切换→通知前端回滚结果
