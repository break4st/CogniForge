任务列表

1. PostgreSQL数据库Schema设计与迁移脚本

P0 阻塞 · migration · 6h · dev

设计并实现所有数据表的DDL：projects、environments、deployment_keys、deployments、deployment_steps、deployment_logs、audit_logs、users、files。包含UUID主键、外键约束、索引策略、软删除字段、JSONB字段、BIGSERIAL自增ID，以及Flyway迁移脚本框架（V1__init_schema.sql）。

依赖: 无

2. RabbitMQ消息队列部署与拓扑配置

P0 阻塞 · config · 4h · dev

搭建RabbitMQ基础环境，配置5个Exchange（task/status/log/retry/dlx）和5个Queue及对应的Binding。实现连接管理、心跳检测、指数退避重连机制。配置死信队列(DLQ)和TTL策略。

依赖: 无

3. MinIO文件存储基础设施部署

P0 阻塞 · config · 4h · dev

部署MinIO对象存储服务，创建deploy-artifacts存储桶并开启版本控制，配置30天自动清理的生命周期规则。实现文件上传、下载、删除和过期清理接口，对接服务内部REST通信。

依赖: 无

4. 密钥存储服务 - 加密存储引擎与CRUD

P0 阻塞 · service · 8h · dev

基于AES-256-GCM实现SSH私钥和密码的加密存储。实现密钥的创建（POST /api/v1/keys）、列表查询（GET /api/v1/keys）、详情查询（GET /api/v1/keys/{id}）、软删除（DELETE /api/v1/keys/{id}）和解密内部接口（/internal/api/v1/keys/{id}/decrypt）。支持SSH密钥自动提取公钥计算SHA256指纹。

依赖: PostgreSQL数据库Schema设计与迁移脚本

5. 项目管理服务 - 项目CRUD与生命周期

P1 高 · service · 6h · dev

实现项目的创建(POST)、列表分页(GET)、详情(GET)、更新(PUT)和软删除(DELETE)接口。包含名称唯一性校验（大小写不敏感）、分页搜索（ILIKE模糊匹配）、软删除过滤、存在进行中部署任务时禁止删除的业务约束。

依赖: PostgreSQL数据库Schema设计与迁移脚本

6. 环境配置服务 - 环境管理与连通性验证

P1 高 · service · 8h · dev

实现部署环境的CRUD接口（环境列表/详情/创建/更新/删除）。支持环境类型枚举（test/gray/production）。实现连通性验证接口POST /api/v1/environments/{id}/verify，通过密钥存储服务获取解密凭证建立SSH测试连接并更新环境状态（unknown/reachable/unreachable）。

依赖: PostgreSQL数据库Schema设计与迁移脚本, 密钥存储服务 - 加密存储引擎与CRUD

7. SSH连接池服务 - 连接复用与管理

P0 阻塞 · service · 6h · dev

实现SSH连接池管理，支持连接创建/复用/健康检查/自动重连/超时控制。实现POST /internal/ssh/execute接口供部署编排服务调用。包含连接状态机（CREATED/IDLE/IN_USE/ERROR/CLOSED），基于sync.RWMutex的并发安全，每目标服务器并发上限控制（max_active=10）。

依赖: 密钥存储服务 - 加密存储引擎与CRUD

8. 部署编排服务 - 核心部署流程引擎

P1 高 · service · 8h · dev

实现部署触发(POST /api/v1/deployments)、状态查询(GET /api/v1/deployments/{id})接口。核心编排流程：创建版本目录→上传可执行文件→生成启动脚本（start.sh/stop.sh/restart.sh）→执行启动。状态机管理（pending→running→success/failed），通过SSH连接池执行远程命令。

依赖: PostgreSQL数据库Schema设计与迁移脚本, MinIO文件存储基础设施部署, SSH连接池服务 - 连接复用与管理

9. 审计日志服务 - 记录查询与归档

P1 高 · service · 6h · dev

实现审计日志记录内部接口（/internal/api/v1/audit-logs）、日志查询接口（GET /api/v1/audit-logs，支持按project_id/action分页过滤）和归档接口（POST /api/v1/audit-logs/archive）。15种审计操作类型枚举，归档任务状态机（idle→archiving→completed/failed），归档文件写入文件存储。

依赖: PostgreSQL数据库Schema设计与迁移脚本, MinIO文件存储基础设施部署

10. 部署编排服务 - 消息队列集成与事件驱动

P1 高 · endpoint · 6h · dev

实现部署任务消息的MQ发布（exchange.deployment.task）和消费（queue.deployment.task）。部署状态变更事件（exchange.deployment.status）和日志事件（exchange.deployment.log）的发布。实现重试机制（最多3次，指数退避）和死信队列兜底。任务幂等性处理。

依赖: RabbitMQ消息队列部署与拓扑配置, 部署编排服务 - 核心部署流程引擎

11. 部署编排服务 - WebSocket实时日志推送

P2 中 · endpoint · 6h · dev

实现WebSocket端点WS /api/v1/ws/deployments/{id}/logs，消费MQ queue.deployment.log的日志事件并通过WebSocket实时推送到前端。支持断线自动重连（指数退避，最多5次）、日志按步骤分组、消息类型区分（log/status/error）。

依赖: RabbitMQ消息队列部署与拓扑配置, 部署编排服务 - 消息队列集成与事件驱动

依赖: 项目管理服务 - 项目CRUD与生命周期, 环境配置服务 - 环境管理与连通性验证, 部署编排服务 - 消息队列集成与事件驱动, 部署编排服务 - WebSocket实时日志推送, 审计日志服务 - 记录查询与归档, 密钥存储服务 - 加密存储引擎与CRUD
