系统概述

本系统为一套Web端学生管理系统，目标用户为教务管理员和教师。系统提供学生信息管理（增删改查）、班级信息管理、年级信息管理以及学习统计数据管理等核心功能。采用前后端分离的微服务架构，支持按班级/年级维度进行数据汇总与统计分析。

🏗️

架构设计

采用前后端分离的分层微服务架构。前端为单页应用（SPA），通过API网关统一接入后端服务。后端按业务领域拆分为四个独立微服务：学生服务、班级服务、年级服务和统计服务，每个服务独立部署、独立数据库表空间，通过RESTful API相互通信。数据层使用关系型数据库（MySQL）作为主存储，Redis作为缓存层加速热点数据访问。API网关统一处理认证鉴权、请求路由和限流。整体架构支持水平扩展，各服务无状态化设计。

拓扑结构

采用经典三层拓扑结构。展示层：浏览器端SPA，通过HTTPS与API网关通信。业务层：API网关作为统一入口，后面接四个微服务（学生服务、班级服务、年级服务、统计服务），服务之间通过内部REST API调用。数据层：MySQL主库负责持久化，Redis作为缓存层。各服务均无状态，部署于容器化环境（Docker/K8s），支持水平扩展。所有服务部署在同一内网网段，通过服务发现（如Consul/Nacos）实现相互寻址。

数据流

核心业务数据流：1）用户操作流：用户通过浏览器访问Web前端 → 前端构建HTTP请求 → API网关接收请求并校验JWT令牌 → 网关将请求路由至对应微服务 → 微服务处理业务逻辑（读取/写入MySQL数据库，操作Redis缓存） → 返回结果经网关回传至前端渲染展示。2）学生管理数据流：教务管理员在前端填写学生信息 → 信息经学生服务校验后写入MySQL → 成功响应返回前端。3）统计查询数据流：教师在前端发起统计查询请求 → 请求路由至统计服务 → 统计服务优先查询Redis缓存 → 缓存未命中则查询MySQL并回填缓存 → 统计数据经网关返回前端可视化展示。4）班级-年级层级数据流：年级服务管理年级节点 → 班级服务关联年级ID → 学生服务关联班级ID → 统计服务沿层级汇总数据。
